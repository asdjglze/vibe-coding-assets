## 任务描述
修复 Android 阅读模块中翻页模式与滚动模式排版渲染不一致的问题，确保行间距、段间距、首行缩进及字号处理逻辑完全统一。

## 执行过程
```mermaid
graph TD
    A[用户反馈:翻页模式渲染规则异常] --> B[搜索 ReaderSettingsStore 确认配置参数]
    B --> C[对比 PagedReaderBodies.kt 与 MdBody.kt 实现]
    C --> D{逐项核对:行距/段距/缩进/字号}
    D -->|一致 | E[继续检查特殊块处理]
    D -->|发现差异 | F[定位 Signature 落款字号差异]
    F --> G[定位 Poetic 诗词字距缩放差异]
    G --> H[修复 Signature 字号为 bodySp-1f]
    H --> I[修复 Poetic 字距 letterSpacingSp 不随 scale 变化]
    I --> J[全面回归核对 Code/Quote/TitleNote 等块]
    J --> K[编译验证无报错]
```

## 任务总结
成功修复翻页模式渲染差异：
1. **Signature 落款**：修正字号从 `bodySp` 改为 `bodySp - 1f`，与滚动模式保持一致。
2. **Poetic 诗词**：移除字距随行宽缩放 (`letterSpacingSp * scale`) 的逻辑，保持固定字距。
3. **其他块**：确认 Quote、Code、TitleNote 等背景与字号处理均与滚动模式一致。
所有排版参数（行距 ratio、段距 sp、缩进 em）均正确读取自 `settings`，无硬编码差异。
