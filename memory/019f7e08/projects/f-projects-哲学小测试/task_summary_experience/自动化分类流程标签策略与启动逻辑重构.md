## 任务描述
优化“先发布后分类”自动化流程规划，解决无来源文件标签策略、AI 细分类启动判定逻辑及标签来源机制问题。

## 执行过程
```mermaid
graph TD
    A[需求:优化分类流程] --> B[定义无来源散文件标签策略]
    B --> C[明确只挂「未校对」,类型留白归未知分区]
    C --> D[重构 AI 细分类启动判定逻辑]
    D --> E[废除「字段值 + 标签」组合判断]
    E --> F[确立「以标为准」直白逻辑:有标即做]
    F --> G[明确「位置即分类」规则:已归档书不启动 AI]
    G --> H[定义标签来源:快通道程序自动打标]
    H --> I[降级字段检查为复查兜底]
```

## 任务总结
成功更新规划文档：1) 无来源散文件仅挂「未校对」，精修时补类型；2) 细分类启动完全依赖「待分类」标签，废除字段值判断，明确物理归档书籍直接登记路径不启动 AI；3) 标签由快通道程序按欠账自动打标，人工仅在例外时干预；4) 字段检查降为防漏标的兜底机制。
