## 任务描述
从马克思主义文献网站增量爬取所有人物书籍文章，区分诗集类型，排除非人物条目及手工维护库（如毛泽东）数据。

## 执行过程
```mermaid
graph TD
    A[需求:全量人物书籍爬取] --> B[检查现有进程与人物清单]
    B --> C[扩充people.json至148人并剔除无效链接]
    C --> D[修正主页URL为index.html并增量抓structure.json]
    D --> E[修复probe_structure.py避免旧数据被覆盖]
    E --> F[新增crawl_new.py串行抓取新人主页(含头像/文章)]
    F --> G[修改fetch_tocs/crawl_books增加SKIP={'maozedong'}保护]
    G --> H[补写book.json标记已有articles.json的书以跳过重复下载]
    H --> I[优化crawl_books复用主页同URL文章避免二次请求]
    I --> J[后台并发执行目录抓取与书内容抓取]
```

## 任务总结
成功将人物库扩充至148人并完成增量抓取；通过复用主页文章URL逻辑减少约50%下载量；在关键脚本中植入对'maozedong'等手工库人物的跳过保护，确保人工整理数据不被爬虫覆盖；最终完成123本目录页与剩余书内容的抓取。
