## 任务描述
将硬编码的百科词条链接重构为数据库存储方案，解决代码臃肿问题并支持动态更新。

## 执行过程
```mermaid
graph TD
    A[发现硬编码问题] --> B[编写 Python 脚本批量验证并生成 URL]
    B --> C[脚本执行: ALTER TABLE person ADD COLUMN baikeUrl]
    C --> D[脚本填充 60 位人物的百度百科链接 (ID+ 词条名)]
    D --> E[修改 Person 实体新增 baikeUrl 字段]
    E --> F[升级 AppDatabase version 从 6 到 7]
    F --> G[删除 HomeScreen.kt 中的 BAIKE_ENTRIES mapOf 硬编码]
    G --> H[UI 层直接读取 person.baikeUrl 属性]
    H --> I[编译验证无报错]
```

## 任务总结
完成百科链接数据库化：通过 Python 脚本向 `notes_editor\quote.db` 的 `person` 表新增 `baikeUrl` 列并写入 60 个有效链接，仅编者（id=3）保持 null。代码层面移除硬编码 Map，升级 Room 数据库版本，UI 层直接绑定实体字段。此方案避免了代码膨胀，后续只需更新数据库即可生效，无需重新打包发布。
