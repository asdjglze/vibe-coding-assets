## 任务描述
重构图集元数据提取逻辑，废除"单轮盲猜"模式，改为与中图域同构的 Agent 化工具会话，允许 AI 自由调用 read_pages/view_pages/web_search 工具获取图集号与正式名称。

## 执行过程
```mermaid
graph TD
    A[用户批评:图集补号不应是单轮盲猜] --> B[分析现有流程:程序分类路径无AI介入导致缺号]
    B --> C[设计新方案:复用tagger工具协议实现多轮交互]
    C --> D[重构ai_atlas_identity函数:支持工具轮次循环]
    D --> E[集成_render_view_pages/_exec_tool实现翻页/渲染/搜索]
    E --> F[更新提示词:system位说明书式引导+工具协议定义]
    F --> G[清理旧代码:移除"身份轮"命名与独立提示词文件]
    G --> H[验证编译与逻辑一致性]
```

## 任务总结
成功将图集元数据提取从"单轮静态推理"升级为"Agent 动态会话"：
1. **能力升级**：AI 可主动请求 view_pages(看图)、read_pages(读文本)、web_search(联网) 补充信息，最多 1 轮工具交互。
2. **架构统一**：复用 tagger 模块的工具执行器与图像渲染协议，与出版社查找逻辑完全一致。
3. **命名修正**：清除"身份轮"等误导性术语，明确定位为"书名元数据补齐"。
4. **容错机制**：判不出号仍返回空串，不编造，确保纯名称入库不阻塞归档。
