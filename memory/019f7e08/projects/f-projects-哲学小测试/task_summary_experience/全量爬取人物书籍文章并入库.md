## 任务描述
全量爬取马克思主义文献网（marxists.org/chinese）所有人物主页及书籍文章，区分诗集类型，排除手工维护库（如毛泽东），最终同步至本地数据库。

## 执行过程
```mermaid
graph TD
    A[需求:全量爬取人物书籍] --> B[检查现有进程与人物清单]
    B --> C[修正主页URL: index.htm → index.html]
    C --> D[扩充 people.json: 58人→148人]
    D --> E[增量抓取新人主页结构 probe_structure.py]
    E --> F[补抓缺失文章 fetch_missing.py]
    F --> G[抓取书目录 fetch_tocs.py]
    G --> H[抓取书内文章 crawl_books.py 含复用优化]
    H --> I[标记诗集类型 rebuild_catalog.py]
    I --> J[入库新人数据 load_db.py 跳过毛泽东]
    J --> K[重建数据库 rebuild_catalog.py]
```

## 任务总结
成功完成 148 人全量爬取：头像齐全、主页文章 5410 篇、书目录 123 本、书内文章 2553 篇（复用优化节省时间）、诗集标记逻辑就绪（全站无诗集书）。修复关键 bug：URL 变更、增量加载覆盖、重复下载、手工库跳过保护。最终 DB 新增 383 本书、6130 篇文章（非手工库），仅 4 篇缺失兜底入库。
