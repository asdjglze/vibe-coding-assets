## 任务描述
对马克思在线图书馆进行全站人物书籍爬取，并实现诗集自动标记与数据库重建。

## 执行过程
```mermaid
graph TD
    A[需求:全站人物书籍爬取+诗集标记] --> B[扩充people.json至148人]
    B --> C[运行probe_structure.py抓取主页结构]
    C --> D[运行crawl_new.py串行抓取文章/插图]
    D --> E[运行fetch_tocs.py抓取书目录]
    E --> F[运行crawl_books.py抓取书内文章]
    F --> G[修改rebuild_catalog.py增加诗集正则标记]
    G --> H[执行rebuild_catalog.py重建SQLite数据库]
    H --> I[修改App端ArticleDao/BookshelfRepository兼容poem搜索]
```

## 任务总结
1. 完成148位人物的主页结构、文章、插图及290本著作的爬取。
2. 在rebuild_catalog.py中引入POETRY_RX正则，将整本诗集文章的kind标记为'poem'。
3. App端搜索逻辑适配，支持按source检索时包含poem类型文章。
4. 所有脚本增加了maozedong/luxun/editor等手工库人物的跳过保护。
