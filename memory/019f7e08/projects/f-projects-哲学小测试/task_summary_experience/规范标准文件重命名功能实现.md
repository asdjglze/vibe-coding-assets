## 任务描述
为规范标准类文件实现自动化重命名功能，去除下载站垃圾前缀、书名号等非标准字符，统一格式为「标准号 标准名称」。

## 执行过程
```mermaid
graph TD
    A[需求:规范标准文件重命名] --> B[定义_norm_std_title清洗函数]
    B --> C[剥书名号/压缩空白/去连接符]
    C --> D[在organize_standard中集成重命名逻辑]
    D --> E[优先使用std_number+title组合]
    E --> F[引入_budget_name处理超长路径截断]
    F --> G[确保扩展名保留及主干可读性]
    G --> H[单元测试验证不同场景]
```

## 任务总结
成功实现标准文件重命名：新增 `_norm_std_title` 清洗函数；归档时优先拼接 `std_number` 和 `title`；利用 `_budget_name` 跨平台预算机制截断超长文件名（单段≤47字，总长≤236字），确保书文件夹和文件名的规范性与兼容性。
