## 任务描述
解决新版 Edge/Chrome 浏览器调试端口 WebSocket 连接返回 403 Forbidden 错误。

## 执行过程
```mermaid
graph TD
    A[报错: WebSocketHandshake 403 Forbidden] --> B[分析错误日志]
    B --> C[发现需 --remote-allow-origins 参数]
    C --> D[修改 subprocess.Popen 添加启动参数]
    D --> E[修改 websocket.create_connection 添加 suppress_origin=True]
    E --> F[验证 websocket-client 库版本及参数支持]
```

## 任务总结
通过双保险方式修复了新版浏览器的 Origin 校验拦截：
1. 启动浏览器时增加 `--remote-allow-origins=*` 参数；
2. 建立 WebSocket 连接时设置 `suppress_origin=True` 以抑制 Origin 头发送。
