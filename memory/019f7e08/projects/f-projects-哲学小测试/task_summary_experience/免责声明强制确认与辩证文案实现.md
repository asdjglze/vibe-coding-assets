## 任务描述
为应用启动页免责声明增加强制确认机制（首次必须点击同意）、提供拒绝退出权利，并扩写文案以体现辩证唯物主义思想（版本差异、历史背景、文本发展观、扬弃等）。

## 执行过程
```mermaid
graph TD
    A[需求:免责声明强制确认与文案升级] --> B[新建 DisclaimerStore 持久化层]
    B --> C[在 QuoteApplication 注册单例]
    C --> D[修改 MainActivity 启动逻辑]
    D --> E[区分已同意/未同意状态]
    E --> F[未同意态:显示双按钮 (同意/拒绝)]
    F --> G[同意态:自动进入;拒绝态:直接退出]
    G --> H[重写 DisclaimerLoadingPage UI]
    H --> I[添加可滚动正文区]
    I --> J[扩写五段式文案 (风险→版本→历史→发展→实践)]
    J --> K[新增争议人物阅读指引]
    K --> L[编译验证通过]
```

## 任务总结
成功实现免责声明强制确认机制：新建 `DisclaimerStore` 持久化标记；首次启动显示「同意并进入」与「拒绝退出」双按钮，拒绝则直接退出且不记录同意状态；已同意用户自动跳过按钮。文案升级为六段递进结构：来源风险 → 一字之差需对比 → 版本无绝对权威结合历史 → 作者改稿体现意义依附时代 → 拒绝念经强调发展与扬弃 → 争议人物需辩证批判读。UI采用标题固定、正文可滚动布局，适配小屏。
