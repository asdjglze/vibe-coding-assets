## 任务描述
重构 merger.py 的分卷合并逻辑，解决旧版基于文件名正则（如(1)(2)、001/002）机械拼接导致的严重误判问题（如 Windows 复制产生的重复文件被合并、系列册书被强行拼成一本书）。

## 执行过程
```mermaid
graph TD
    A[需求:重构merger合并逻辑] --> B[分析旧逻辑缺陷:正则误判重复文件和系列册]
    B --> C[设计新策略:程序哈希去重 + AI语义判定]
    C --> D[实现SHA256哈希聚类:完全相同文件只保留一份]
    D --> E[重写merger.py:剩余同格式文件组交由LLM分析]
    E --> F[优化Prompt:明确区分split(分卷)与separate(系列册)]
    F --> G[编写测试脚本验证三种场景:重复/分卷/系列册]
    G --> H[清理临时测试文件与旧缓存记录]
```

## 任务总结
成功实现智能合并逻辑：1. 程序层通过 SHA256 哈希精准识别并备份内容完全相同的重复文件；2. 引入 LLM 对同目录同格式文件的开头/结尾进行语义分析，准确区分“同书拆分”与“独立成册”；3. 废弃了不可靠的正则命名规则判断，彻底解决了重复文件合并与系列册误合的问题。
