## 任务描述
对马克思恩格斯文献库进行深度清洗：合并完全重复的书目、拆分CHM合辑、纠正错挂篇章。

## 执行过程
```mermaid
graph TD
    A[核查:伊罗生/巴布石金等重复情况] --> B[备份quote.db]
    B --> C[执行基础改名:著作->拾遗汇编,书信->书信集]
    C --> D[删除完全重复CHM:巴布石金/伊罗生等4本]
    D --> E[内容级比对:归一化(去格式/标点)后对比正文]
    E --> F{是否子集?}
    F -- 是 --> G[保留文章数多的版本,删除少篇]
    F -- 否 --> H[保留两本,恢复原书名]
    H --> I[拆分CHM合辑:1408/1419按篇目归属拆分]
    I --> J[纠正错挂:摘除1416/1415中不属于本书的章节]
    J --> K[重排toc sortOrder]
```

## 任务总结
成功完成文献库清洗：
1. **去重规则**：采用归一化正文比对（去除HTML/脚注/空白/标点），若A包含B且内容一致，则保留文章数多的A。
2. **合辑拆分**：将1408(马克思)、1419(恩格斯)等合辑按实际篇目拆分为独立书籍，单书恢复原书名。
3. **纠错**：移除了1416/1415中的错挂篇章，修正了1417的排序。
4. **结果**：删除4本重复书，拆分2本合辑，清理多篇孤儿文章。
