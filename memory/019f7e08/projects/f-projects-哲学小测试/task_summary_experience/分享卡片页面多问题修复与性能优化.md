## 任务描述
修复分享卡片页面的7个问题：双重滚动卡顿、注释符号残留、标题截断、书名截取错误、导出按钮无响应、加载速度慢、以及动态调整尺寸方案。

```mermaid
    C --> D[修改ShareCardScreen:剥离注释/移除滚动容器/增加兜底查询]
    D --> E[修改ShareCardWebView:开启LOAD_DEFAULT缓存提升速度]
    E --> F[修改share_core.js:修正书名提取逻辑避免截取]
    F --> G[更新ShareTools:增加失败Toast提示]
```

## 任务总结
1. **性能与交互**：WebView改为`LOAD_DEFAULT`利用磁盘缓存；移除外层`verticalScroll`解决双重滚动卡顿；增加2.5s延迟兜底查询高度防止按钮卡死。
2. **数据清洗**：正则升级为`\[\^(\d+|\*)]|\[\d+]|\[\*]`彻底剥离各类注释标记。
3. **UI修复**：书名提取逻辑改为判断首字符是否为《，是则原样保留，否则包裹，禁止截取。
4. **反馈优化**：导出按钮根据`cardHeight`状态显示不同文案及禁用态。
