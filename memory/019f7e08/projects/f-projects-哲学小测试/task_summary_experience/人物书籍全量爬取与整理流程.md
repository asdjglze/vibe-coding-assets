## 任务描述
全量爬取马克思主义人物网站的人物书籍文章，整理目录并入库，同时区分诗集类型并跳过手工维护库人物。

## 执行过程
```mermaid
graph TD
    A[需求:全量爬取人物书籍] --> B[发现主页 URL 错误 index.htm->index.html]
    B --> C[修正 URL 并校验人物清单]
    C --> D[扩充 people.json 至 148 人 (含缺失的 90 人)]
    D --> E[增量抓取新人主页结构 probe_structure]
    E --> F[修复诗集标记逻辑 is_poetry_book]
    F --> G[添加手工库人物跳过保护 SKIP={'maozedong'}]
    G --> H[优化 crawl_books 复用主页文章避免重复下载]
    H --> I[补写 book.json 标记加速缓存识别]
    I --> J[启动 fetch_tocs/crawl_books/pdfs_scan 后台并行抓取]
    J --> K[验证头像齐全及文章总数]
```

## 任务总结
成功完成 148 人全量爬取：修正主页 URL 为 index.html，扩充人物清单至 148 人，增量抓取结构，实现诗集自动标记（正则匹配书名），添加毛泽东等手工库人物跳过保护，优化书内文章复用逻辑（复用率约 50%），补写 book.json 标记避免重复下载。最终获取 5410 篇主页文章，290 本书籍，148 个头像齐全，所有数据按人物分类落地。
