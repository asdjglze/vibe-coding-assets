## 任务描述
重构项目日志系统，实现按当前日期自动分文件、全局 print 镜像带精准定位（文件:行号:函数）、未捕获异常及业务异常完整 traceback 逐行落盘、AI 输入输出全量记录。

## 执行过程
```mermaid
graph TD
    A[需求:升级日志系统] --> B[创建 src/log.py 统一模块]
    B --> C[实现按当前日期分文件 DailyFileHandler]
    C --> D[实现 print 镜像与 LogRecord 构造]
    D --> E[调试发现 Python 3.12 extra 覆盖 filename 报错]
    E --> F[改用直接构造 LogRecord 绕过限制]
    F --> G[修复终端重复输出问题(只写文件 handler)]
    G --> H[接入 run.py 初始化 + 异常 hook]
    H --> I[修改 llm_client.py 全量记录 AI 交互]
    I --> J[批量修改 agent/web_searcher/standard 补全 log_exception]
    J --> K[编译验证 + 实际运行 dry_run 测试]
```

## 任务总结
成功构建统一日志模块：1) 日志按 logs/YYYY-MM-DD.log 自动切分；2) 所有 print 语句镜像至日志并标注调用位置；3) 主线程/子线程未捕获异常及业务异常均输出完整 traceback；4) LLM 调用全量记录输入输出。关键经验：Python 3.12+ 禁止通过 extra 参数覆盖 LogRecord 的 filename/lineno/funcName，需直接构造 LogRecord 对象处理。
