## 任务描述
恢复因华为云 WAF 风控拦截而停滞的电子书批量下载任务，修复断点续传逻辑并优化请求策略。

## 执行过程
```mermaid
graph TD
    A[发现后台进程死锁/卡死] --> B[分析日志定位根因: WAF随机挑战+断点续传失效]
    B --> C[实验验证: 浏览器正常 vs 脚本被拦, 确认WAF为概率性拦截]
    C --> D[修复classify_book: .html结尾直接判老书, 避免请求触发WAF]
    D --> E[增强fetch_legacy: 本地有效入口/XML副本优先复用]
    E --> F[优化WAF重试策略: 从25s重罚改为1s轻退避+多次重试]
    F --> G[清理受损包: 删除64个WAF脏包/半包]
    G --> H[重启进程并验证: 队列恢复正常推进]
```

## 任务总结
成功恢复下载队列。核心修复包括：1) 建立全局请求闸与WAF识别机制（检测HuaweiCloudWAF特征）；2) 修正断点续传判定逻辑（基于XML引用完整性99%阈值）；3) 优化WAF应对策略（秒级退避而非长时间惩罚）；4) 修复stdout双层包装导致的崩溃隐患。
