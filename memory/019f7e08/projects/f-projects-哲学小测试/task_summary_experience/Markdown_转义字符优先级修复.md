## 任务描述
修复 Markdown 解析器中转义字符（\[标记] 或 /[标记]）与块标记（[诗]/[题]/[抬]/[款]/[副]）的优先级冲突，确保转义行不被误识别为格式块，而是作为普通文本显示。

## 执行过程
```mermaid
graph TD
    A[需求:转义符优先级高于块标记] --> B[定义转义正则 ESCAPE_HEAD_RE]
    B --> C[App 解析器 Md.kt: 主循环最前检查转义行]
    C --> D[App 解析器: 转义行打断 [诗]/[题] 惰性延续]
    D --> E[校对工具 index.html: 同步转义检查与打断逻辑]
    E --> F[纯文本渲染点修正: WidgetCardRenderer.kt & ReadingDecor.kt]
    F --> G[验证: 转义行显示字面文本且不进入诗块]
```

## 任务总结
成功实现转义优先机制：在 App 端 (Md.kt) 和校对工具 (index.html) 中新增 `ESCAPE_HEAD_RE` 正则，将 `\[标记]` 或 `/[标记]` 行剥离转义符后作为普通正文处理；该行为会打断 [诗]/[题] 等块的惰性延续；同时在桌面组件纯文本化 (WidgetCardRenderer.kt) 和诗词兜底渲染 (ReadingDecor.kt) 中同步修正，防止误剥字面标记。验证通过：转义行正确显示为 `[诗]xxx` 文本，不渲染为居中块，且不影响正常块标记功能。
