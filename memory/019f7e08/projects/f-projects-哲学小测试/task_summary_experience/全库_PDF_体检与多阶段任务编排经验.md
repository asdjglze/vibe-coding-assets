## 任务描述
在电子书补缺项目中，对全库 PDF 进行完整性体检（空白页、坏页、WAF 假页检测），并编排多阶段自动化任务（补缺接力、批量转 PDF）。

## 执行过程
```mermaid
graph TD
    A[需求:确认 PDF 完整性] --> B[检查补缺日志分析异常]
    B --> C{发现 iframe.csv 误拦}
    C --> D[编写_fix_csv.py 手动补全]
    D --> E[启动第二批自动接力脚本_repair2.py]
    E --> F[编写_pdf_stock.py 盘点全库 PDF]
    F --> G[编写_pdfcheck.py 逐页体检]
    G --> H[体检规则:空白页 + 坏页 + 尺寸异常(WAF 假页)]
    H --> I[启动_batch_swf2pdf.py 批量 SWF 转 PDF]
    I --> J[后台并行三任务:补缺接力/体检/转换]
```

## 任务总结
成功实现全库 PDF 体检：通过低分辨率渲染检测空白页，读取异常检测坏页，**页图宽度偏离中位值 50% 以上检测 WAF 验证假页**。同时编排多阶段任务：第一批补缺完成后自动触发第二批移动版补缺，并启动后台批量 SWF 转 PDF 流程，所有任务均支持断点续传与自动跳过已完成项。
