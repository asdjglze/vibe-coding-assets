## 任务描述
批量扫描项目资源目录（如头像文件夹），识别不符合规范（如非 1:1 比例）的文件，并通过数据库查询将资源文件名映射为可读的人物中文名。

## 执行过程
```mermaid
graph TD
    A[需求：检查头像比例] --> B[定位资源目录 drawable-nodpi]
    B --> C[编写 Python 脚本扫描图片尺寸]
    C --> D[筛选出非 1:1 比例的文件列表]
    D --> E[连接 SQLite 数据库查询人物信息]
    E --> F{尝试常见字段名匹配}
    F -- 失败/无结果 --> G[查询实际存储格式 (如 avatar_xxx)]
    G --> H[修正查询条件重新映射]
    H --> I[解决终端输出乱码问题 (写文件中转)]
    I --> J[清理临时脚本与文件]
```

## 任务总结
成功识别 150 个头像中 13 个非 1:1 比例文件。在数据库查询中，发现 `avatarRes` 字段存储的是完整资源名（`avatar_xxx`）而非仅 key，需调整 SQL 查询条件；遇到终端中文乱码时，采用写入 UTF-8 临时文件的方式中转输出，确保准确获取人物中文名。
