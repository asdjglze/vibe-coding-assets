## 任务描述
将项目中所有硬编码在Python源文件中的长提示词（System Prompt, Task Template, JSON Spec等）拆分为独立的Markdown文件，存放在 `skills/` 目录下，并创建统一的提示词加载器。

## 执行过程
```mermaid
graph TD
    A[需求:提示词外部化] --> B[创建 prompt_loader.py]
    B --> C[定义 load() 函数读取 skills/<name>.md]
    C --> D[扫描各模块 recognizer.py/agent.py/standard.py 等]
    D --> E[识别硬编码字符串常量]
    E --> F[创建对应的 skills/*.md 文件]
    F --> G[修改源码替换为 _pl("name") 调用]
    G --> H[运行冒烟测试验证占位符匹配]
    H --> I[清理冗余模板和死代码]
```

## 任务总结
成功实现提示词外部化：
1. 新增 `src/prompt_loader.py`，提供 `load(name)` 接口，支持进程内缓存。
2. 在 `skills/` 目录下创建了36个 `.md` 单文件提示词，涵盖系统提示、任务模板、JSON规格等。
3. 重构了 `recognizer.py`, `agent.py`, `merger.py`, `standard.py`, `folder_judge.py`, `web_searcher.py`，移除了约500行硬编码字符串。
4. 建立了命名规范：`模块_用途.md`，共享片段通过 `{warn}` 等占位符注入。
5. 验证通过：编译检查、Import检查、模板参数匹配测试及真实AI端到端测试均通过。
