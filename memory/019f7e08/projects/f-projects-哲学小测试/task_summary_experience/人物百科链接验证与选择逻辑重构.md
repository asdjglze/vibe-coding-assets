## 任务描述
为哲学小测试 App 实现人物百科链接批量验证与补全，同时优化人物选择逻辑：支持语料扩充后自动补选新增人物，并将无语录/文章内容的「预备役」人物从展示列表中过滤。

## 执行过程
```mermaid
graph TD
    A[需求:补全百科链接 & 优化人物逻辑] --> B[编写 Python 脚本批量验证 61 人词条]
    B --> C{SSL 握手失败}
    C -->|是 | D[添加 ssl.create_default_context 并降级加密]
    D --> E[重试脚本验证]
    E --> F[发现部分词条不存在]
    F --> G[使用 WebSearch 并行查询确认正确词条名]
    G --> H[整理最终百科 URL 映射表]
    
    I[需求:默认全选 & 语料扩充兼容] --> J[修改 PersonSelectionStore 数据结构]
    J --> K[新增 KEY_ALL_IDS 存储当时全量人物 ID]
    K --> L[loadSelectedIds 逻辑改为: 已存选中 + 新增 ID 自动补选]
    L --> M[更新 Repository 与 ViewModel 调用签名]
    
    N[需求:过滤无内容人物] --> O[PersonDao 新增 findContentPersonIds 查询]
    O --> P[PersonSelectionRepository.getAllPersons 增加内容 ID 过滤]
    P --> Q[同步更新 DailyRepository 与 UI 层调用]
```

## 任务总结
1. **百科链接**: 修复 SSL 握手问题，通过 WebSearch 批量验证并修正了阿尔都塞、季诺维也夫等 10+ 个词条名称，生成最终 URL 映射。
2. **全选逻辑**: 采用「保存全量 ID + 增量补选」策略，确保语料库扩充后新增人物自动进入默认选中池，旧用户数据平滑兼容。
3. **预备役过滤**: 通过 `UNION SELECT` 查询语录与文章表获取有效人物 ID，在 Repository 层统一过滤，确保书架、选择页、每日推荐均不展示无内容人物。
