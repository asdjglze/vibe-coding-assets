## 任务描述
在阅读设置中添加“翻页阅读”模式，适配墨水屏低刷设备。

## 关键执行点
1. **设置持久化**：在 `ReaderSettings` 添加 `pagingMode` 字段并接入 SharedPreferences。
2. **渲染器重构**：新建 `PagedReaderBodies.kt`，使用 `TextMeasurer` 进行行级测量和贪心装箱分页。
3. **交互适配**：点击左右区翻页，无动画直切；进度记录改为页号百分比。
4. **避坑指南**：
   - Compose 1.12.0 中 `AnnotatedString` 无双参数 `substring`，需改用 `subSequence`。
   - `sumOf` 存在 Int/UInt 重载歧义，需改用 `fold` 显式累加。
   - 注意 `TextRange` 与 `IntRange` 的类型差异。

## 任务总结
实现了滚动与翻页双模式切换，仅在设置页生效。翻页模式下内容超视口自动分页，点击热区翻页，适合墨水屏。
