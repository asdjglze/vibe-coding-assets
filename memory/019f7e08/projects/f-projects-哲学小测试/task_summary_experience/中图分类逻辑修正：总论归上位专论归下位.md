## 任务描述
修正中图分类归档逻辑：废除"强制下钻至第四层"的错误规则，改为遵循"总论归上位，专论归下位"原则，允许书籍根据论述范围停在任意层级。

## 执行过程
```mermaid
graph TD
    A[用户质疑:为何TU242下还有子类目却要求停四层] --> B[WebSearch研究中图法官方规则]
    B --> C[结论:类级控制在4级左右是上限，非强制下限;泛论书应停上位类]
    C --> D[定位 agent.py 提示词与校验逻辑]
    D --> E[修改提示词:强调"scope=general"声明泛论]
    E --> F[重构_check_final_clc校验函数:接受>=3层或泛论声明]
    F --> G[更新人工建议文案:移除"必须下钻到第四层"硬编码]
    G --> H[Bash测试新逻辑覆盖泛论/专论场景]
```

## 任务总结
成功修复分类逻辑：
1. 提示词新增"总论归上位，专论归下位"规则，支持AI输出{"scope": "general"}声明泛论。
2. _check_final_clc校验逻辑调整为：路径>=3层直接OK；<3层但声明泛论或confidence=low则放行；否则重试。
3. 人工建议文案更新为引导用户判断"专论"还是"泛论"，不再强制下钻。
4. 实测验证：泛论书可停在TU242(三层)，专论书可下钻至TU242.3(六层)。
