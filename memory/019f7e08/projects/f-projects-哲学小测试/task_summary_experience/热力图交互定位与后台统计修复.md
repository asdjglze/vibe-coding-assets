## 任务描述
修复阅读热力图点击识别不准、悬浮窗位置偏移以及后台时长统计不准确的问题。

## 执行过程
```mermaid
graph TD
    A[需求:修复热力图交互与统计] --> B[定位 StatsCharts 点击坐标计算逻辑]
    B --> C[发现行列尺寸未独立计算导致错位]
    C --> D[修正 cellW/cellH 计算公式]
    D --> E[定位 ChartTip 悬浮窗定位逻辑]
    E --> F[发现叠加了容器窗口位置导致越界]
    F --> G[移除 windowPos 参数，直接使用图表局部坐标]
    G --> H[定位 ReaderScreen 后台计时逻辑]
    H --> I[添加 LifecycleEventObserver 监听前台/后台切换]
    I --> J[实现 onForeground/onBackground 结算会话时长]
    J --> K[编译验证修复效果]
```

## 任务总结
修复三个关键 Bug：1. 热力图点击区域错位：修正行列宽高独立计算逻辑；2. 悬浮窗乱飞：移除错误的窗口位置叠加，改用相对父容器的局部坐标并收敛范围；3. 时长统计不准：在 ReaderScreen 中添加 LifecycleObserver，在应用切后台时自动结算会话时长，确保数据完整性。
