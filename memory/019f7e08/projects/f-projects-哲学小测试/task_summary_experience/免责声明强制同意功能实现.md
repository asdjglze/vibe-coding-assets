## 任务描述
为应用启动页添加免责声明强制同意机制，并扩写核心理念文案。

## 执行过程
```mermaid
graph TD
    A[需求：首次进入需点击同意按钮，后续自动跳过] --> B[设计持久化层：新建 DisclaimerStore 封装 SharedPreferences]
    B --> C[注册单例：在 QuoteApplication 中懒加载实例]
    C --> D[修改启动逻辑：MainActivity 读取标记判断是否展示按钮]
    D --> E[重构 UI：DisclaimerLoadingPage 支持 accepted 参数区分状态]
    E --> F[扩写文案：增加版本差异、历史背景、独立思考等理念内容]
    F --> G[优化布局：标题固定顶部，正文可滚动，底部按钮交互]
```

## 任务总结
实现免责声明的强制同意流程：首次安装显示「同意并进入」按钮，点击后调用 `markAccepted()` 落盘至 SharedPreferences；后续启动自动检测标记，若已同意则仅展示加载提示并自动跳转。同时丰富了文案，强调「一字之差，义理万别」及独立思考的核心理念，提升用户认知。
