## 任务描述
实现人物选择功能的「默认全选 + 语料扩充自动补选」机制，过滤无内容人物（预备役），并完成60位历史人物的百度百科链接映射。

## 执行过程
```mermaid
graph TD
    A[需求:优化人物选择逻辑] --> B[PersonSelectionStore: 新增KEY_ALL_IDS记录全量人物]
    B --> C[loadSelectedIds: 对比新旧ID集合，自动补选新增人物]
    C --> D[PersonDao: 新增findContentPersonIds查询有内容人物]
    D --> E[Repository: getAllPersons/filter 过滤无内容及编者人物]
    E --> F[DailyRepository/BookshelfViewModel: 统一调用过滤后列表]
    F --> G[HomeScreen: 构建BAIKE_ENTRIES映射表 (词条名+ID)]
    G --> H[baikeUrlOf: 动态编码拼出跳转链接]
    H --> I[编译验证: 修复导入并确认BUILD SUCCESSFUL]
```

## 任务总结
成功改造人物选择持久化逻辑：保存时记录当时全量人物主键，读取时自动补选语料库扩充的新增人物；在Repository层统一过滤无内容人物（仅保留语录/文章/诗词）；重构首页百科链接为「词条名+ID」结构，通过Uri.encode动态生成URL，完成60位人物映射并编译通过。
