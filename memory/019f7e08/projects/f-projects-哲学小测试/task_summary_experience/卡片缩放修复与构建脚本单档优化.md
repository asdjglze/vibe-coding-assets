## 任务描述
修复 MaoYulu 项目中分享卡片被错误缩放成点的显示问题，并优化构建脚本以支持单档打包且不覆盖其他档位。

## 执行过程
```mermaid
graph TD
    A[需求:修复卡片缩放异常] --> B[搜索 ShareCardScreen.kt 确认外部无缩放]
    B --> C[定位问题:外部 min(cardHeight, maxHeight) 压扁 WebView]
    C --> D[修改逻辑:移除高度封顶，改用自然高度 + 外层 verticalScroll]
    D --> E[补充 import:rememberScrollState 和 verticalScroll]
    E --> F[需求追加:构建脚本支持单档打包]
    F --> G[读取 build_pack.ps1 发现单档模式误删所有旧包]
    G --> H[修改清理逻辑:all 模式全删，单档模式仅删对应档]
    H --> I[执行 -Tier mini 验证单档构建]
```

## 任务总结
成功修复卡片显示：Kotlin 侧移除高度封顶限制，启用外层滚动，内部仅做宽度微缩；优化 build_pack.ps1 脚本，新增 `-Tier` 参数支持单档构建，且单档模式下仅清理对应档位的 APK，保留其他档位产物。
