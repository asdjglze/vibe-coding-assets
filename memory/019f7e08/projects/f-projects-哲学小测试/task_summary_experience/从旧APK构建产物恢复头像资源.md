## 任务描述
用户在处理头像图片时误覆盖了原始版本，需要从项目中恢复这些手工处理过的头像。

## 执行过程
```mermaid
graph TD
    A[需求:恢复被覆盖的头像] --> B[检查 Git 历史/备份目录]
    B --> C[发现无 Git 仓库且无直接备份]
    C --> D[搜索全项目寻找旧 APK 构建产物]
    D --> E[定位 app-debug.apk (16:25 编译)]
    E --> F[解压 APK 提取 drawable-nodpi 下的头像]
    F --> G[对比新旧文件 MD5 确认用户版]
    G --> H[批量复制回 src/main/res/drawable-nodpi]
    H --> I[清理同名冲突文件]
```

## 任务总结
成功从旧 APK 构建产物中提取并恢复了 60 个头像（10 个 png + 50 个 jpg），解决了因误操作导致的资源丢失问题。
