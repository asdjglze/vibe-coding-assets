## 任务描述
整理 Android 项目 drawable-nodpi 目录中的头像资源，解决文件名乱码、非 1:1 比例及数据库引用不一致问题。

## 执行过程
```mermaid
graph TD
    A[需求:整理头像资源] --> B[查询 DB person 表字段]
    B --> C[发现 avatarRes 存储格式为 avatar_xxx]
    C --> D[尝试直接查询发现控制台乱码]
    D --> E[编写 Python 脚本读取 DB 并写入 UTF-8 文件]
    E --> F[列出目录文件，发现 (1) 副本均为 1:1 新图]
    F --> G[编写脚本：删除旧非 1:1 文件 + 重命名 (1) 副本]
    G --> H[执行重命名并生成日志]
    H --> I[编写最终校验脚本：检查比例/残留/DB 一致性]
    I --> J[清理所有临时脚本]
```

## 任务总结
成功将 13 张非 1:1 头像替换为 1:1 版本，通过 Python 脚本解决 Windows 控制台 GBK 乱码导致的文件名解析问题，利用 `(1)` 后缀副本作为新图来源，实现了文件名标准化、比例统一及 DB 引用一致性校验。
