## 任务描述
修复分享卡片导出图片模糊及WebView双重滚动卡顿问题。用户反馈导出分辨率仅320px导致手机显示模糊，且超高卡片因外层滚动导致WebView纹理超限降采样和事件抢夺。

## 执行过程
```mermaid
graph TD
    A[问题:导出图片模糊/双重滚动卡顿] --> B[分析原因:画布1:1渲染 vs 手机高PPI屏]
    B --> C[修改share_core.js:引入3x超采样(scale=3)]
    C --> D[调整SVG尺寸与transform:scale(3)容器]
    D --> E[修改ShareCardScreen.kt:移除外层滚动,WebView填充满视口]
    E --> F[修改ShareCardWebView.kt:启用内部滚动,isScrollContainer=true]
    F --> G[编译验证:Gradle构建通过]
    G --> H[浏览器实测:验证导出尺寸960px及滚动流畅度]
```

## 任务总结
成功解决导出模糊与卡顿：
1. JS层实现3x超采样，将320px基准扩展至960px宽度，确保高清输出；
2. Kotlin层重构布局，WebView高度固定为视口高度，禁用外层滚动，改为WebView内部单一滚动源，避免GPU纹理超限降采样及事件冲突。
