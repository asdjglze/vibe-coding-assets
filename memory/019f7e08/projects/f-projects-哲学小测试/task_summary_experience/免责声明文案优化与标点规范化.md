## 任务描述
在 Android 应用（Kotlin）的免责声明页面中，新增“软件著者按”区块，修正关于文本处理的表述，并将所有文案中的破折号替换为冒号或逗号。

## 执行过程
```mermaid
graph TD
    A[需求:修改免责声明文案] --> B[确认当前文件状态及已删内容]
    B --> C[在正文区开头插入'软件著者按'区块及说明文字]
    C --> D[用户反馈修正'校对'表述为'软件层面校正']
    D --> E[SearchReplace 修改文案，明确校正范围(格式/序号/标点)]
    E --> F[Grep 搜索全文含破折号的文案及注释]
    F --> G[逐一替换4处破折号为冒号或逗号]
    G --> H[Gradle 编译验证代码无错误]
```

## 任务总结
成功实现免责声明优化：新增“软件著者按”区块，明确文本处理仅为“软件层面的校正”（格式、数据库、序号、标点），未涉及内容校对；将文中所有破折号统一替换为冒号或调整句式，确保语义通顺；编译通过，准备打包。
