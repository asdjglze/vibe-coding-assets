## 任务描述
修复应用设置自定义字体后，阅读页加粗、斜体及标题粗细全部失效的问题。

## 执行过程
```mermaid
graph TD
    A[用户反馈：设置字体后加粗/斜体失效] --> B[排查渲染链路：MdBody.kt & PagedReaderBodies.kt]
    B --> C[定位根因：FontManager.fontFamily() 使用 FontFamily(typeface)]
    C --> D[分析原因：Typeface 构造方式不区分字重，不做合成加粗/斜体]
    D --> E[对比默认路径：assets 分支使用 FontFamily(Font(...)) 正常合成]
    E --> F[实施修复：将 files/fonts/ 分支也改为 FontFamily(Font(file))]
    F --> G[清理无用 import：移除 android.graphics.Typeface]
    G --> H[验证编译通过并测试效果恢复]
```

## 任务总结
成功修复自定义字体下所有字重样式失效问题。核心在于 Android Compose 中 `FontFamily(Typeface)` 会忽略字重请求，必须改用 `FontFamily(Font(file))` 或 `Font(path)` 构造，才能触发 Compose 的合成加粗/斜体机制。修复后标题、**加粗**、*斜体*及半粗称谓均恢复正常显示。
