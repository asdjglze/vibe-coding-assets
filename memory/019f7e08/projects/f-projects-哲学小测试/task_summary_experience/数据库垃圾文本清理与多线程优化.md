## 任务描述
清理 quote.db 数据库中残留的面包屑、导航链接及下载信息等垃圾文本。

## 执行过程
```mermaid
graph TD
    A[需求:清理数据库垃圾文本] --> B[运行_finalize.py恢复主库]
    B --> C[编写_verify2.py单线程扫描验证]
    C --> D[发现扫描耗时过长(67s)]
    D --> E[重构为_verify3.py多线程(8线程)分片扫描]
    E --> F[定位到5篇含'下载信息'残留的文章]
    F --> G[编写_fix_leftover.py批量删除垃圾行]
    G --> H[发现article 4804整行删除导致标题丢失]
    H --> I[利用备份库_diag_copy.db还原上下文进行修复]
```

## 任务总结
成功清理所有面包屑/页头/分页导航残留；针对下载信息残留，通过多线程加速验证并精准修复5篇文章；解决了正则匹配整行删除导致的标题丢失问题，建立了利用备份库快速回滚/修复的机制。
