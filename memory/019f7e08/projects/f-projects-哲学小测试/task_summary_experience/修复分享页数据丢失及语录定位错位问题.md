## 任务描述
修复三个关键Bug：1. 分享页无法显示头像/名字（JSON数据未传递）；2. 点击语录卡片进入后定位错误；3. 全文搜索高亮样式需改为区分当前项与其余项，且移除整段背景。

## 执行过程
```mermaid
graph TD
    A[需求:修复分享页/定位/搜索高亮] --> B[分析ShareBridge字节码]
    B --> C[发现getData()属性getter与@JavascriptInterface方法冲突]
    C --> D[修改ShareCardWebView.kt: 属性改名+onPageFinished主动推送JSON]
    D --> E[修改share_core.js: 增加maoyuluSetData接收双保险]
    E --> F[重构selectAutoRange: 返回匹配块文本与比例]
    F --> G[修改ReaderScreen.kt: 语录定位改用真选区结果映射回doc空间]
    G --> H[修改MdBody.kt/PagedReaderBodies.kt: 移除整块背景, 引入hitRole双色高亮]
```

## 任务总结
1. **分享页修复**：消除ShareBridge的`getData()`方法冲突，通过原生主动推送JSON实现双保险数据传递。
2. **定位修复**：统一语录定位与选区匹配的文本空间，根据选区在匹配块内的比例计算滚动目标，解决“选中正确但定位错误”问题。
3. **高亮优化**：移除搜索整块背景，实现文内搜索双色高亮（当前项深色+强调色文字，其余项淡色背景），提升用户识别效率。
