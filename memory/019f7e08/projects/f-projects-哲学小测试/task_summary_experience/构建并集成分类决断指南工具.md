## 任务描述
为解决图书分类中哲学/宗教/文学等边界模糊导致的决策困难，构建本地《分类决断指南》并集成至Agent工具链，使AI在两可时能按需检索裁决规则。

## 执行过程
```mermaid
graph TD
    A[需求:解决模糊分类决策] --> B[搜集官方中图法说明及馆级业务规范]
    B --> C[提炼归类总则/多主题裁决次序/体裁优先规则]
    C --> D[编写resources/classify_guide.md方法论手册]
    D --> E[在agent.py实现_guide_sections/_guide_tool函数]
    E --> F[将guide注册入_TOOLS_FNS字典]
    F --> G[更新skills/agent_system.md提示词告知AI使用指南]
    G --> H[全链路Mock测试验证工具调用与分类归档]
```

## 任务总结
成功创建包含16节方法论的分类决断指南，实现了支持关键词检索和目录浏览的`guide`工具，并将其无缝集成到Agent系统中。测试表明AI可在遇到两可问题时通过`guide`获取裁决依据，显著提升了分类准确率。
