## 任务描述
扩充人物清单至 148 人，批量爬取所有人物主页及书籍文章，区分诗集类型并标记，同时适配 App 端搜索逻辑。

## 执行过程
```mermaid
graph TD
    A[需求:批量爬取人物书籍] --> B[检查现有进程与人物清单]
    B --> C[发现主页 URL 为 index.html 而非 index.htm]
    C --> D[修正_fetch_home_people.py 中的 URL 后缀]
    D --> E[执行_expand_people.py 扩充人物列表至 148 人]
    E --> F[修改 probe_structure.py 支持增量抓取结构]
    F --> G[修复旧人物结构被覆盖的 Bug]
    G --> H[在 rebuild_catalog.py 中增加诗集判定逻辑 (POETRY_RX)]
    H --> I[调整 book.kind 保持 article，仅文章/toc 标记 poem]
    I --> J[修改 App 端 ArticleDao 与 BookshelfRepository 支持诗词搜索]
    J --> K[配置限流参数 (max_workers=2, interval=1.5) 防止封禁]
    K --> L[启动 crawl_new.py 后台增量抓取]
```

## 任务总结
成功将人物库从 58 人扩充至 148 人，实现增量抓取机制避免重复下载；通过正则 `POETRY_RX` 自动识别诗集并将文章类别标记为 `poem`，同时修正数据库 schema 兼容逻辑；App 端搜索功能扩展至支持诗词检索；全程采用限流策略保障爬虫稳定性。
