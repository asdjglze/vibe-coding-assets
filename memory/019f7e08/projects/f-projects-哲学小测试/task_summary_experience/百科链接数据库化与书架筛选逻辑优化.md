## 任务描述
将人物百科链接从代码硬编码迁移至数据库，并优化书架筛选逻辑：仅当人物拥有书籍、语录或诗词时，才在书架筛选栏中显示（仅有文章的人物不显示）。

## 执行过程
```mermaid
graph TD
    A[需求：百科链接去硬编码 + 书架筛选优化] --> B[编写 Python 脚本填充 person.baikeUrl 字段]
    B --> C[验证数据完整性：60 人填充成功]
    C --> D[修改 Person 实体添加 baikeUrl 列]
    D --> E[调整 AppDatabase version 为 7]
    E --> F[发现 Room 预打包库 user_version 陷阱]
    F --> G[执行 user_version=0 策略触发 onCreate 重建 hash]
    G --> H[移除 HomeScreen.kt 硬编码映射]
    H --> I[重构 BookshelfRepository 筛选逻辑]
    I --> J[SQL 条件：personId IN book OR quote OR poem AND NOT article-only]
    J --> K[编译验证通过]
```

## 任务总结
成功将 60 位人物的百科链接存入数据库，移除代码硬编码。针对 Room 预打包数据库，采用 `user_version=0` 策略避免 schema hash 校验失败导致崩溃。书架筛选逻辑修正为：仅当人物存在书籍、语录或诗词记录时进入筛选栏，彻底过滤仅有文章的冗余人员。
