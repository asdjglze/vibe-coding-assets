## 任务描述
解决批量 SWF 转 PDF 过程中，因本地渲染服务器端口未正确释放导致的后续任务连接超时/被拒问题，并修复已损坏的 PDF 文件。

## 执行过程
```mermaid
graph TD
    A[用户反馈:某书 PDF 首页缺失] --> B[诊断:检查文件头/日志/PDF 页数]
    B --> C[定位:前 N 页渲染全部失败/超时]
    C --> D[根因分析:查看 swf转pdf.py 源码]
    D --> E[发现:srv.shutdown() 后缺 server_close(), 端口残留]
    E --> F[修复代码:禁止端口复用 + 开工自检 + 彻底释放]
    F --> G[编写重转脚本:预处理空白页 + 旧 PDF 改名备份]
    G --> H[启动重转:验证新任务成功渲染失败页]
```

## 任务总结
成功定位并修复了 SWF 转 PDF 工具的严重 Bug：原代码在关闭本地 HTTP 服务器时仅调用 shutdown() 未释放 socket，导致 Windows 下端口复用冲突，引发后续书籍渲染全失败。修复方案包括设置 allow_reuse_address=False、增加服务器可用性自检、以及关闭时显式调用 server_close()。同时执行了全队列重转策略，自动保留旧版 PDF 并补渲缺失页面，确保所有书籍数据完整。
