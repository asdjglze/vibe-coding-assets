## 任务描述
解决马克思主义文库数据同步中重复下载文章的问题，将匹配策略从"按文件名"升级为"按标题"，实现数据库、主页数据、书数据的分级复用。

```mermaid
    B --> C[编写_title_match.py抽样统计]
    C --> D[确认复用率约6%但方向正确]
    D --> E[停止旧的低效补缺进程]
    E --> F[开发fetch_tocs.py抓取目录页获取标题+href]
    F --> G[重构rebuild_catalog.py核心逻辑]
    G --> H[新增resolve函数:DB同标题→主页同标题→书同href→下载]
    H --> I[修复plan元组解包错误导致的崩溃]
    I --> J[配置限速参数(2线程/2.5秒间隔)防止限流]
```

## 任务总结
成功实施标题优先匹配策略：在 rebuild_catalog.py 中新增 resolve 函数，按"数据库同标题→主页数据同标题→书数据同 href→下载"顺序查找文章；新增 fetch_tocs.py 抓取目录页解析章节标题；配置低并发参数防止触发网站限流，彻底解决重复下载问题。
