## 任务描述
优化中图分类归档逻辑：解决AI钻取层级控制不当（死循环或过早停止）及目录结构混乱（泛论书与子分类混放）的问题。

## 执行过程
```mermaid
graph TD
    A[需求:优化中图分类归档] --> B[修改agent.py提示词]
    B --> C[明确'尽量第四层'与'叶子自动退出'规则]
    C --> D[实现叶子节点检测逻辑:无子类目直接final]
    D --> E[修改organizer.py归档路径]
    E --> F[在分类层与作者桶间插入'[本层书籍]'文件夹]
    F --> G[验证标记冲突:确保[本层书籍]不被误识别]
```

## 任务总结
1. **Agent逻辑**：在 `agent.py` 中强化提示词，规定默认目标为第四层，并添加代码逻辑：若当前类目无子类目，直接返回 final 指令，避免无效交互。
2. **目录结构**：在 `organizer.py` 中，所有停在当前层的书籍统一归入 `[本层书籍]` 文件夹。这使得分类目录下仅存在“带类号的子分类文件夹”和“[本层书籍]”，实现了视觉上的清晰隔离。
3. **兼容性**：验证确认 `[本层书籍]` 不会触发现有的特殊文件夹标记逻辑。
