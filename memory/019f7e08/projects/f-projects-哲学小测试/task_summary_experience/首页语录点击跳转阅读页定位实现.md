## 任务描述
实现从首页语录卡片点击进入阅读页后，自动跳转到原文中对应语录所在的段落。

## 执行过程
```mermaid
graph TD
    A[需求:语录点击跳转定位] --> B[修改HomeScreen携带语录文本]
    B --> C[MainActivity维护readerJumpText状态并传递给ReaderScreen]
    C --> D[ReaderViewModel.load接收jumpText并清洗注码]
    D --> E[正文加载后三级匹配(完整/首句/指纹)定位块下标]
    E --> F[MdBody为段落/引用块记录y坐标]
    F --> G[ReaderScreen LaunchedEffect等待加载完成并滚动]
    G --> H[添加门闩机制防止字体重排导致反复拉回]
```

## 任务总结
成功实现语录跳转：
1. **数据流**：HomeScreen -> MainActivity -> ReaderViewModel -> ReaderScreen。
2. **匹配算法**：在ReaderViewModel中实现normalizeForMatch清洗注码，采用完整包含->首句->前6字指纹的三级降级匹配策略。
3. **定位逻辑**：MdBody记录块坐标，ReaderScreen在isLoading=false且maxValue>0时执行滚动，目标位置设为视口上部22%处。
4. **稳定性**：引入jumpExecuted计数器和lastJumpTarget比对，防止字体替换重排触发effect重启导致的死循环或干扰用户手动滚动。
