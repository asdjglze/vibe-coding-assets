## 任务描述
优化「阿虚收藏夹制作」工具的用户提示信息，解决三大认知问题：1）主菜单中‘支持阿虚同学’表述空泛；2）备用链接标记被书签栏截断导致误判重复；3）默认输出路径未明示引发用户困惑。

## 执行过程
```mermaid
graph TD
    A[需求:提升用户认知清晰度] --> B[分析主菜单免责声明区]
    B --> C[将空洞支持话术重构为三段式：身份介绍+具体动作+原站链接]
    C --> D[定位备用链接生成逻辑 _extract_urls / backup_line]
    D --> E[将[备用A]后缀改为【备用A】前缀，多备选自动编号]
    E --> F[搜索默认路径逻辑 desktop = os.path.join...]
    F --> G[在主菜单[1]选项旁和生成流程起始处双位置添加默认路径提示]
    G --> H[全部通过py_compile语法验证]
```

## 任务总结
完成三项关键UI提示优化：主菜单新增「关于阿虚同学」模块并给出公众号关注、点赞/在看/转发等具体支持方式；备用链接统一前置【备用】标记，避免书签栏截断丢失标识；主菜单选项[1]和生成流程起始处同步明示默认保存路径为“桌面\\阿虚同学书签\\”，显著降低用户理解成本。
