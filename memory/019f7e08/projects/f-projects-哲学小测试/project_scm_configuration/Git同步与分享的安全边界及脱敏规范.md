项目级配置（如 `.qoder/rules`、`.agents`、`.codex/skills`）在 Git 同步或分享时，必须严格限制范围：
1. **他人提供的 Skill**：仅保留来源链接，不上传源码，以便换设备重装或更新。
2. **自研内容**：包括自定义规则、人格文件（Personas）、自写 Skill 代码，需全量上传。
3. **安全要求**：所有同步和分享的文件必须经过脱敏处理，严禁包含个人敏感信息（如账号、IP、路径等）。
