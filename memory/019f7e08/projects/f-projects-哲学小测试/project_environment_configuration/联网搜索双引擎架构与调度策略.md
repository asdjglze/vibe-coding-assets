联网搜索服务采用双引擎架构：豆包搜索作为主力引擎提供高质量结果，SearXNG自建实例作为兜底引擎无配额限制。已移除Tavily搜索及正文提取功能。调度逻辑为优先调用豆包搜索，当豆包失败或不可用时自动回退至SearXNG。
