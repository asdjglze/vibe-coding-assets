跨系统文件名健壮性编码:
- **字符闸门**: Windows禁符转下划线，控制符转空格，剥除尾点/空格，保留设备名加前缀；Emoji/生僻字经NFKC转换后切除，确保GBK兼容。
- **长度预算**: 单段名上限47字符（适配群晖加密共享），总路径上限236字符，防止长路径错误。
- **全角策略**: 库内显示用全角冒号「：」，磁盘文件名统一使用半角符号（建议斜杠统一为全角／以兼容旧档）。
