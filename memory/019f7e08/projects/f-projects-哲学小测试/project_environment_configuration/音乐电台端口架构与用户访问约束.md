音乐电台部署在服务器SERVER-IP：后端 music-radio 由 systemd 托管（监听25800端口），nginx music_radio.conf（5001端口）反代已指向25800，5001已恢复访问。用户明确要求：不要动nginx反代配置；用户通过IP+端口访问服务，域名未备案，不要查看或修改域名相关配置。
