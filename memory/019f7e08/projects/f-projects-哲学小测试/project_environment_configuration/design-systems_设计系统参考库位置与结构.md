F:\projects\哲学小测试\server\data\design-systems 是设计系统参考库，含 160+ 风格目录（brutalism、editorial、minimal、luxury、gradient、glassmorphism、flat、retro、neobrutalism、kami 等），每目录有 DESIGN.md（视觉气质、色板 token、字体族），kami 与 default 另有 tokens.css 机器可读 token。做 UI 设计或风格 demo 时优先从这里取 token 与风格方向，用户要求避免单一拟物风。
