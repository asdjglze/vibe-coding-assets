Ollama是无状态API，无自带记忆，上下文必须由程序控制拼接：1. Token预算控制（如12000，超限先压缩再发，永不触发服务端截断）；2. 分层窗口策略（最近N轮完整保留，旧轮折叠进事实清单）；3. 超长工具结果自动压缩（使用独立LLM调用进行压缩，不占用Agent主流程轮数）。
