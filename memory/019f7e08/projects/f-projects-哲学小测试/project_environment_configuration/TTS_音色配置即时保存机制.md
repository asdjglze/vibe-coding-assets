TTS 音色配置保存机制存在严重缺陷：原实现依赖 3 分钟无操作定时器自动提交，用户选完音色后若未等待超时即关闭设置面板或切换页面，配置将永久丢失（数据库 tts_speaker 字段为 None）。修复方案：1. 音色选择后立即调用 saveAllPending() 落库；2. 主页面关闭设置面板时通过 postMessage 通知子页面立即保存；3. 检测到音色无效自动回退默认时也立即保存。核心原则：关键配置不能依赖延迟定时器，必须确保用户操作闭环内完成落库。
