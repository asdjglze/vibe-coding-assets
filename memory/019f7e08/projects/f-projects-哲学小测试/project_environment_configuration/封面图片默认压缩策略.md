项目封面加载策略：后端 `/api/cover/<id>` 接口默认返回 800px 缩略图而非原图（`size=0` 或空时返回原图）；前端优先使用 `coverUrl800` 字段，兼容旧字段 `coverUrl300`，缺失时自动补 `size=800` 参数兜底；点击封面弹出毛玻璃弹窗显示原图（size=0），关闭时释放大图内存。
