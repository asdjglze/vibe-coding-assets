数据库中的书名与磁盘文件名采用分层策略：
- **库书名**：无文件系统字符限制，保留原始元数据（如全角斜杠、特殊符号），用于展示和检索。
- **磁盘文件名**：经过 `name_sanitize` 健壮性编码（GBK兼容、长度预算、禁符替换），确保跨平台（Win/Linux/群晖）兼容性。
