文逊图书 opds-web 前端现行版本只存在于服务器 SERVER-IP:51837（目录 /www/wwwroot/opds-web），本地 opds_nas/web/src 是旧版（缺 GuideView/music/login/党政学习支持），服务器上也没有源码。用户明确要求：修改该前端时，从服务器拉取需改的产物 → 修改 → 上传回服务器，不要试图从别处找源码重建。改版注意：/assets/* 有 30 天强缓存，修改过的文件必须换新文件名并把 index.html、入口包及全部 chunk 之间的互相引用同步改掉（所有 chunk 必须指向同一入口文件名，否则会加载第二份入口包导致 Vue 双实例、生命周期钩子失效）。
