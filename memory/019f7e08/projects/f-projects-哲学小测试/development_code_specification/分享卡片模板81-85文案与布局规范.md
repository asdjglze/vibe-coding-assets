分享卡片模板81-85文案规范:
1. 文章标题位: hm-royal(爱马仕)、ibm-sub上方区块(IBM)、mm-mark(MOMA)、mit-meta(MIT)均写文章标题，需加 `data-fit-title` 控制字号防溢出。
2. 出处行(hm-sub/ab-sub/mm-sub/mit-sub): 统一格式为「— 作者 · 《书名》」或「— 作者 · 《书名》 · 出版年份」。
3. 节选文案(ibm-source/hm-source/ab-source/mm-source/mit-source): 统一使用外语表达「Excerpt shared in [当前年]」。
4. 装饰元素: 爱马仕hm-no和appName删除；爱彼迎ab-belo改为白色毛体思「思」字；其余保留原logo。
