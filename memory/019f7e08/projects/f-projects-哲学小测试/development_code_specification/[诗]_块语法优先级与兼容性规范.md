Markdown 块级标签 `[诗]` 的优先级与兼容性规范：
1. 优先级：转义符优先级高于块识别，若破坏结构则视为错误文本直接显示
2. 行内语法隔离：块内 spans 走标准 parseInline，加粗/斜体/删除线/下划线/链接/脚注等必须照常解析渲染，不因居中而失效
3. 打断机制：[诗] 块与 [副]/[题]/[抬]/[款]/脚注定义行双向打断，确保结构清晰
