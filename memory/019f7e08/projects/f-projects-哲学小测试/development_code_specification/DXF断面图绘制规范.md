DXF/CAD 挡土墙断面示意图绘制规范:
- 几何定义: 总高 H = h1(墙身) + h2(基础) + h3(垫层)，垫层底面在 y=H；墙身 0~h1、基础 h1~h1+h2、垫层 h1+h2~H
- Y轴方向: 自然地坪在顶部，向下为深度（需做Y轴翻转映射）
- 包含内容: 浆砌片石墙身、基础、砂砾垫层
- 排除内容: 沟槽开挖线、台背回填条带、反滤层等土方相关内容
