气象类分享模板的正文使用 data-flat 扁平模式（share_core.js fillTextContext 支持）：pre+text+post 拼接为完整一段文本（不切 ctx-pre/sel/post 三段、无渐隐），模板 quote 容器 text-align:left 左对齐、align-items:flex-start。用户明确拒绝三段式与居中对齐的正文效果。
