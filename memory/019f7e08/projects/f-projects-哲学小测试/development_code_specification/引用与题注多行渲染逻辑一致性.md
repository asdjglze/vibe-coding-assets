markdown-it（CommonMark）引用块的多行逻辑是惰性延续：首行 `>` 前缀，后续连续非空行无需前缀自动并入同一 `<blockquote><p>`，遇空行结束。自研标记 `[题]` 题记的多行逻辑必须与引用完全一致：首行 `[题]` 前缀，后续连续非空行自动并入（兼容旧格式每行带 `[题]` 时剥离前缀），空行结束；`[副]`/`[抬]`/`[款]` 标记行与脚注定义行 `[^N]:` 会打断题记。两端（校对工具 renderMd 与 App Md.kt parse）需同步保持此行为，修改后须实测对照引用的渲染结构验证。
