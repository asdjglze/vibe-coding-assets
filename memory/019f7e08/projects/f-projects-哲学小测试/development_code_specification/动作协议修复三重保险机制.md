动作协议修复采用三重保险机制：1. 提示词严格约束（每轮只输出一个JSON对象、禁止额外内容）；2. 统一单一格式（全部使用args嵌套，消除顶层code写法）；3. 代码双读兜底（同时读取顶层字段和args并合并）。
