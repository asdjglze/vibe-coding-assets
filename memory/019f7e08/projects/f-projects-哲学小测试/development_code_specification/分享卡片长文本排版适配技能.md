分享卡片长文本排版适配：1.独占整行元素跳过字号缩放，仅inline-block保留兜底；2.大字体标题增加正文参考字号下限（无正文退14px），缩至接近正文仍放不下两行时放弃缩放、按当前字号暴力换行，永不跌破正文；3.组合行成员跳过单独缩小，flex容器自动补wrap实现整体换行；4.验证测试覆盖超长数据场景。核心原则：区分独占整行、标题缩放、组合行语义，标题字号不低于正文。
