---
title: "App内禁用emoji与静态截图文案规范"
usage_scenario:
    - "编写App内UI文案或图标时"
    - "生成分享卡片文案与符号时"
keywords:
    - "emoji禁用"
    - "跨设备一致性"
    - "已收藏"
    - "截图感"
---

App 内 UI（含分享卡片生成图）严禁使用 emoji：不同手机的 emoji 渲染效果不一致，破坏跨设备一致性。需要图标语义时用自绘矢量、几何符号或纯文字替代（如「赞 / 已收藏 / 转发」）。静态展示的分享图不写可点击态文案（如「收藏」应写「已收藏」以呈现截图感）。
