规范标准类文件归档时禁止保留原文件名，必须重命名为标准化名称。命名来源优先级：程序分类获取的`编号 标准名称` > AI兜底给出的title > 清洗后的原文件名stem。需执行清洗（剥书名号、压缩空白、去首尾连接符）并遵守路径长度限制（单段≤47字，总长236字符，扩展名始终保留）。
