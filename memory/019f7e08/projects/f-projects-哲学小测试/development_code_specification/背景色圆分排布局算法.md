背景色选择器采用智能分排布局算法：根据每行最大容量（如9格）计算总行数，优先保证除最后一行外各行的格子数完全一致；若无法完全一致，则使最后一行的格子数与上面行的格子数相差最小（差距控制在1格内）。例如20格按每行9格分为3行（7,7,6），而非强行凑成4行。
