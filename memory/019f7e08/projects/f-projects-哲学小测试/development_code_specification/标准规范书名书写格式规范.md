国内标准规范书名必须采用【代号 序号-年号：标题】格式，例如【AQ 1058-2008：煤矿瓦斯检查工安全技术培训大纲及考核标准】。具体要求：
1. 代号与序号之间保留一个空格（如 DB 11/）；
2. 编号与标题之间使用全角冒号（：）分隔；
3. 禁止使用空格分隔编号和标题（如 AQ1058-2008 煤矿...）或半角冒号。
