数据库 book 表包含两个独立字段：
1. `source`（来源栏目）：记录书籍来源，合法枚举值为“著作”、“未分段”。早期爬虫残留的“其它”、“网页版”等杂值需清理。
2. `kind`（内容分类）：记录文章体裁，合法枚举值为“文章”、“语录”、“诗”。
两者互不混淆，严禁将 source 误认为 kind。
