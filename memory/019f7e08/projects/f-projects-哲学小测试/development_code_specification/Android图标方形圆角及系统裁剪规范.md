Android应用图标设计规范：采用方形圆角设计，不使用Adaptive Icon分层或预留圆形安全区；开发者只需提供最终的方形圆角PNG图片，图标的圆形、圆角等最终形态完全交由系统Launcher自行裁剪适配，开发者无需干预。
