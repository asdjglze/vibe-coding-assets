搜索提示词必须遵循搜索引擎规律以优化命中率：
1. 使用 2~6 个关键词空格分隔的短语，禁止生成包含虚词的完整人类语言长句
2. 实体名称必须写全称
3. 根据意图精准添加修饰词（如背景搜“创作背景”，乐评搜“解析”）
4. 动态类搜索需带上具体年份或专辑名
