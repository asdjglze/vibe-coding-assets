分享卡片模板命名规则：公司类（tags 含「公司」）与平台类（tags 含「平台」）模板，若该主体在模板池中唯一（删掉修饰后缀后不与其他模板重名），则去掉颜色/修饰后缀只留主体名（如 X 推特→X、企鹅经典→企鹅）；若该主体有多个模板（删后缀会重名，如 Apple 3 个、Spotify 3 个），则保留「主体名 · 修饰词」后缀用于区分（如 Spotify 深绿、Apple 极简、NASA 蠕虫）。判断核心是删后缀后是否重名。非公司/平台类模板一律去颜色尾缀只留主体名；去尾缀重名的换用别名/变体译名表达（禁止「·重制」后缀）。
