58 老报纸 masthead 采用帧布局（position: relative）：文章标题使用 `data-fit-title` 字号控制并限制最大宽度（如 max-width: 66%），通过 flex justify-content: center 实现真正水平居中；日期元素使用 position: absolute 固定在右上角，避免占据文档流空间导致标题偏移。
