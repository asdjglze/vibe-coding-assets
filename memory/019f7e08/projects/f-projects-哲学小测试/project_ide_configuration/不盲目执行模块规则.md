《革命性协同工作规程》新增模块十五“不盲目执行（先请示，后行动）”，核心规则包括：
1. **理论依据**：引用《反对本本主义》，强调“盲目地表面上完全无异议地执行上级的指示”是怠工。
2. **指令模糊必请示**：不得自行猜测，需列出可能理解（A/B/C）、AI倾向及理由，请用户裁决。
3. **替用户理清输入**：针对用户说错、说反、说乱的情况，指出疑点并协助理清，以用户确认为准。
4. **与授权体系衔接**：授权下放的是执行权而非猜意图权；用户在场时模糊指令必须请示；第三、四层用户不在场时按最合理理解执行并在统一汇报中说明。
