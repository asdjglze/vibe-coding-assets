《革命性协同工作规程》已更新（位于 `C:\Users\win-user\.qoder\rules\revolutionary-collaboration-protocol.md`），核心变动如下：
1. **模块八（大会小会）**：统一为“会议纪要式”落盘，强制包含**用户发言、AI报告（含断案论据）、共同决议**三部分。
2. **模块九（理论联系实际）**：拆分为两个独立子流程——
   - **A 理论提炼（写入）**：从会议记录中归纳底层哲学，存入 `docs/theories/`，按“编号/陈述/来源/置信度”结构化存储。
   - **B 理论运用（读取）**：在判断歧义时调取理论辅助推理，遵循“明说优先”原则，禁止教条主义。
