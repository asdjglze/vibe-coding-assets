《革命性协同工作规程》已新增模块十一“发展扬弃”（认识论层），核心规则包括：1. 过去不可变：历史记录落盘后只可追加不可篡改；2. 现在必须变：当前判断需反映实际，旧规则冲突时报告等待决策；3. 变化分级：系统规则极慢→事实认知极快，共五级；4. 扬弃方式：修改旧条目时采用“标注取代”而非直接删除，保留演化路径。
