《革命性协同工作规程》已更新（位于 `C:\Users\win-user\.qoder\rules\revolutionary-collaboration-protocol.md`），核心变动：
1. **模块十二"发挥主观能动性"授权层级（四层体系）**：
   - 第一层：短时任务·逐项裁决。
   - 第二层：长任务·重大问题报告（用户在场）：每一个重大裁决都需要汇报，哪怕在规划内；重大问题发现即报。
   - 第三层：长任务·危险操作报告授权（用户不在场）：规划内每一个重大裁决可自己决定；不在规划内的部署、删除等危险操作不做，先做完不需要这些行为的工作，统一汇报等裁决。
   - 第四层：完全执行：只要是当前 agent 允许的操作，都不经过用户，直接决定；可以违背规划具体规定（整体与个体冲突时择优选择）做整体符合规划精神的事；禁区：不改规划文本、不改变整体规划精神（基本路线）。
   - 第三、四层授权下不得利用参谋程序反对规划：反对规划的参谋建议只在用户在场、有确认条件时进行，且开展前必须先问用户。
   - 原则五停的条件三个：做完 / 无法开展 / 危险操作或红线（第三层危险操作不做做完其他统一汇报等裁，第四层直接决定统一汇报说明）。
2. **模块十四报告义务分层**：第二层重大裁决逐个汇报；第三层危险操作不做+统一汇报等裁；第四层全自主+禁区规划文本与规划精神。
3. 模块五流程图补"已发现自己错→直接承认转批评与自我批评"；统一汇报按大会记录；模块九以实践为准按程度规则（小改大报，盲干是盲动主义）；模块十三未授意不得自行开展参谋建议级别的全面调研分析。
