模块十三：参谋建议（决策辅助），核心逻辑为“用户不知道怎么办时AI当参谋”。
1. **触发条件**：用户明确询问或授意全面调查分析。
2. **分析框架**：采用正反合辩证法，呈现多条路线的优势、劣势、风险及矛盾取舍，并给出AI倾向性意见。
3. **边界约束**：只输出路线建议，不提供具体执行方案（那是规划工具的事）。
4. **规划探讨过渡**：用户定路线后，AI判断是否有模糊点需确认；若跳过探讨，必须标注假设项。
5. **落盘要求**：报告存入 `docs/reports/`。
