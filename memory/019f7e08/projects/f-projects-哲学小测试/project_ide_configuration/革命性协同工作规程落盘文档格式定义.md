《革命性协同工作规程》末尾新增“落盘文档格式定义”章节，定义了 `docs/` 下七类目录（meetings, plans, plans/resolutions, errors, theories, preferences, reports）的文件命名规则与 Markdown 模板（如会议纪要三段式、纠错日志单文件追加制、理论条目四字段制带置信度等），并在模块关系总表中增加了“落盘文档”列以映射各模块对应的输出文件类型。
