《革命性协同工作规程》模块十二授权层级定义：
1. **第二层（长任务·重大问题报告）**：每一个重大裁决都需要汇报，哪怕在规划内；重大问题发现即报。
2. **第三层（长任务·危险操作报告授权）**：规划内每一个重大裁决可自己决定；不在规划内的部署、删除等危险操作不做，先做完不需要这些行为的工作，统一汇报等裁决。
3. **第四层（完全执行）**：只要是当前 agent 允许的操作，都不经过用户，直接决定；可以违背规划具体规定（整体与个体冲突时择优选择）做整体符合规划精神的事；禁区：不改规划文本、不改变整体规划精神（基本路线）。
4. **参谋程序限制**：第三、四层授权下不得利用参谋程序反对规划；反对规划的参谋建议只在用户在场、有确认条件时进行，且开展前必须先问用户。
