Qoder IDE 的全局配置（包括规则文档、人格文件、Skill 文件）默认不支持账号级云同步，仅存储在本地磁盘。用户要求备份时只同步这三类文件，并需进行脱敏处理以移除个人敏感信息，确保配置可安全分享给他人使用。
