## 输入
- 需要置顶的人物名单（按指定顺序）
- 待排序的人物列表

## 步骤
1. 定义固定置顶名单常量（如 PINNED_NAMES），按用户指定顺序排列
2. 从待排序列表中筛选出属于置顶名单的人物，保持名单顺序（若名单中某人在列表中不存在则自动跳过）
3. 将剩余人物按原有规则（如笔画数、ID等）进行排序
4. 合并结果：[置顶名单人物] + [其余排序人物]

## 输出
- 排序后的人物列表，其中置顶人物始终位于最前且顺序固定
- 其余人物按既定规则正常排序

## 注意事项
- 需处理名单中人物在原始列表中缺失的情况（使用 mapNotNull 或类似过滤机制）
- 确保 UI 提示文字与新的排序逻辑保持一致
