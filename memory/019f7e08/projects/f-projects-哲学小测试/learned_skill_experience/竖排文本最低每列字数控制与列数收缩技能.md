## 输入
- 竖排文本容器 HTML 元素（含 data-cols 等属性）
- 短文本内容导致列数不足的场景

## 步骤
1. 在竖排容器添加 `data-min-col-chars` 属性（如 `6`），定义最低每列字数阈值
2. 在 share_core.js 的竖排填充逻辑中：
   - 读取 `data-min-col-chars` 值作为 `minCol`
   - 计算当前每列字符数 `perCol = ceil(totalChars / cols)`
   - 若 `perCol < minCol`，则强制 `perCol = minCol`
   - 重新计算实际列数 `actualCols = ceil(totalChars / perCol)`
   - 若 `actualCols < 原列数`，动态收窄容器宽度（宽度 = actualCols * line-height + padding/border）
3. 验证效果：短文本时列数自动收缩，避免单列仅 2-3 字导致视觉上像横排

## 输出
竖排文本在内容较少时自动减少列数并保持每列至少 N 字，视觉上保持竖排特征

## 注意事项
- **核心原则**：短文时优先收缩列数而非压短列高，否则竖排会失去纵向延伸感
- **属性命名**：使用 `data-min-col-chars` 而非硬编码，便于不同模板差异化配置
- **宽度同步**：列数收缩时必须同步收窄容器宽度，否则会出现多余空白
