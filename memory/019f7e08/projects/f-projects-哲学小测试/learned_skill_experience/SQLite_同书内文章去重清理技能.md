## 输入
- SQLite 数据库文件路径（如 quote.db）
- 待处理的重复文章组列表（每组包含 bookId 和 articleIds）

## 步骤
1. **预扫描验证**：遍历每组文章，确认每篇的引用书集合 == {组所在书} 且无 quote 引用，标记跨书或已引用组为跳过。
2. **创建备份**：在操作前复制整个数据库文件（命名含时间戳，如 `quote.db.bak_YYYYMMDD_HHMMSS`）。
3. **执行删除**：对每组保留 toc sortOrder 最小的 article，删除其余文章的 toc_entry 和 article 记录。
4. **提交事务**：使用 BEGIN/COMMIT 确保原子性。
5. **后验证**：重跑扫描脚本，确认重复组归零；抽查关键案例确认保留状态。

## 输出
- 清理日志文件（记录每组保留/删除详情及总数）
- 数据库规模变化统计（article/toc 减少数量）
- 验证结果（重复组数 = 0）

## 注意事项
- **核心约束**：严禁删除跨书引用的文章，必须逐篇校验 ref_books == {bookId}。
- **超时处理**：若脚本执行超时，不要直接终止，应检查进程状态并等待日志写入完成。
- **扩展资源**：需具备编写 SQL 查询以校验引用书集合和 quote 计数的能力。
