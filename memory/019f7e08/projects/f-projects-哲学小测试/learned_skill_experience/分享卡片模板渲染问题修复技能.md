## 输入
- 用户反馈的模板渲染问题（如渐变方向错误、竖排布局错乱、文案前缀冗余等）
- 待修复的 HTML/CSS/JS 模板文件

## 步骤
1. **定位问题**：阅读相关模板文件（HTML）和共享脚本（share_core.js），对照用户描述定位具体代码行
2. **修复渐变逻辑**：
   - 检查 `gradientSpan` 函数参数，确认是否误用 `reverse` 导致下文渐变反向
   - 修正为：上文从低透明度到高透明度（近远），下文从高到低；截断时省略号应放在最远端（最后）
3. **修复竖排布局**：
   - 识别竖排容器中的 `display: flex; align-items: center` 会导致子元素横向排列
   - 改为 `display: block` 或移除 flex，确保 pre/正文/post 按竖排流自然堆叠
4. **优化文案显示**：
   - 在 `fillTextField` 中添加 `data-short` 属性判断，自动截取出处中的「· 篇名」部分，仅保留书名
   - 移除硬编码的「节选 · 」等冗余前缀
5. **清理装饰元素**：删除装饰图标（如星星）的 `background` 背景色，保持透明位图效果
6. **验证修复**：重新生成预览工具页，通过浏览器交互测试按钮切换、滚动条、渐变方向等效果

## 输出
- 修复后的模板文件，渲染效果符合用户预期
- 预览工具页刷新后，所有交互和样式正常

## 注意事项
- **竖排陷阱**：竖排模式下严禁使用 `display: flex` 包裹文本块，否则会导致内容横向排列
- **渐变方向**：`gradientSpan` 的 `reverse` 参数需谨慎使用，建议手动控制前后文逻辑更清晰
- **数据隔离**：`data-short` 机制应在 JS 层统一处理，避免每个模板重复写截取逻辑
