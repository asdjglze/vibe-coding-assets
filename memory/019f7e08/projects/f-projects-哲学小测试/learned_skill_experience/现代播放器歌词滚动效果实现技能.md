## 输入
- 需要实现现代播放器风格歌词滚动效果（上下两端模糊渐隐、当前句放大高亮、切句丝滑滚动）
- 项目已有基础滚动条样式规范需对齐

## 步骤
1. **模糊渐隐遮罩**：歌词容器用 `::before`/`::after` 伪元素（height 56px、z-index 2、pointer-events none），叠加三种效果：`background: linear-gradient(背景色, transparent)` 淡出变浅 + `backdrop-filter: blur(8px)` 变模糊 + `mask-image: linear-gradient(black 30%, transparent)` 让遮罩自身只在边缘生效、中间完全透明不渲染，实现"越靠近两端越模糊越浅、像要消失"而中间清晰
2. **当前行特效**：`.active` 用 `font-size` 放大 + `font-weight: 700` + 高亮色（禁用 transform scale，保证矢量渲染清晰不发虚）
3. **内容留白**：歌词内容区上下 padding 与遮罩同高（56px），确保首末行能完整滚入模糊渐隐区；竖屏窄模式遮罩与 padding 同步缩小为 24px
4. **JS 缓动滚动**：替换直接赋值 `scrollTop`，用 `requestAnimationFrame` 实现 easeOutCubic 缓动，距离越大时长越长（300-600ms），切换歌曲时 `cancelAnimationFrame` 取消未完成动画并回顶

## 输出
- 歌词靠近上下两端时逐渐模糊变浅，视觉上像消失
- 当前播放行字号放大、加粗、高亮且始终清晰
- 切句滚动丝滑无瞬移
- 滚动条样式与全局规范一致

## 注意事项
- backdrop-filter 与 mask-image 组合时 mask 决定 blur 生效区域，必须同时加 `-webkit-` 前缀
- 遮罩需设置 `pointer-events: none` 避免阻挡点击
- 中间区域必须保持完全清晰，当前句不受任何模糊影响
