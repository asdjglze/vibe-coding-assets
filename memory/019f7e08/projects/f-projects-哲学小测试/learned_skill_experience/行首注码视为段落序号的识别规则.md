## 输入
- 待处理的 Markdown 文本内容
- 需要识别的注码模式（如 <N>、〔N〕、[N]、带圈数字等）

## 步骤
1. 遍历文本中的每个注码匹配项
2. 对于每个匹配项，检查其所在行内匹配位置之前的字符
3. 判断标准：若匹配位置之前（本行内）除空白外没有任何文字，则视为行首
4. 行首注码判定为段落序号/标记，不执行注释相关操作（不转换、不统计、不渲染为脚注样式）
5. 非行首注码按正常逻辑处理（转换为 [^N] 引用、计入统计、渲染为可点击脚注）

## 输出
- 正确的注码分类结果（序号 vs 注释）
- 准确的统计数量（不含行首序号）
- 正确的渲染样式（行首注码显示为普通文本）

## 注意事项
- 核心原则：注释永远跟在正文之后，行首的注码不是注释
- 需在所有注码识别路径中统一应用此规则（批量转换、列表统计、预览渲染、App 正文渲染）
- 行首判断需考虑软换行后的情况（块首或软换行后也视为行首）
