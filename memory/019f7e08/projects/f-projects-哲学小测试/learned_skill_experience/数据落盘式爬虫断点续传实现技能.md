## 输入
- 数据下载/同步脚本需按层级结构落盘 JSON 文件（如 `data/{person}/books/{book_dir}/articles.json`）
- 目标目录可能尚未创建（如新书目录从未初始化）

## 步骤
1. 在落盘前检查并创建完整目录树：`os.makedirs(os.path.dirname(file_path), exist_ok=True)`
2. 采用临时文件 + 原子替换策略：先写 `{path}.tmp`，成功后再 `os.replace(tmp, path)`
3. 每本书处理完即落盘，支持中断后重跑跳过已下载内容
4. 单线程限速请求（如 1.5s 间隔），遇网络错误自动重试

## 输出
- 所有书籍的 articles.json 完整落盘至本地目录
- 日志记录跳过/下载/失败数量，支持断点续传

## 注意事项
- 必须确保父目录存在，否则 `open(..., 'w')` 会报 FileNotFoundError
- 临时文件后缀建议统一为 `.tmp`，避免与正常数据混淆
