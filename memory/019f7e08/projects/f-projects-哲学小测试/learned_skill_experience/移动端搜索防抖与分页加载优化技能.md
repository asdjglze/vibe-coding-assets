## 输入
- 用户反馈搜索卡顿或UI不一致
- 搜索结果数据量较大（如上千条）

## 步骤
1. **搜索防抖**：在 ViewModel 中引入 `delay`（如300ms），用户停止输入后才触发真实查询；同时立即更新 UI 状态以回显关键词。
2. **分页/虚拟列表渲染**：不要一次性渲染所有结果。维护 `visibleCount` 状态，初始只渲染第一页（如50条）；监听列表滚动到底部事件，追加下一页数据。
3. **UI 一致性检查**：对比目标页面与全局标准页面（如设置页）的背景色和组件样式；使用项目定义的全局 Theme 变量（如 `Paper`, `Bone`）替换硬编码颜色（如 `Color.White`）。

## 输出
- 搜索框输入即时回显，无延迟感
- 大量搜索结果通过滚动逐步加载，不阻塞主线程
- 人物选择页等子页面背景色与全局主题保持一致

## 注意事项
- 防抖时间不宜过短（<200ms可能无效）也不宜过长（>500ms影响体验）
- 分页加载需处理边界情况（如剩余不足一页时停止加载）
