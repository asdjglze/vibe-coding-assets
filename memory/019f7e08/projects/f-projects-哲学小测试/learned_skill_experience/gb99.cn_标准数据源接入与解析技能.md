## 输入
- 标准编号（如 GB/T 1.1-2020）

## 步骤
1. **URL 构造**：将编号中的空格和斜杠替换为连字符（`-`），生成 slug（例如 `GB/T 22522-2021` → `GB-T-22522-2021`；`DB11/T 1820-2021` → `DB11-T-1820-2021`）。访问 `https://gb99.cn/std/{slug}`。
2. **页面校验**：检查返回状态码是否为 200。若为 200，需进一步解析 HTML 内容。
3. **未收录页识别**：检测 HTML 中是否包含 `${std.std_code}` 等前端模板占位符，或关键字段（如标准号行）缺失。若存在占位符，判定为“未收录”，返回匹配度 0。
4. **字段提取**：若未命中占位符，从 `<th>标签</th><td>值</td>` 结构中提取标准名称、状态、CCS、ICS、日期、归口部门、发布单位、适用范围等字段。
5. **严格匹配**：对比提取的标准号与输入编号，计算匹配度（match_level）。

## 输出
- 成功：返回字典（含 source, number, status, ccs, ics, dates, dept 等）及匹配度（通常 100）。
- 失败：返回 (None, 0)。

## 注意事项
- gb99.cn 未收录时不返回 404，而是返回 200 + 模板占位页，必须通过字段校验识别，不可直接采信。
- URL 拼写规则：优先尝试“空格/斜杠转连字符”，其次尝试“去斜杠”。
