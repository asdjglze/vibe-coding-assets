## 输入
- 用户指定的功能文件夹名称列表（如"强制按单独文件分析"、"暂不处理"等）
- 每个文件夹对应的行为机制（skip整树跳过 / single单文件独立识别 / 强制类型等）

## 步骤
1. **定义约定映射**：在 `src/scanner.py` 中定义 `SPECIAL_DIRS` 字典，键为文件夹名，值为行为标签（如 "single", "skip", "force_book" 等）。
2. **自动创建与保护**：
   - 扫描入口函数遍历 `SPECIAL_DIRS`，若目录不存在则自动创建（`os.makedirs(..., exist_ok=True)`）。
   - 将约定名加入空文件夹清理器的 `_HARD_PROTECT` 集合，确保即使为空也不被删除。
3. **路径链匹配与标记继承**：
   - 修改 `match_folder_tags` 函数，不仅检查文件名，还检查完整路径链中是否包含约定名。
   - 命中约定名即自动打上对应标记（如 "single"），子目录内文件自动继承该标记。
4. **全链路行为控制**：
   - **扫描阶段**：命中 "skip" 标签的目录直接 `continue`，整树不进入递归；命中 "single" 标签照常下钻但标记已生效。
   - **合并阶段**：在 `merger.py` 中增加 `_in_special` 判断，命中约定名的目录不参与分卷合并。
   - **清理阶段**：依赖 `_HARD_PROTECT` 硬保护名单。
5. **扩展新类型**：新增类型只需在 `SPECIAL_DIRS` 添加条目，并在对应模块（如 `recognizer.py` 或 `standard.py`）增加对该标签的处理逻辑即可。

## 输出
- 一套无需用户记忆标记语法的“约定功能文件夹”系统
- 指定文件夹内的文件自动获得预设行为（跳过/单文件分析/强制类型等）
- 空文件夹清理时这些文件夹永不消失

## 注意事项
- 约定名必须唯一且不含特殊字符，避免误匹配。
- “暂不处理”类文件夹整树跳过，内部文件不会被任何 AI 识别或移动。
- 强制类型类文件夹（如“强制规范”）跳过AI初判，直接走程序规则分类。
- 所有约定文件夹均支持子目录继承机制（路径链任意层级命中即生效）。
