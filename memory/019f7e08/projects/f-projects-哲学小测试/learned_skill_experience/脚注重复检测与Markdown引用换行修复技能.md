## 输入
- 文本内容（含脚注标记和Markdown引用）
- 前端预览渲染容器元素

## 步骤
1. **重复检测修复**：后端统计时避免使用 `set()` 直接去重，改用列表收集后计数，筛选出现次数 > 1 的编号作为重复项返回；前端同步增加重复引用计数逻辑。
2. **引用换行修复**：检查 Markdown 渲染引擎（如 markdown-it）输出的 HTML 结构，若包含 `<p>` 或 `<blockquote>` 标签且内部保留 `
`，需为对应 CSS 选择器添加 `white-space: pre-line;` 以保留软换行。

## 输出
- 左侧列表显示“重复×N”徽章及悬停详情
- 预览区多行引用正确换行显示

## 注意事项
- `set()` 会吞掉重复项，需显式计数判断
- 浏览器默认将连续空白符（含 `
`）折叠为空格
