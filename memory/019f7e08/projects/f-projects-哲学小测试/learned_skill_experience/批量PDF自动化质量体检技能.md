## 输入
- PDF文件目录路径列表
- （可选）源文件目录（用于页数比对）

## 步骤
1. **全量盘点**：遍历目录列出所有PDF及其基本信息（页数、大小、结构）。
2. **逐页质量扫描**：对每个PDF进行低分辨率渲染（dpi=32）分析：
   - **空白页检测**：计算非白像素占比，<0.1%标记为空白页。
   - **坏页检测**：捕获读取/渲染异常，记录错误信息。
   - **尺寸异常检测**：统计每本书页图宽度中位数，若某页宽度偏离中位数50%以下或250%以上，标记为异常（疑似WAF验证页等假页）。
3. **源文件比对**：若存在源图片目录，对比源图片数量与PDF页数是否一致。
4. **评级与报告**：根据异常数量分级（OK/需关注/需人工复核），生成包含异常页号清单的详细报告。

## 输出
- 体检统计表：每本PDF的评级（OK/!/X）、页数、文件大小、异常类型及具体页号。
- 详细JSON报告：包含所有异常细节，便于后续处理。

## 注意事项
- **尺寸异常检测是关键**：单纯查空白页无法发现"WAF验证页被存成图"的情况，必须结合页图尺寸分布分析。
- **性能优化**：使用低分辨率（dpi=32）渲染即可满足质量判断需求，避免高分辨率导致耗时过长。
- **容错处理**：单个文件读取失败不应中断整个批处理流程，应记录错误并继续。
