## 输入
- 音乐推荐服务或Agent调度服务的代码重构需求

## 步骤
1. **删除AI能量曲线逻辑**：彻底清除所有让AI计算/编排能量曲线的提示词和死代码（如`select_and_arrange_songs`），保留程序精排（基于真实音频特征库）。
2. **串词一次成型改造**：
   - 删除二审块（机械化检测+AI修正整个JSON）。
   - `_parse_json_response`增强：先走程序修复（尾逗号、截断补引号/括号、去代码块标记），不耗token。
   - 仅当程序修不了的乱格式才走一次轻量AI修复：极简提示“只修JSON格式，内容一字不改”，不带上下文/人格/歌曲信息。
3. **工具描述只发1次**：
   - `_analyze_task`：唯一一次注入完整工具描述，输出新增`tools`字段。
   - `_validate_task`：不再注入工具描述，只传工具名列表。
   - `_generate_plan`：只注入分析阶段选定工具的描述（选定为空才回退全量）。

## 输出
- 代码中无残留的能量曲线AI提示词
- 串词生成流程简化为：AI初稿 → 程序修复 → (可选)轻量AI格式修复
- Agent调度Token消耗降低（工具描述减少重复注入）

## 注意事项
- 人格提示词是核心功能而非装饰，必须保留在对话注入和串词模板中。
- 情绪判断保留LLM动态分析，不使用硬编码映射表替代。
