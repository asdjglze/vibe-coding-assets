## 停止规则
1. **层级目标**：默认目标尽量下钻到第四层。
2. **自动完成机制**：若AI选择的是叶子类目（无子类），程序直接返回“层级钻入自动完成”，强制触发final输出，不再追问或让AI多想一轮。

## 文件夹结构规范
- **中图分类域**：按官方类号实层目录 → 作者数字桶 → 作者名 → 书名数字桶 → 书文件夹（含PDF/metadata.opf）。
- **规范图集域**：统一为分类层 → 年份层 → 书文件夹模式。
- **文件约束**：所有书文件必须被独立文件夹包裹，分类目录下只允许存在子分类文件夹和书文件夹，禁止散落PDF。
