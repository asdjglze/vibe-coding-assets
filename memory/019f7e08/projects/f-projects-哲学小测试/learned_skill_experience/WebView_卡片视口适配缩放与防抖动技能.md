## 输入
- 卡片自然尺寸 (width, height)
- WebView 视口尺寸 (baseVw, baseVh)

## 步骤
1. **计算宽度缩放因子**：若卡片宽 > 视口宽，sW = 视口宽 / 卡片宽；否则 sW = 1
2. **计算高度缩放因子**：若卡片高 > 视口高，sH = 视口高 / 卡片高；否则 sH = 1
3. **确定最终缩放**：target = Math.min(sW, sH)（取两者中更小的因子，即超出比例更大的维度决定缩放）
4. **应用缩放**：仅当 target < 1 时设置 document.documentElement.style.zoom = target
5. **防抖动关键**：绝对禁止在测量前重置页面 zoom 值，避免触发 resize 事件风暴导致视觉闪烁

## 输出
卡片以 contain 模式完整嵌入视口，无局部裁剪或过度缩放，且无视觉抖动

## 注意事项
- **核心原则**：高超出按高缩、宽超出按宽缩；都超出时看哪个超出得更多（超出比例更大），按那个缩放
- **禁止操作**：不要先重置 zoom=1 再测量，这会触发无限 resize 风暴（一下大一下小）
- **幂等处理**：目标值与当前值相同则不写，防止不必要的重绘
