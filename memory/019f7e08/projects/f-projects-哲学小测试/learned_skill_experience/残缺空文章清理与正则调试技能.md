## 输入
- 待清理的文章 ID 列表（已知候选）
- 数据库连接对象或文件路径

## 步骤
1. **备份**：在执行删除前备份数据库（`shutil.copy2`）。
2. **定义垃圾判定规则**：
   - 占位语：匹配 `正文未见|暂略|略去|可参看实体书|待补`。
   - 面包屑：整篇为 `中文马克思主义文库 >> ... >> 《书名》`（无正文）。
   - 纯出版信息：整篇为 `XX 译 XX 出版，XX 年 XX 月`（需允许换行）。
   - 导航词：剔除 `上一篇|回目录|下一篇`、期号模式、`译文` 前缀等。
3. **关键调试点**：
   - **顺序敏感**：先剔除长串干扰（如 `译文`），再剔除短字（如单字 `译`），避免误伤。
   - **格式兼容**：正则需支持换行符（使用 `re.S` 或显式排除 `
`）。
4. **执行删除**：
   - 遍历候选，应用规则判定是否为垃圾。
   - 收集需删除的 `toc_entry` 和 `article`（若 `toc` 为空且无 `quote` 引用则一并删）。
   - 执行批量删除并记录原因。
5. **生成清单**：将已删除文章的全文、引用位置、原因写入文本文件供后续补录。
6. **验证**：查询残留 ID 数量应为 0，并抽样检查正常短内容未被误删。

## 输出
- 数据库中被标记为垃圾的文章及关联目录条目被物理删除。
- 生成包含全文和元数据的 `_incomplete_list.txt` 清单文件。
- 确认残留数为 0，正常内容完好。

## 注意事项
- **正则顺序**：长模式优先于短模式，防止短模式提前截断导致长模式失效。
- **换行处理**：涉及多行内容的正则必须开启 `re.S` 或显式处理换行符。
- **孤儿判断**：删除所有 `toc_entry` 后，若无 `quote` 引用，`article` 应视为孤儿一并删除。
