## 诊断与优化步骤
1. **代码精读**：理解设计意图，区分架构对错与实现Bug。确认检索-判断式Agent架构及零编造原则。
2. **协议一致性排查**：检查提示词示例与代码解析字段是否一致（如顶层code vs args嵌套），确保模型不混淆。
3. **上下文溢出治理**：针对Ollama无状态特性，实施滑动窗口、长结果自动压缩（独立LLM调用）及事实清单回填，防止头部截断导致的失忆。
4. **分类逻辑校准**：确保目录名/文件名仅作为线索，不作为直通分类依据。跨学科书籍按内容实质归类，避免强行归类。
5. **性能与稳定性**：关注网络超时设置（30-60s），确保工具重试机制合理（网络/工具/AI分层处理）。
