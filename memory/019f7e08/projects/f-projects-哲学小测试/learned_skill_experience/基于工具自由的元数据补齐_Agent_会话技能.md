## 输入
- 待处理文件路径及扩展名
- 当前已知的元数据（如文件名提取的编号、初判结果等）
- 状态目录路径（用于暂存渲染图片）

## 步骤
1. **初始化锚点**：提取文件前 3 页（封面/扉页/版权页）作为初始图像证据，并读取正文前段文本。
2. **构建 Agent 会话**：使用系统提示词定义任务（如补全书名/标准号），赋予 AI 工具自由权（read_pages 翻页读文、view_pages 看图、web_search 联网）。
3. **多轮交互循环**：
   - 发送当前证据给模型，请求输出 JSON 或工具调用列表。
   - 若需工具：并行执行 `read_pages`/`view_pages`/`web_search`，收集结果并追加到历史对话。
   - 注意视图纪律：每轮仅附带本轮请求查看的页面，旧图撤离，关键信息靠文本留痕。
4. **收口输出**：当模型返回完整 JSON（含 std_number/title/reason）时终止循环；若无法判断则返回空值。

## 输出
- 结构化字典：{"std_number": "图集号", "title": "正式名称", "reason": "依据"}
- 若无法识别，字段为空串，不阻塞流程。

## 注意事项
- **工具复用**：直接复用项目中已有的 `_exec_tool` 执行器和 `_render_view_pages` 视图协议，无需重复造轮子。
- **Token 优化**：避免双份提示词，将详细规则放入 system prompt，user prompt 仅简述任务。
- **宁缺勿错**：找不到确切编号时输出空串，严禁编造。
- **架构一致性**：确保该会话模式与项目内其他 Agent 化环节（如出版社查找）保持同构，便于维护和扩展。
