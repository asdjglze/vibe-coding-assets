## 输入
- 需要对 `revolutionary-collaboration-protocol.md` 进行内容新增或修正
- 具体的修改指令（如新增模块、修正某条规则定义）

## 步骤
1. **反向复制**：将目标规则文件复制到工作区暂存（如 `_tmp_rule.md`）。
2. **定位修改点**：分析需要修改的位置（正文插入、总表行、流程图节点、具体规则条目等）。
3. **执行 SearchReplace**：在暂存文件中依次执行多处修改，确保 diff 无误。
4. **回写落盘**：将暂存文件覆盖回原路径（`~/.qoder/rules/...`）。
5. **哈希校验**：对比源文件和目标文件的 SHA256 哈希值，确保一致。
6. **锚点验证**：使用 PowerShell 检查关键文本片段是否存在，确认修改生效。
7. **清理**：删除工作区内的暂存文件。

## 输出
规则文件更新完毕，哈希校验通过，所有锚点验证 OK。

## 注意事项
- **防篡改机制**：必须遵循“暂存编辑 -> 复制落盘 -> 哈希校验”流程，禁止直接编辑全局规则文件。
- **新会话生效**：Desktop IDE 的规则注入副本为会话启动快照，本次修改需在新会话中生效。
- **具体业务修正示例**：
  - 规划变更管理：已执行完的才是旧规划；执行中变更=改文件（原内容标记作废、追加新内容，不删除）。
  - 权限判断：不得把“我去睡觉了”等日常话语猜测为第三层授权。
  - 报告义务：大事必须报，小事不要烦；不可逆风险立即停报。
