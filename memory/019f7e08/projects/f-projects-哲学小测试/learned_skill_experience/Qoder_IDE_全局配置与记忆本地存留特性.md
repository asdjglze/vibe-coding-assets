## 输入
- Qoder IDE 全局规则、偏好文档或记忆是否支持账号级云同步的疑问

## 步骤
1. **本地结构核查**：检查 `~/.qoder` 目录下 `rules`（规则）、`memories`（记忆）、`docs`（自定义文档）等目录是否存在且包含文件。
2. **官方文档查证**：搜索 Qoder 官方文档中关于 Rules/Memory 的存储说明，确认是否提及账号同步或跨设备同步功能。
3. **社区/问答核实**：查阅开发者社区或官方问答，确认默认行为（通常明确标注“不支持跨设备自动同步”）。
4. **结论输出**：明确告知用户当前配置仅本地存留，项目级规则随 Git 共享，但全局配置无云同步。
5. **风险与建议**：提示重装/换机将导致数据丢失，建议建立私有仓库（如 GitHub）进行版本化管理和备份。

## 输出
- 明确的同步状态结论（本地存留 vs 云同步）
- 配置文件的具体本地路径
- 数据丢失风险评估及备份方案建议

## 注意事项
- Qoder IDE 的全局规则（`.qoder/rules`）和记忆（`.qoder/memories`）**默认不支持账号级云同步**，仅存储在本地磁盘。
- 项目级规则（`.qoder/rules` 在项目根目录）可通过 Git 在团队间共享，但不等同于个人账号云同步。
- 若需多设备同步，必须自行搭建备份机制（如私有 Git 仓库），不能依赖 Qoder 内置功能。
