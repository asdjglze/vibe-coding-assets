## 输入
- 用户在前端设置页修改了配置项（如 TTS 音色）
- 用户即将关闭设置面板或切换回主页面

## 步骤
1. **监听字段变更**：在 `markDirty(key, value)` 被调用后，若涉及关键配置（如音色），立即追加 `saveAllPending()` 调用，不再等待 3 分钟定时器
2. **监听关闭事件**：在主页面 `closeSettings` 函数中，向 iframe 发送 `postMessage({ type: 'settings-save-request' })`，子页面收到后立即触发 `saveAllPending()`
3. **兜底处理**：当检测到当前配置无效（如音色下架自动回退默认）时，同样立即调用 `saveAllPending()` 落库

## 输出
- 用户配置（如 tts_speaker）实时写入数据库，无需等待超时
- 关闭设置面板后，主页面读取到的配置与用户最后选择一致

## 注意事项
- 避免滥用立即保存：仅对高频修改且易丢失的关键配置生效，普通配置保留 3 分钟防抖机制
- 确保 `saveAllPending` 内部已清除定时器，防止重复提交
