## 输入
- 待处理的文件列表（可能包含伪装后缀如 .rar.pdf）

## 步骤
1. **魔数检测**：读取文件头部字节，匹配已知格式魔数表（如PK头对应zip/epub/docx/xlsx等），确定真实文件类型。
2. **后缀比对与修正**：将检测到的真实类型与实际文件后缀对比，若不一致则重命名为正确后缀（如 `book.rar.pdf` -> `book.rar`）。
3. **解压处理**：对确认为压缩包的文件进行解压，生成 `_解压` 后缀的副本，原件备份至 `_merged_src`。
4. **推广文件清理**：在后续步骤中清理 `.url`, `.lnk` 等非书籍文件。

## 输出
- 文件名后缀被修正为真实类型的文件
- 压缩包被解压且原件已备份

## 注意事项
- 该流程需覆盖所有目录（pending + heavy），避免普通目录中的伪装文件进入AI识别环节导致漏书。
- 依赖 `file_type.py` 中的魔数表实现高精度识别。
