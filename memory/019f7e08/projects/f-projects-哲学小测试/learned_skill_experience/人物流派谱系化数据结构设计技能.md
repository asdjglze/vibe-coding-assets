## 输入
- 需要按人物思想谱系（如马克思主义 vs 非马左翼）进行筛选、排序或视觉区分的需求
- 现有数据结构仅包含人物表和单一流派名称字段（TEXT），无谱系元数据

## 步骤
1. **现状评估**：确认当前是否仅靠人工约定的流派名称字符串区分谱系，缺乏布尔标记或关联表。
2. **方案选择**：
   - **轻量级方案**：在人物表中增加 `schoolCategory` 字段（枚举：马主义/非马左翼/前马等），直接用于筛选和样式控制。
   - **规范级方案**：新建 `schools` 元数据表（含流派名、谱系类别、排序、颜色等），原表通过外键关联，实现流派属性的集中管理。
3. **实施迁移**：根据历史事实将现有流派映射到新类别，执行 SQL 变更（ALTER TABLE / CREATE TABLE + UPDATE）。
4. **逻辑更新**：修改应用层代码，基于新字段实现筛选逻辑、徽标颜色渲染及排序规则。

## 输出
- 数据库支持按谱系类别查询（如 `WHERE schoolCategory = '马克思主义'`）。
- 前端可依据类别动态调整 UI（徽标颜色、分组展示）。
- 新增流派时只需维护元数据表，无需修改人物表结构。

## 注意事项
- 若仅需简单筛选，方案 A 成本低；若需频繁调整流派属性（颜色、排序、描述），方案 B 扩展性更好。
- 历史数据清洗是关键，需确保每个流派准确归类到对应的谱系类别中。
