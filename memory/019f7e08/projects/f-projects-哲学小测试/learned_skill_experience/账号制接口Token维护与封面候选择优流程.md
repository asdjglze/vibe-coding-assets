## 输入
- 需要接入外部数据接口（如PDC版本数据中心）
- 需要从多个来源收集素材（如封面）并进行最终择优

## 步骤
1. **Token维护**：对于账号制/反爬接口，若Token失效，由人工在浏览器中登录并处理验证码（如滑块），然后从浏览器控制台获取Token写入配置文件。
2. **双路接入**：同时接入接口的核心数据（如分类）和附属资源（如封面图）。
3. **顺带收集**：在任何使用接口或程序提取到素材时，顺带存入候选池（自动分配序号seq，md5去重，限制上限）。
4. **最后择优**：在其他工序（如识别、分类）全部完成后，单独发起一次AI会话进行择优。向AI提供带序号的候选清单及缩略图，要求AI输出选中序号。
5. **兜底机制**：若候选不足或AI失败，回退到原有默认逻辑。

## 输出
- 接口数据成功查询并入库
- 最终选定的一张素材（如封面）作为正式产物

## 注意事项
- 候选池存储路径建议为 `state/cover_pool/<key>/`，key可使用文件路径的md5前缀。
- AI择优仅在候选≥2时触发，避免浪费token；唯一候选直接采用。
- 快通道（纯本地流程）应独立于该机制，保持零联网。
