## 输入
- 图书分类中的两可归属场景（如哲学vs宗教、文学vs历史）
- 官方分类法注释或馆级业务规范素材

## 步骤
1. **搜集权威依据**：搜索《中图法》修订调研报告、国家图书馆官网问答、馆级编目业务规范，提取归类总则（学科性质是本质属性）、多主题裁决次序（因果归结果、应用归被应用方等）、体裁优先规则。
2. **构建方法论框架**：编写《分类决断指南》，核心是【裁决规则】而非【案例清单】。结构包括：总则、多主题裁决次序、体裁优先判定、学科属性三问法、特定边界（如哲学vs宗教）。
3. **提供示范案例**：针对高频争议（如易经、道家vs道教），仅作为规则应用的示范，演示如何根据书籍目的和写法落类，不穷举所有情况。
4. **实现按需检索工具**：开发 `guide` 工具，支持 `topic` 关键词匹配章节全文或 `list` 查看目录，避免一次性加载大量文本消耗 token。
5. **集成到 Agent 提示词**：在系统提示词中告知 AI 存在该指南，规定“两可时先查指南再联网”，并要求在 final 的 reason 中记录判据。

## 输出
- 本地 Markdown 格式的《分类决断指南》（约16节）
- Agent 可用的 `guide` 工具函数
- 更新后的 Agent 系统提示词

## 注意事项
- 指南不是类目清单，最终类号仍需通过 `get_children/list_tree` 验证官方表。
- 专家都争议的两可题，Agent 应依据规则给出决断，不留人工。
