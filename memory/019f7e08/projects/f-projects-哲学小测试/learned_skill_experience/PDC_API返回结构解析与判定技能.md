## 输入
- PDC API 接口返回数据（如 search/detail）

## 步骤
1. 判断返回类型是否为 dict（成功时通常返回包含 list 和统计字段的字典）
2. 从 dict 中提取 'list' 键获取结果列表
3. 检查 dict 中是否存在 '_error' 键来判断是否出错
4. 若为异常分支，统一构造 {'_error': ...} 格式保持结构一致

## 输出
正确的结果列表或错误信息，确保后续逻辑能正确处理

## 注意事项
- PDC API 成功响应是 dict 而非 list，直接按 list 处理会导致判定失败
- 所有分支应保持一致的数据结构，便于统一处理
