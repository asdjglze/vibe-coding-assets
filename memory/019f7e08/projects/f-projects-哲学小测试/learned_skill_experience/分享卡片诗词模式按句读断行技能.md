## 输入
- 分享卡片模板中的文本元素（div/span）
- 数据字段（text, pre, post）

## 步骤
1. **标识诗词模式**：在 HTML 元素添加 `data-poem="1"` 属性（区别于竖排 `data-vertical="1"`）。
2. **配置上下文行数**：设置 `data-pre-lines`（上文保留句数）和 `data-post-lines`（下文保留句数）。
3. **实现句读断行逻辑**：在 `fillTextContext` 函数中增加分支，当检测到 `data-poem="1"` 时：
   - 调用 `poemLines()` 函数按中文标点（逗号、句号等）分割文本为句子数组。
   - 截取上文/下文时按句子数组切片（如 `slice(-preLN)`），而非按字符数截取。
   - 最终渲染时将句子数组用换行符 `
` 连接，确保每句独立成行。
4. **禁用填满逻辑**：诗词模式下不执行“按行宽填满”的截断，保持句子完整性。

## 输出
- 诗词内容按句读完整分行显示（如“雄关漫道真如铁，\n而今迈步从头越。”）
- 上下文预览以整句为单位截取，避免句子被切断

## 注意事项
- **核心区别**：竖排模式按字符数截取（每列一字），诗词模式必须按语义（句读）断行。
- **兼容性**：`data-poem` 优先级高于或独立于 `data-vertical`，需显式区分两种模式。
- **兜底处理**：若容器高度不足，由 CSS overflow 裁剪兜底，不强制截断句子。
- **扩展资源**：需实现 `poemLines(text)` 辅助函数，使用正则匹配中文标点分割句子。
