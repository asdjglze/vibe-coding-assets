## 输入
- 目标 URL 或资源路径（如电子书入口页、XML 文件、SWF 资源）
- 本地已存在的部分资源目录（用于判断是否可复用）

## 步骤
1. **WAF 特征识别**：检测响应内容是否包含 "HuaweiCloudWAF" 或 "Access Verification"，确认是否为随机挑战页而非永久损坏。
2. **智能分类优化**：若 URL 以 ".html" 结尾且为 FlipViewer 入口（如 detail 页锚点），直接判定为 "legacy" 类型，避免发起无效请求触发 WAF。
3. **本地缓存复用**：在续传或整包下载前，优先检查本地是否存在有效的入口页 (index.html) 和数据文件 (book.xml)，验证其内容包含关键配置 (urlOfFlipBook) 且非 WAF 页，若有效则直接复用，跳过网络请求。
4. **动态重试策略**：命中 WAF 时仅短暂退避 (1s) 并立即重试（最多 8-12 次），利用 WAF 随机挑战特性（约 15-20% 概率）快速恢复，避免长时间阻塞；连续失败超过阈值时全局暂停。
5. **完整性校验**：使用 99% 阈值判定整包完成，允许少量 WAF 顽固缺口留待下轮自动补齐。

## 输出
- 成功下载完整资源包（含入口、数据文件及所有引用资源）
- 或跳过已知完整包，继续处理下一项

## 注意事项
- **WAF 行为特征**：华为云 WAF 对脚本流量常表现为随机概率拦截（秒级返回验证页），而非持续挂起或永久 404；单发请求通常正常，批量高频易触发。
- **URL 参数风险**：给 URL 添加随机查询参数可能反而增加被拦截概率，不建议作为绕过手段。
- **脏材料回滚**：若下载的入口/XML 被确认为 WAF 页，必须删除该文件并回滚重试，防止误判为成功。
- **并发控制**：建议设置最小请求间隔 (0.5s+) 以降低触发率，配合局部重试机制。
