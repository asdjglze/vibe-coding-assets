## 输入
- 需要验证数据库中疑似重复的文章条目（特别是 norm 后长度较短的）
- 数据库路径（如 quote.db）

## 步骤
1. **初步验证**：使用 `python -c "..."` 直接查询可疑 article ID 的内容，观察是否包含导航文字（如「上一篇 回目录 下一篇」）而非实质重复。
2. **解决编码问题**：若终端输出出现 `UnicodeEncodeError` 或乱码，必须使用 `-X utf8` 参数运行 Python，并配合 `io.TextIOWrapper` 强制 UTF-8 输出到文件或标准流。
3. **脚本优化**：在去重逻辑中增加 `MIN_LEN` 阈值（如 40），将 norm 后长度低于此值的视为「空文章/残缺数据」单独归类，避免误报为实质重复。

## 输出
- 确认哪些是真正的实质内容重复
- 识别出哪些是仅含导航文字的残缺数据（需补正文而非去重）

## 注意事项
### 扩展资源
- Windows 终端中文乱码修复命令：`python -X utf8 -c "..."`
- 数据清洗经验：短字符串重复往往是抓取残缺（仅导航链接），需结合长度阈值过滤
