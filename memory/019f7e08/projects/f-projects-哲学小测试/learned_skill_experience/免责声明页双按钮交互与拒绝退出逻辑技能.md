## 输入
- 需要实现免责声明或类似引导页的双按钮交互（同意进入 vs 拒绝退出）
- 业务规则：拒绝操作需直接退出应用且不记录同意状态，确保下次启动仍展示该页面

## 步骤
1. 修改 UI 布局：底部区域由单按钮改为双按钮容器（Column），主按钮为实心高亮样式，次按钮为描边低对比度样式
2. 定义回调参数：在 Composable 函数中增加 `onDecline` 回调，并在调用处传入 `finishAffinity()` 逻辑
3. 实现状态逻辑：点击「同意」时写入持久化标记并跳转；点击「拒绝」时仅执行退出，**不写入**任何同意标记
4. 验证流程：确保已同意用户不受影响（自动跳过），未同意用户每次启动均可见双按钮

## 输出
- 免责声明页底部显示「同意并进入」与「拒绝退出」两个按钮
- 点击「拒绝退出」后应用关闭，且下次启动时再次弹出免责声明及双按钮

## 注意事项
- 关键逻辑在于「拒绝」操作必须**避免**写入同意标记，否则下次将不再展示
- 次按钮样式应明显弱于主按钮（如使用描边而非实心背景），以引导用户选择同意
