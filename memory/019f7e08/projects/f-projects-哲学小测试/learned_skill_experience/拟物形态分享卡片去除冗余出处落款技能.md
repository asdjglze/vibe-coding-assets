## 输入
- 分享卡片模板类型（如信笺风、书页风等拟物形态）
- 当前版面已包含的元数据字段（标题、作者、生卒年等）

## 步骤
1. **检查版面语义**：判断模板是否属于拟物形态（信笺、书页、卷轴等模拟"物"的场景）
2. **评估信息冗余**：若标题、作者、生卒年已完整展示，则禁止额外添加"摘自《xxx》"类出处落款
3. **执行精简**：删除重复的出处行，保留署名/落款即可（署名本身已承载来源语义）
4. **验证布局**：确保最终版面为「标题 → 作者行 → 正文」的简洁结构

## 输出
去除了冗余出处信息的分享卡片模板，版面仅保留必要的元数据层级

## 注意事项
- **核心原则**：拟物形态模拟的是"物"，真实的物上没有"出处标签"，署名/落款即代表来源
- **避免堆砌**：标题、作者、生卒年已构成完整元数据链，无需再用"摘自"重复强调
- **风格适配**：极简几何风排斥具象头像；拟物风排斥多余装饰性文案
