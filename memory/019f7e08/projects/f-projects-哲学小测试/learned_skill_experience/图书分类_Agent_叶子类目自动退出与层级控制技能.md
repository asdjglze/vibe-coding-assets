## 输入
- 当前中图分类代码（code）
- 该代码的子类目信息（通过 get_children/list_tree 获取）

## 步骤
1. **诊断强制残留**：扫描 agent.py 提示词，查找并移除“绝不允许停在还有子类目的层级”、“必须下钻到第X层”等绝对化指令。
2. **修正停止逻辑**：在提示词中明确“默认目标：尽量下钻到第四层”，同时强调“叶子类目（下面没有子类目了）自然停止，程序会自动结束钻入”。
3. **实现叶子检测**：在 `_decide_level_tool` 函数中添加判断：若 `get_children(code)` 返回空列表，直接返回特定提示语（如“这是叶子类目，下面没有子类目，层级钻入自动完成。请直接输出 final”），不再等待 AI 决策 stop。
4. **验证生效**：测试叶子类目（如 TU206）和非叶子类目（如 I247），确认前者直接触发 Final，后者继续推进。

## 输出
- 叶子类目：Agent 收到“自动完成”提示，直接输出 final JSON。
- 非叶子类目：Agent 收到继续下钻的反馈。

## 注意事项
- 区分“总论/专论”规则与“叶子自动退出”：专论书需下钻到具体子类目，而泛论书或叶子类目应直接停止。
- 避免将“尽量第四层”误解为“必须第四层”，实际以内容实质和类目存在性为准。
- 文件夹结构需统一为“分类层 → 作者/年份桶 → 书文件夹”模式，确保所有书文件被文件夹包裹。
