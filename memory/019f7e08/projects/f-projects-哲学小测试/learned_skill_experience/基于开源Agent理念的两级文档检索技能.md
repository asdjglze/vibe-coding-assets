## 输入
- 需要被AI按需检索的本地长文档或知识库

## 步骤
1. **第一级（低成本预览）**：生成高密度清单。对于目录结构，每节附带首行非空文本作为摘要；对于关键词检索，返回命中项列表及摘要，而非直接返回全文。
2. **第二级（按需精读）**：根据第一级的信息密度决定策略。若单节命中或某一项显著领先（如分数≥其他项总和），直接返回该项全文以节省轮数；若多节分散命中，仅返回命中清单，由AI决定是否需要进一步调用工具读取特定条目全文。
3. **检索优化**：支持多词OR检索（拆分关键词分别计分求和），解决整串短语匹配失败的问题。

## 输出
- 带摘要的目录列表
- 命中结果清单（含相关度排序）
- 精选后的单节全文

## 注意事项
- 核心目标是控制Token用量并提高AI定位效率，避免一次性发送大块无关内容。
- 借鉴开源Coding Agent（如Aider Repo-map, Claude Code Grep模式）的设计理念。
