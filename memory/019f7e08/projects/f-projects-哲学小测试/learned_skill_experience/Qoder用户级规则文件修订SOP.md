## 输入
- Qoder 用户级规则文件绝对路径（如 `C:\Users\win-user\.qoder\rules\xxx.md`）
- 需要修改的具体内容或指令

## 步骤
1. **工作区暂存**：使用 `Copy-Item` 将目标规则文件复制到当前项目工作区作为临时副本。
2. **精确修改**：在临时副本上使用 `SearchReplace` 进行精准文本替换，确保格式和缩进无误。
3. **哈希校验**：对比临时副本与目标文件的哈希值（`Get-FileHash`），确认修改完全一致且无意外变更。
4. **回写生效**：将校验通过的临时副本覆盖回原路径。
5. **清理现场**：删除工作区内的临时副本。

## 输出
规则文件成功更新，且与原文件结构/内容逻辑一致。

## 注意事项
- **会话机制**：Desktop IDE 加载的是会话启动时的规则快照，本次修改需开启**新会话**才能生效。
- **权限限制**：Qoder 内置文件编辑工具无法操作工作区外的 `.qoder` 目录，必须使用命令行（PowerShell/Bash）。
- **编码安全**：PowerShell 命令行传中文可能导致多字节字符损坏，若遇乱码应改用 Python 脚本处理。
