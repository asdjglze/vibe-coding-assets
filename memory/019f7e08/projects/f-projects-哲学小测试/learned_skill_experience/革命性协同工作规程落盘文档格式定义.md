## 输入
- 需要落盘的文档类型（会议纪要/规划/纠错/理论/偏好/调查报告）

## 步骤
1. 确定文档类型，选择对应的 `docs/` 子目录和命名规则
2. 按照对应模板填充内容（如会议纪要需包含“用户发言/AI报告/决议”三段式；纠错日志为单文件追加制；理论条目需标注置信度与取代关系）
3. 确保格式要点合规（如推理判断必须记录断案论据，历史错误不可修改只能追加）
4. 将生成的 Markdown 文件保存至指定路径

## 输出
符合《革命性协同工作规程》定义的标准化 Markdown 文档

## 注意事项
- **会议纪要**：小会可精简但“推理判断”和“决议”不可省略；大会必须写完整版。
- **纠错日志**：`errors/error-log.md` 单文件追加，原记录不可修改。
- **理论文档**：被取代的条目标注状态和取代者，保留原文不删除。
- **长期偏好**：仅在用户明确说“以后都”“永远”时才记录，临时指令不入此文件。
- **扩展资源**：完整模板见 `C:\Users\win-user\.qoder\rules\revolutionary-collaboration-protocol.md` 末尾章节
