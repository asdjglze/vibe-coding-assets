## 输入
- 业务对象（如语录、诗词、文章）不存在或为空

## 步骤
1. Repository层：查询不到数据时直接返回 `null`，禁止使用默认值或回退到其他数据源
2. ViewModel层：接收 `null` 并存储到 State 中
3. UI层（Compose）：使用 `?.let { ... }` 包裹组件渲染逻辑，当值为 null 时整个组件块不渲染

## 输出
对应UI卡片完全隐藏，不显示任何空白占位符

## 注意事项
- 严禁在Repository层做“找不到A就找B”的回退逻辑，应严格遵循当前主体的数据完整性
- UI层必须通过控制渲染流来体现数据存在与否，而非渲染一个空的View
