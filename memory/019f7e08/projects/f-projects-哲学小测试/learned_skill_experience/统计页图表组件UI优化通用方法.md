## 输入
- 统计页图表组件的交互与样式调整需求（悬浮窗位置、热力图算法、排行榜文案、人物配色）

## 步骤
1. **悬浮窗容器内钳制**：`ChartTip` 中 `Popup` 的 `offset` 参数是**相对父布局（图表容器）**的局部坐标——直接用图表锚点 `(tip.x, tip.y)` 计算，仅接收 `containerSize` 钳制在容器范围内；**禁止**把锚点换算成窗口坐标再叠加容器窗口位置，否则气泡向右下双重偏移、弹到容器之外。
2. **热力图8级着色**：弃用相对最大值分4级，改为按当天绝对时长分8档（绿→黄→红），阈值分别为 <30m, 30m~1h, 1~2h, 2~4h, 4~6h, 6~8h, 8~12h, ≥12h。
3. **排行榜文案精简**：移除列表项中的时间维度前缀（如“7天”、“30天”），仅保留数值，由上方标签体现维度。
4. **人物固定配色**：建立 `personColorBy` Map，将人物 `styleKey` 映射到固定颜色（毛=红，鲁=藏青），替换原有的取模随机色板，确保全场景（柱状图、图例、悬浮窗）颜色一致。

## 输出
- 悬浮窗不越界且位置贴合点击点
- 热力图显示8级色阶
- 排行榜数值简洁
- 人物颜色固定且无绿色

## 注意事项
- 涉及文件：`StatsCharts.kt` (图表逻辑), `StatsScreen.kt` (UI组装)
- 需同步更新图例和悬浮窗详情中的颜色引用
- 热力图点击定位：行号必须用行高（高/7）计算，列号用列宽（宽-行标签宽）/列数，两者尺寸不同不可混用
- 阅读时长计时需监听生命周期，ON_STOP 结算并暂停、ON_START 恢复，否则后台停留时间被误计入阅读时长
