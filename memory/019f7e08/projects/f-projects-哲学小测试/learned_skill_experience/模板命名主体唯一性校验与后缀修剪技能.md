## 输入
- 模板清单文件（如 manifest.json）
- 模板分类标签（如 tags 含「公司」或「平台」）

## 步骤
1. 提取所有公司/平台类模板的当前名称列表
2. 对每个带修饰后缀的名称，模拟删除后缀后得到主体名
3. 检查主体名在模板池中是否唯一（去重计数）
4. **决策逻辑**：
   - 若主体名唯一 → 删除后缀，只保留主体名
   - 若主体名不唯一（会重名） → 保留原「主体名·修饰词」后缀用于区分
5. 执行批量修改并验证 JSON 合法性与最终零重名

## 输出
- 修改后的模板清单，所有公司/平台类模板名称符合「主体唯一则删后缀」规则
- 验证报告：确认无重名冲突

## 注意事项
- **核心原则**：判断依据是「删后缀后是否重名」，而非模板类型本身
- **例外处理**：产品全名（如微信读书）非「主体+后缀」结构，无需处理
- **验证关键**：修改后必须全局查重，确保零重复
- **适用场景**：适用于任何需要统一命名规范的模板库、资源池管理
