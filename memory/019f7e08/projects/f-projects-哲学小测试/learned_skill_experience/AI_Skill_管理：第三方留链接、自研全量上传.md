## 输入
- AI Agent Skill 列表及其来源属性（第三方开源 vs 本地自研）

## 步骤
1. **分类识别**：判断每个 Skill 的来源。
   - **别人的（第三方）**：仅保留来源链接（如 GitHub URL），以便换设备时重新下载或更新。
   - **自己写的（自研）**：进行全量文件上传/备份，确保代码和配置完整。
2. **执行操作**：根据分类结果，分别生成分享包或备份清单。

## 输出
- 包含正确分类处理的资产分享包或备份记录

## 注意事项
- 不要对第三方 Skill 进行全量上传，节省空间和时间。
- 自研 Skill 必须全量保留，因为可能没有公开源码或版本控制。
