## 输入
- 书籍元数据（包含标签状态、分类字段值）
- 书籍物理存储位置（文件夹路径）

## 步骤
1. **快通道进驻时自动打标**：
   - 若未分类 → 直打「待分类」标
   - 若简介/标签缺失 → 直打「待富化」标
   - 若元数据未核 → 直打「未校对」标
2. **执行任务判定**：
   - 仅依据标签启动对应处理（有标→做，无标→跳过）
   - 忽略“分类字段有值但带标”的旧逻辑，直接以标签为唯一触发源
3. **处理已分类书籍**：
   - 检测到书籍位于分类文件夹结构中 → 读取路径直接转为分类字段登记
   - **绝不启动 AI 分类**，直接归档
4. **兜底复查**：
   - 对无标但字段确实缺失的情况进行补标（防漏标）

## 输出
- 书籍按标签进入对应处理流程或跳过
- 已归档书籍标记为“已归档”，摘除相关标签
- 无需人工干预打标，全流程自动化

## 注意事项
- **核心原则**：标签 = 欠账任务单，逻辑必须直白，禁止组合推理
- **位置即分类**：只要书籍在分类文件夹内，视为已分类，不进入未分类域
- **待人工区锁死**：该区域书籍不参与任何自动判定
