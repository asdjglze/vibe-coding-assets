## 输入
- SQLite 数据库路径
- 需要检测的垃圾内容正则表达式列表

## 步骤
1. **多线程扫描**：使用 `ThreadPoolExecutor` 将文章 ID 范围分片，每个线程独立连接数据库进行只读扫描，汇总结果。
2. **垃圾清理**：查询命中正则的文章，逐行过滤垃圾内容并更新数据库。
3. **异常修复**：若发现垃圾内容与有效正文（如标题）在同一行，需先通过备份或副本文件定位原文上下文，提取有效文本后重新插入，避免误删。

## 输出
- 扫描耗时及各类垃圾残留数量统计
- 清理后的数据库状态确认

## 注意事项
- 多线程扫描时每个线程应创建独立的数据库连接（URI模式 `mode=ro`），避免锁冲突。
- 清理前务必检查垃圾是否混在有效行中，直接整行删除可能导致数据丢失。
