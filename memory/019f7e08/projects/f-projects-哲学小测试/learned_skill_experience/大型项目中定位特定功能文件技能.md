## 输入
- 项目根目录路径
- 目标功能关键词（如'邀请码'、'register'等）

## 步骤
1. **初步扫描**：使用 `Get-ChildItem -Recurse` 列出项目文件结构，注意处理可能的编码乱码问题。
2. **内容搜索**：对关键后缀文件（.py, .js, .php, .html, .json等）使用 `Select-String` 搜索关键词，快速定位包含相关逻辑的文件列表。
3. **结构确认**：查看搜索结果所在目录的完整结构，识别配置文件、脚本文件或模板文件。
4. **引用关系分析**：读取候选文件内容，确认其是否被其他核心逻辑（如后端注册页）引用，区分‘数据定义文件’与‘业务逻辑文件’。
5. **版本辨析**：检查是否存在 `server_backup` 或类似备份目录，明确本地编辑源与线上实际生效文件的对应关系。

## 输出
- 目标功能对应的具体文件路径
- 该文件在项目中的角色（如：数据源、逻辑入口、备份副本）
- 线上生效文件与本地文件的映射说明

## 注意事项
- Windows PowerShell 环境下文件名可能因编码显示为乱码，建议结合文件扩展名和内容特征判断。
- 务必区分开发环境的本地文件与服务器的实际运行文件，修改前需确认同步机制。
