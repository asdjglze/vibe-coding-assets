## 输入
- 用户明确要求保持模板字体引用不变
- 需要让特定档位（如 Mini）包含缺失的字体资源

## 步骤
1. 检查并恢复分享模板 HTML 中的 `@font-face` 引用，确保指向正确的本地字体文件路径
2. 定位构建打包脚本（如 `build_pack.ps1` 或 `build.gradle`）
3. 在脚本的字体清单数组（如 `$ShareKeys` 或 `fonts` 列表）中添加缺失字体的标识符
4. 更新档位说明注释，确认该档位字体数量变化

## 输出
模板文件未被修改，仅打包脚本更新了字体依赖清单，目标档位成功包含所需字体

## 注意事项
- 核心原则：当用户要求“保留模板原样”但需增加字体时，应优先修改构建配置而非直接编辑模板文件
- 需确认字体源文件是否存在且有效（如文件大小异常可能表示文件损坏）
