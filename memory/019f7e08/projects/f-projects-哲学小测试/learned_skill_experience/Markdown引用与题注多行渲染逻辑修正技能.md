## 输入
- Markdown格式的引用或题注内容

## 步骤
1. 识别引用块（`>`）或题注标记
2. 解析引用块内的多行文本逻辑：在markdown-it中，引用块内的多行文本通常会被合并为一个段落（`<p>`标签），即使中间有空行或无`>`前缀的续行
3. 确保题注渲染逻辑与引用块保持一致，特别是多行内容的包裹和换行处理
4. 验证渲染后的HTML结构是否符合预期（如`<blockquote>`包含`<p>`）

## 输出
正确渲染的HTML结构，引用和题注的多行内容被正确处理

## 注意事项
- 必须实测markdown-it的实际渲染行为，而非仅凭假设
- 引用块内的多行逻辑需特别注意，避免错误地分割或忽略内容
