## 输入
- 需要修改阅读设置（如背景色、字体）
- 需要改变阅读模式（如从滚动切换到翻页）

## 步骤
1. **拦截直接操作**：在触发关键变更（如切换翻页模式）时，不直接应用，而是设置 `pendingPaging` 等中间状态。
2. **展示文学化确认弹窗**：使用 `AzDialog` 展示变更后果（如排版自动调整、分享关闭、动画关闭），文案需兼具文学性与严谨性。
3. **提供三选一决策**：
   - **一并改之**：切换模式 + 应用预设排版（如纯白底、纯黑字、黑体）。
   - **仅换模式**：仅切换模式参数，保持现有排版。
   - **维持原样**：取消操作，回滚状态。
4. **处理副作用**：根据最终选择更新 `ReaderSettingsStore`，并同步 UI 状态（如翻页模式下隐藏分享按钮）。

## 输出
用户完成确认后，阅读页按选定配置渲染；若取消则恢复原状。

## 注意事项
- **文案风格**：按钮和提示语应避免枯燥列表，采用带有文学色彩的短句（如“一并改之”、“雪宣纯白”）。
- **墨水屏特性**：翻页模式默认关闭分享功能（框选不弹分享），但保留收藏功能。
- **色板分排算法**：色板圆点需自适应分行。计算行数 $R = \lceil N / C \rceil$（$N$为总数，$C$为每行最大数）。分配策略：优先保证前 $R-1$ 行满额，最后一行补齐；若余数导致最后一行过少，则从上到下微调使各行数量差值最小（不超过1格）。
