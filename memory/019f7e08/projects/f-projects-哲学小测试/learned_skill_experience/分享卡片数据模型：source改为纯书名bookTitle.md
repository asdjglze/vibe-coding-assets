## 输入
- 分享卡片生成需求

## 步骤
1. **数据结构定义**：在 `ShareCardData` 等数据类中，使用独立的 `bookTitle` 字段存储纯书名，彻底删除 `source` 字段。
2. **移除拼接逻辑**：在调用方（如 `ReaderScreen.kt`）直接透传 `uiState.bookTitle`，严禁在此处拼接「摘自《》」或「 > 篇名」。
3. **前端兼容映射**：在渲染脚本（如 `share_core.js`）中增加兼容逻辑，将旧模板的 `data-field="source"` 统一映射到 `bookTitle`，防止旧模板报错。
4. **展示权下放**：模板自行决定如何显示书名（加不加书名号、是否写「摘自」等），App 端只负责提供纯净数据。

## 输出
- 数据结构中仅有 `bookTitle` 字段，值为纯书名（如「毛泽东诗词」）。
- 预览工具及 App 端均按新结构传递数据。

## 注意事项
- **核心原则**：结构化字段各自独立，禁止在数据层进行展示层的拼接。
- **兼容性**：必须保留对旧模板 `source` 字段的兼容映射，确保平滑过渡。
