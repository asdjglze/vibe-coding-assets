## 输入
- 桩号数值数组（如 [0, 11.5, 18.3]）
- 工程量元数据及对应数据

## 步骤
1. **桩号格式化**：将数值转换为 `Kx+xxx` 格式。核心逻辑：`km = floor(n/1000)`，`rem = n - km*1000`，整数部分补零，小数部分使用 `toFixed(3).replace(/0+$/,'').replace(/^0/,'')` 去除前导零。
2. **构建阶梯行结构**：遍历每个桩号，为每个桩号生成两行 HTML `<tr>`。
   - 第1行：桩号单元格设置 `rowspan=2`。
   - 第2行：间距单元格设置 `rowspan=2`，实现与下一桩号第1行的错位合并。
3. **分配工程量显示**：在间距合并的两行中，第一行显示计算式+数值，第二行仅显示数值。
4. **样式控制**：合并单元格需设置 `vertical-align: middle` 确保垂直居中。

## 输出
符合工程计量规范的交错合并表格 DOM 结构，桩号列与间距列呈阶梯状分布。

## 注意事项
- 桩号小数处理时，避免直接拼接导致出现 `K0+011.0.5` 这种双重小数点错误，应先分离整数和小数部分再分别格式化。
- 最后一个桩号的间距格应为空，防止多余合并。
