## 输入
- 拥有完整源代码的项目环境
- 需要排查前端页面功能或数据展示问题的场景

## 步骤
1. 放弃外部工具（如浏览器访问、网络抓包）作为首要手段
2. 直接读取项目源码文件（如 `router.js` 路由配置、`App.vue` 主组件、业务组件文件）
3. 搜索关键功能关键词（如统计名称、状态标签、API 接口名）定位相关代码逻辑
4. 分析代码中的数据处理流和渲染逻辑以定位问题根源

## 输出
成功定位到实现特定功能的代码文件或逻辑块，明确问题所在

## 注意事项
- 当拥有源码时，优先从代码层面排查，避免在无源码情况下盲目猜测或仅依赖运行结果
- 结合路由文件和组件树结构快速缩小搜索范围
