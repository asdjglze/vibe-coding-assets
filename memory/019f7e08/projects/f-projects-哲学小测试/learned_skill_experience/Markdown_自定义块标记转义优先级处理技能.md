## 输入
- 自定义块标记（如 [诗]/[题]/[抬]/[款]）存在惰性延续逻辑
- 用户输入包含转义字符（\ 或 /）后接块标记（如 \[诗] 或 /[诗]）
- 需确认转义后的字面文本是否会被误识别为块或吸进延续块

## 步骤
1. **定义转义正则**：`^[\\/](\[(?:副|题|抬|款|诗)\].*)$`，匹配行首反斜杠或斜杠后紧跟块标记。
2. **提升优先级**：在解析循环最前端检查转义行，若匹配则立即剥离转义符，作为普通正文行处理，不进入任何块标记分支。
3. **打断延续逻辑**：在所有块标记（[题]/[诗] 等）的惰性延续判断中，加入转义行检测；遇到转义行时强制结束当前块的延续，将转义行视为普通文本。
4. **同步纯文本渲染点**：在桌面组件、诗词兜底等纯文本提取函数中，先剥离转义符，再执行其他前缀移除（如 `[诗]`），防止字面标记被误剥。

## 输出
- 转义行（如 `\[诗]xxx` 或 `/[诗]xxx`）显示为字面文本 `[诗]xxx`，不渲染为格式块
- 转义行不会吸进前后块的惰性延续中，正确打断结构
- 全页无转义符残留（`\` 或 `/` 被剥离）

## 注意事项
- 核心原则：转义符优先级高于一切块标记和延续逻辑
- 该策略适用于所有同族自定义块标记（[副]/[题]/[抬]/[款]/[诗]），避免逐个修改
- 正则需精确匹配行首，避免误伤路径中的反斜杠（如 `C:\path`）或注释行（`//`）
