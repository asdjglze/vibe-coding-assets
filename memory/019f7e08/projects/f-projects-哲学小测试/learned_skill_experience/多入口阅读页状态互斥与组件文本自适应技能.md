## 输入
- 多入口进入同一阅读页（如书架恢复进度 vs 首页语录定位跳转）
- 固定尺寸容器内显示不定长文本（如桌面小组件显示语录/诗词）

## 步骤
1. **解决滚动控制权抢占**：
   - 识别冲突点：多个 `LaunchedEffect` 同时监听状态变化并操作滚动位置。
   - 实施互斥：在进度恢复逻辑中增加前置判断条件（如 `jumpBlockIndex < 0`），确保在有更高优先级定位任务时跳过进度恢复。
2. **实现固定容器内的文本自适应**：
   - 放弃固定行数截断方案，改为动态计算。
   - 优先使用原字号尝试排版全文。
   - 若超出容器高度，采用二分查找法在 `[最小字号, 原字号]` 区间内寻找能容纳全文的最大字号。
   - 设定最小字号下限（如 11sp），低于下限时仍按固定行数截断省略号作为兜底。

## 输出
- 阅读页根据入口类型正确执行定位或恢复进度，无闪烁或错位。
- 桌面组件中的语录/诗词在不同尺寸下均能最大化展示全文，仅在极小尺寸下截断。

## 注意事项
- 进度恢复公式通常为 `pct = (scroll + viewport/2) / (max + viewport)`，需根据实际 UI 结构调整。
- 桌面组件渲染使用 Canvas/StaticLayout，性能敏感，二分查找次数不宜过多（10轮足够收敛）。
