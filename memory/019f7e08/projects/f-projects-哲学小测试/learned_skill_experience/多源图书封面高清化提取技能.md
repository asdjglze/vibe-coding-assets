## 输入
- 图书来源（豆瓣/微信读书/PDC）
- 原始封面 URL

## 步骤
1. **豆瓣**：将 URL 中的 `/s/public/` 替换为 `/l/public/` 获取大图；下载时必须添加 `Referer: https://book.douban.com/` 头，否则会被 HTTP 418 拒绝。
2. **微信读书**：尝试将 URL 文件名前缀从 `s_` 替换为 `b_`（最大公开档）；若 `b_` 返回 404，则回退到 `m_`。
3. **PDC**：优先使用详情页的 `f_image`（大图）而非列表页的 `image`（小图）。

## 输出
- 豆瓣：1080x1564 / 180KB
- 微信读书：140x200 / 26KB
- PDC：详情大图

## 注意事项
- 清晰度必须在入池时解决，AI 无法凭空变出高清图。
- 通用下载器默认不带 Referer，针对豆瓣必须显式添加。
