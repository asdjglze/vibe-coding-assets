## 输入
- 需要自动完成网页登录并提取认证令牌（如Cookie/Token）
- 目标网站可能检测自动化特征或存在跳转逻辑

## 步骤
1. **启动独立浏览器**：使用 `msedge.exe` 或 `chrome.exe` 启动一个独立的浏览器实例，通过 `--remote-debugging-port=9223` 开启 CDP 端口，确保浏览器进程与脚本分离。
2. **持久化配置**：指定 `--user-data-dir` 指向项目工作区内的目录（如 `state/pdc_browser`），避免使用临时目录导致会话丢失。
3. **等待与探测**：脚本通过 HTTP 请求 `http://127.0.0.1:9223/json` 获取目标页签的 WebSocket URL 和状态，轮询间隔建议 1.5秒。
4. **提取令牌**：一旦检测到目标页面加载完成，通过 CDP 协议执行 JS 或直接读取本地存储文件（如 `Local Storage/leveldb`）中的 Token。
5. **验证与落盘**：将提取的 Token 写入配置文件，并通过业务接口（如搜索 API）进行验证，确认有效性。

## 输出
- 浏览器独立运行在指定端口，用户可手动交互登录。
- 脚本成功捕获 Token 并写入本地文件，后续任务可直接使用该 Token。

## 注意事项
- **避免 Playwright/Puppeteer 托管模式**：对于容易触发反爬或页面自关的网站，托管模式极易因 TargetClosedError 崩溃且无法恢复。
- **会话持久化**：务必使用固定的 User Data Dir，否则关闭浏览器后所有登录状态清零。
- **权限问题**：Windows 下查询进程可能需要管理员权限，若遇拒绝访问需调整执行环境。
