## 输入
- 同一目录下相同扩展名的多个文件列表
- 每个文件的文件名、大小、页数（PDF）、开头文字、结尾文字等元数据

## 步骤
1. **程序预处理（绝对可靠）**：按文件大小聚类，计算SHA256哈希值。完全相同的文件视为重复，只保留一份，其余移入备份目录（如`_merged_src`），不参与后续AI判断。
2. **构建AI提示词**：将剩余文件的元数据（文件名、大小、页数、首尾文本）整理成结构化证据，发送给LLM。
3. **LLM语义判定**：让AI根据内容线索判断文件间关系，输出JSON格式结果：
   - `split`：同书拆分（如上下卷、章节连续），需按顺序拼接。
   - `separate`：独立书籍/系列册（如《史记》第一册/第二册，各自成书不接续），保持独立。
   - `mixed` / `unknown`：证据不足或关系复杂，保持独立，不强行合并。
4. **执行操作**：根据AI返回的JSON结果，对标记为`split`的文件进行物理拼接；其他情况保持原样。

## 输出
- 重复文件已去重备份
- 确认为分卷的文件已合并为单一文件
- 确认为独立书籍或关系不明的文件保持独立状态

## 注意事项
- 禁止使用文件名正则（如`(1)(2)`、`001/002`）作为合并依据，这些特征可能对应重复文件或系列册，必须通过内容语义由AI判断。
- 缓存机制：记录判定结果的目录指纹，若文件未变动则跳过重复AI调用以节省成本。
