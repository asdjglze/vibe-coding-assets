## 输入
- Compose UI 组件交互异常（如点击无效、手势冲突）
- 分页/列表渲染异常（如内容重叠、溢出）

## 步骤
1. **排查事件拦截**：检查是否存在兄弟节点重叠且层级不当的情况。若上层组件（如 SelectionContainer）拦截了所有点击，下层热区将失效。修法：移除独立覆盖层，将检测逻辑移至同层（如使用 detectTapGestures），利用长按与短按的手势差异共存。
2. **排查间距计算**：在自定义分页/排版算法中，确认间距变量是“相对值”还是“绝对累积值”。若将绝对位置误作相对间距直接累加，会导致内容严重溢出重叠。修法：记录 `currentTop - prevBottom` 作为真实间距。
3. **排查测量偏差**：检查渲染时的内边距（Padding）是否同步扣除了测量宽度，防止因换行预估不准导致的高度溢出。

## 输出
修复后的 UI 交互恢复正常，内容排版准确无重叠。

## 注意事项
- Compose 兄弟节点事件互斥：上下重叠的 Box 无法共享事件，需在同层处理或调整层级。
- 墨水屏阅读器常采用“全文常驻内存 + 位移”方案，而非 HorizontalPager，以避免残影并支持精准定位。
