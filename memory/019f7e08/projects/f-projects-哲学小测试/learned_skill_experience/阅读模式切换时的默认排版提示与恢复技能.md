## 输入
- 用户在阅读页设置中切换阅读模式（如翻页/滚动）
- 需要告知用户切换后可能发生的排版变化（字体、字色、背景色等）

## 步骤
1. **定义默认排版预设**：在 `ReaderSettingsStore` 中为每种模式定义 `xxxPreset()` 方法，返回该模式的默认排版配置（如 `scrollPreset` 恢复宋体、墨色、茧纸底色；`pagingPreset` 恢复黑体、白底等）。
2. **添加切换确认状态**：在 UI 层（如 `ProfileScreen`）增加 `pendingScroll` / `pendingPaging` 布尔状态，用于控制弹窗显示。
3. **拦截切换操作**：当用户点击切换按钮时，不直接生效，而是将对应 `pending` 状态设为 true，触发弹窗。
4. **实现确认弹窗**：弹窗正文明确说明切换后的默认排版内容（如“宋体、墨色文字、茧纸底色”），并提供选项：
   - “恢复默认排版”：调用 `settings.copy(pagingMode = false).scrollPreset()` 同时应用新模式和默认样式。
   - “保持当前排版”：仅调用 `settings.copy(pagingMode = false)` 切换模式但保留当前样式。
   - “暂不切换”：取消操作。
5. **编译与打包验证**：确保修改后能正常编译并通过构建脚本生成 APK。

## 输出
用户在选择切换模式时看到明确的提示弹窗，可选择是否同步恢复默认排版，且切换后功能正常。

## 注意事项
- 弹窗设计应与现有类似场景（如翻页切换）保持对称，降低用户学习成本。
- 默认排版值应取自系统常量（如 `COLOR_INK`, `FONT_SONG`），避免硬编码字符串导致不一致。
- 切换模式不应影响书签、收藏和阅读进度等独立数据。
