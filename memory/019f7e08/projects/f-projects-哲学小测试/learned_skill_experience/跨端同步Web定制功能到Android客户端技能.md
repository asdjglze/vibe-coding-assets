## 输入
- Web端已实现的定制需求（如：中国万位分组显示、特定标签置顶预置）
- 目标平台为Android OPDS客户端（Kotlin源码）

## 步骤
1. **定位对应UI组件**：在Android项目中找到与Web端对应的视图逻辑（如首页分类按钮、列表项文本渲染）。
2. **实现通用格式化函数**：将Web端的JS逻辑移植为Kotlin工具函数（如`formatCnCount`实现4位一逗号的中国万位分组），确保算法一致。
3. **植入业务逻辑**：
   - **数据展示**：在UI构建处调用格式化函数替换原始数字。
   - **预置支持**：若Web端有“预置标签”（即数据尚未上线但前端需预留位置），在排序表和书签栏中硬编码该标签优先级，并处理无数据时的状态（如置灰或隐藏）。
4. **编译验证**：使用Gradle进行Debug构建，确认无语法错误且APK生成成功。

## 输出
- 包含新功能的Android APK文件
- 功能表现与Web端保持一致（格式、排序、交互）

## 注意事项
- **数据一致性**：若涉及标签排序等逻辑，需确认服务器端数据现状（是否已上线），避免前端硬编码与实际数据冲突。
- **算法移植**：注意语言差异，如JS的正则表达式需转换为Kotlin的字符遍历或正则逻辑。
