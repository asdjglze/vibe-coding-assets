## 输入
- SQLite 数据库文件路径
- 去重规则定义（如：同书同 refId 同标题视为重复；或同内容不同编号视为重复）

## 步骤
1. **统计阶段**：编写只读脚本，按去重键（如 `(bookId, refId, title)`）分组，统计重复组数和具体条目，区分 A 类（完全重复）和 B 类（指向错误）。
2. **备份阶段**：在执行任何修改前，使用 `shutil.copy2` 备份整个数据库文件。
3. **清洗阶段**：
   - 遍历重复组，根据优先级（后代数量最多 -> sortOrder 最小 -> id 最小）确定保留项。
   - 递归收集待删条目的所有子节点（树结构清理）。
   - 开启事务，按 ID 降序删除（避免外键/顺序问题），提交事务。
4. **验证阶段**：再次运行统计脚本，确认重复组数为 0，且总条目数减少量与预期一致。

## 输出
- 数据库文件中重复条目被移除，仅保留一条（含其子树）
- 生成日志文件记录删除明细
- 验证脚本输出显示重复组数为 0

## 注意事项
- **排序空值处理**：在 Python `sorted` 中，若关键字段可能为 `None`，需使用 `key=lambda x: (x[0], x[1] or 0, ...)` 避免 `TypeError`。
- **树结构清理**：删除父节点时需递归收集并删除所有子节点，防止孤儿数据。
- **事务安全**：批量删除操作必须包裹在 `BEGIN...COMMIT` 事务中，确保原子性。
- **扩展资源**：SQLite 外键约束可能导致删除顺序敏感，建议先查表结构确认依赖关系。
