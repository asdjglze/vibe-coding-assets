## 输入
- 待处理的文件路径及扩展名

## 步骤
1. **程序级加密检测**：在读取正文前，先调用专用函数检测文件是否加密。
   - PDF：使用 PyMuPDF 检查 `doc.needs_pass` 或 `doc.is_encrypted`。
   - EPUB/ZIP：使用 zipfile 检查 `info.flag_bits & 0x1`。
2. **分级处理与上下文注入**：
   - 若检测到加密，将原因字符串（如“PDF已加密...”）写入上下文 `locked` 字段。
   - **开场白告知**：在 Prompt 中显式插入【正文不可读】段，指令 AI 放弃读取正文，改用文件名+联网查询。
   - **跳过渲染**：直接跳过初始图片提取（避免无效计算）。
3. **运行时拦截**：若 AI 仍尝试 `read_slice` 或 `view_images`，程序返回拦截提示，强制其转向搜索工具。
4. **决策修正**：更新 Agent 系统提示词，明确“加密≠退出”，仅彻底损坏才中途退出；查无果则 refuse。

## 输出
- 加密文件被正确识别，AI 不再浪费轮数读取正文，而是基于元数据/文件名完成分类或拒绝。

## 注意事项
- 必须区分“加密”、“损坏”和“纯图片/扫描版”。只有程序判定为“彻底损坏无法解析”时才允许中途退出（manual）。
- 加密检测需放在 `_full_text_of` 之前执行，避免异常掩盖真实原因。
