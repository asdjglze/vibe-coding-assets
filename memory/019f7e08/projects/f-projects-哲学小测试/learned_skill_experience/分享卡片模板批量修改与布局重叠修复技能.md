## 输入
- 分享卡片模板修改需求列表（包含文案替换、布局调整、装饰元素增删）
- 涉及的模板文件路径

## 步骤
1. **文案短词化**：批量搜索"分享自阅读笔记"等长文案，根据上下文替换为"今日阅读分享"或"阅读摘录"等短词，确保字数匹配。
2. **布局重叠修复**：当图标/文字与正文重叠时，将元素的 `position: absolute` 改为 `float: right`（配合 `clear: both`），利用流式布局自动避让。
3. **品牌标识替换**：将特定品牌的 Logo 图形替换为毛体"思"字，保持原颜色/形状风格，使用 `@font-face` 引入字体。
4. **视觉风格调整**：
   - 单色条改为四色渐变（如 Google 蓝红黄绿）
   - 磨砂玻璃底色改为夜空渐变 + 星点背景
   - 新拟态恢复内阴影凹陷效果
5. **装饰元素清理**：删除冗余 ornament/badge/footer 等元素。

## 输出
- 修改后的 HTML/CSS 文件
- 浏览器预览中无重叠、文案正确、风格符合预期

## 注意事项
- **核心原则**：UI 元素添加需克制，装饰品保留，仅品牌位替换；重叠问题优先用流式布局（float）而非绝对定位。
- **扩展资源**：毛体字体路径 `f:\projects\maoyulu\app\src\main\assets\fonts\maoti_si.ttf`
