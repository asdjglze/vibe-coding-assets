## 输入
- 语录文本（待匹配）
- 文章正文内容（Markdown格式）

## 步骤
1. **规范化清洗**：对语录和正文分别进行两轮处理：
   - 去除注码标记（如 `[^1]`, `[1]`, `[*]`）
   - 移除所有非汉字/字母/数字字符（包括句号、逗号、省略号、全半角标点、空格、制表符、换行符及 Markdown 标记符号 `>`, `#`, `-`, `*` 等）
2. **精确匹配**：检查清洗后的语录是否完整包含在清洗后的某一段落块中
3. **窗口投票**：若精确匹配失败且语录长度≥8字，将语录切分为多个8字连续窗口，统计每个窗口在正文各段落中的命中次数，选择命中数最多且≥2次的段落作为目标
4. **指纹兜底**：若窗口投票未命中，取清洗后语录的前6字作为指纹，查找包含该指纹的段落

## 输出
- 匹配成功的段落下标（或 -1 表示未找到）
- 匹配类型（exact/first/fp/miss）

## 注意事项
- 清洗规则必须两侧一致，确保只保留核心语义字符
- 窗口投票法能有效容忍语录与正文间的个别错字、缺字或版本异文
- 适用于语录摘录自长文但存在标点/格式差异的场景
