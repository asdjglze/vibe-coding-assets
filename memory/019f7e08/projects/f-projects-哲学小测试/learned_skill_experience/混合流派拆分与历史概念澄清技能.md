## 输入
- 待拆分的混合流派名称（如'社会民主'）
- 该流派下所有人员清单及简介
- 细分依据（如是否属于马克思主义谱系、具体历史定位）

## 步骤
1. **数据探查**：查询原流派下所有人员清单，确认待变更对象总数。
2. **制定方案**：基于历史事实或用户指令，明确细分规则（如将'社会民主'拆分为'第二国际'【马克思主义谱系】和'社会民主'【非马改良派】）。
3. **执行变更**：编写 SQL UPDATE 语句定向修改特定人员流派，同时处理批量重命名或归类。
4. **双重校验**：
   - 检查关键人物是否准确归位（断言影响行数=1）。
   - 遍历全库校验：人物唯一性、流派名长度限制（≤5字）、无未分配人员。
5. **多库同步**：对本地开发库和打包资源库分别执行上述流程。

## 输出
- 数据库变更成功，关键人物流派修正无误。
- 全量校验通过（人数、流派数统计正常，无重复/超长/未分配错误）。
- 项目编译构建成功（BUILD SUCCESSFUL）。

## 注意事项
- 涉及跨类人员时，需依据具体历史定位精准拆分，避免简单按记忆名单硬编码。
- 建议采用“先查后改再校验”的流程，而非直接凭记忆写入计划表，防止遗漏或重复。
- 确保所有流派名称符合系统长度限制（通常≤5字）。
- 对于历史概念混淆的流派（如马克思主义与非马左翼混同），必须显式拆分以体现理论差异。
