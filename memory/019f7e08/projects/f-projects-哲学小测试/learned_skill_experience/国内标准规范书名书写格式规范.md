## 输入
- 原始标准编号（可能粘连或空格不规范）
- 标准名称

## 步骤
1. **编号规范化**：调用 `fmt_std_number(num)` 处理。
   - 强制国标/行标 (AQ, GB 等)：代号 + 空格 + 序号。例：`AQ1058-2008` → `AQ 1058-2008`
   - 推荐标准 (GB/T, JGJ/T 等)：代号 + 空格 + 序号。例：`GB/T20004.1-2016` → `GB/T 20004.1-2016`
   - 地标 (DB)：代号 + 空格 + 省码 + /T(可选) + 序号。例：`DB11/1612-2019` → `DB 11/ 1612-2019`
   - 特殊族 (JTG/JTJ)：保持原样连写。
2. **书名组装**：调用 `fmt_std_title(number, name)`。
   - 将名称中的半角冒号替换为全角冒号。
   - 拼接格式：`[规范后的编号]：[名称]`。

## 输出
符合官方权威源书写的标准书名，如 `AQ 1058-2008：煤矿瓦斯检查工安全技术培训大纲及考核标准`。

## 注意事项
- 所有标准书名必须严格采用【代号 序号 - 年号：标题】格式。
- 编号与标题之间必须使用全角冒号（：）分隔，严禁使用空格分隔。
- 图集号和政策文件不受此规则影响。
