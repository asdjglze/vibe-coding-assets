## 输入
- 目标规则文件路径：`C:\Users\win-user\.qoder\rules\revolutionary-collaboration-protocol.md`
- 模块名称变更（如：`令行禁止` → `一切行动听指挥`）
- 新总纲内容

## 步骤
1. **复制暂存**：将规则文件复制到工作区临时文件 `_tmp_rule.md`。
2. **定位并替换**：使用 `SearchReplace` 修改模块标题、总纲文本。
3. **清理同根源引用**：检查并替换其他模块的关系表、全框架总表、流程简图中对该模块的旧称引用。
4. **残留验证**：使用 `Grep` 全文搜索旧名称，确保匹配数为 0。
5. **回写与校验**：将临时文件覆盖回原路径，并使用 `Get-FileHash` 对比新旧文件哈希值，确认一致后删除临时文件。

## 输出
规则文件已更新，旧名称在全局范围内无残留，哈希校验通过。

## 注意事项
- Qoder Desktop IDE 会加载用户级规则作为会话快照，修改需**新会话**生效。
- 必须清理所有关联引用（表格、流程图等），否则会导致上下文不一致。
