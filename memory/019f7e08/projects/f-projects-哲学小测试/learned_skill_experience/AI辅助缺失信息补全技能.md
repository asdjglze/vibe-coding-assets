## 输入
- 目标对象元数据（如书名、路径）
- 缺失的目标字段（如出版社）

## 步骤
1. **构建证据**：提取对象的正文前段文本，并渲染关键页（如封面、版权页）为图片。
2. **编写提示词**：明确判断依据的优先级（如实印版权页 > 网络检索），规定禁止行为（如禁止用编制单位顶替出版社），要求输出标准JSON格式。
3. **调用LLM**：将文本和图片传入模型，设置 `expect_json=True`。
4. **工具交互循环**：若模型返回工具请求（如 `read_pages` 翻页或 `web_search` 联网），执行工具并将结果追加到历史中，继续请求模型输出最终JSON；若无工具请求则直接取结果。
5. **清理与记录**：清理临时图片，记录日志及统计计数。

## 输出
- 目标字段的准确值；若无法确证则返回空字符串（宁缺毋滥）。

## 注意事项
- **外部化规范**：提示词应独立存放在 skills 目录下，便于维护。
- **防幻觉纪律**：在提示词中明确禁止猜测，必须基于实印证据或确凿来源。
- **容错处理**：捕获 LLM 异常，确保流程不中断。
