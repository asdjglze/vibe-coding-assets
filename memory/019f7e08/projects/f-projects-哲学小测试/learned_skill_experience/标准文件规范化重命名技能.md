## 输入
- 标准/图集文件的原始文件名
- 元数据中的标准号（std_number）和标准名称（title）

## 步骤
1. **名称清洗**：剥去书名号《》、压缩连续空白、去除首尾连接符/点缀符，得到干净的标准名称。
2. **构建标准名**：优先使用「标准号 + 空格 + 标准名称」格式；若仅有名称则直接使用；兜底为清洗后的原文件名 stem。
3. **长度控制**：复用跨平台预算机制（单段上限约47字，整路径预算约236字符），对超长名称进行两级截短，确保扩展名保留且主干可读性（≥20字）。
4. **归档落库**：将处理后的名称用于书文件夹名和内部文件名。

## 输出
符合规范的标准化文件路径，无下载站垃圾前缀，长度在系统限制内。

## 注意事项
- 必须保证扩展名不被截断。
- 标准号与名称拼接时注意空格分隔。
- 依赖 `organizer.py` 中的 `_budget_name` 和 `_clip` 函数实现长度控制。
