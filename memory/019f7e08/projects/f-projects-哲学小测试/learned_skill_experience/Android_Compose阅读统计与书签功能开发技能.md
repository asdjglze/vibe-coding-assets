## 输入
- 需要实现阅读进度（书签）和时长统计功能
- 现有内容库（Room）

## 步骤
1. **数据层隔离**：创建独立的 `StatsDatabase`（如 `stats.db`），与内容库分离，防止内容库被 assets 覆盖导致用户数据丢失。
2. **实体设计**：定义 `ReadProgress`（书签，取历史最大值）和 `ReadSession`（时长会话）实体及对应 DAO。
3. **进度记录逻辑**：在 ViewModel 中注入统计仓库；在 UI 层通过 `snapshotFlow` 监控滚动状态，停止后写库；处理边界情况（翻到底直接置 100%，内容不足一屏打开即 100%）。
4. **时长记录逻辑**：进入篇目开始计时，每 30s 增量结算一次，切换篇目或退出页面时兜底结算剩余段。
5. **UI 展示**：在目录抽屉显示每篇进度徽章；在书架封面底部显示整书进度条；在设置页新增统计入口，使用 Canvas 自绘折线图/柱状图展示多维统计。

## 输出
- 独立的统计数据库文件
- 阅读进度持久化（含暴力 100% 逻辑）
- 阅读时长自动记录与聚合
- 完整的统计图表页面

## 注意事项
- 必须使用独立数据库存储用户数据，避免与预打包内容库混淆。
- 进度更新需遵循“先读后写，非递增跳过”原则以保证取最大值。
- 绘制图表时需正确导入 `androidx.compose.ui.text.drawText`，而非不存在的 `drawscope.drawText`。
