## 输入
- 需要批量修改包含特殊字符（如书名号、间隔号）的配置文件或脚本中的字符串
- 目标是将旧字段名（如 `source`）替换为新字段名（如 `bookTitle`）并更新对应值

## 步骤
1. **读取文件**：使用 `[System.IO.File]::ReadAllText($path, [System.Text.Encoding]::UTF8)` 读取完整内容
2. **构造码点字符串**：
   - 定义辅助函数 `function C($s) { $r = ""; foreach ($cp in $s) { $r += [char]$cp }; return $r }`
   - **关键**：先独立构造各段变量（如 `$seg1`, `$seg2`），再拼接成完整字符串（`$la = $seg1 + $sp + $dot + ...`），**严禁**在表达式中间直接调用函数（如 `C @(...)` 会导致语法错误）
3. **执行替换**：使用 `$c.Replace("\"source\": \"" + $old + "\",", "\"bookTitle\": \"" + $new + "\"")` 进行精确替换
4. **验证结果**：
   - 检查剩余旧字段数量（`[regex]::Matches($s, 'source').Count`）应为 0
   - 检查新字段是否存在且码点正确
5. **重新生成**：运行相关构建脚本（如 `python gen_template_preview.py`）刷新产物

## 输出
- 源文件中的旧字段被成功替换为新字段
- 生成的预览/构建产物中显示正确的名称和字段结构

## 注意事项
- **PowerShell 语法陷阱**：在字符串拼接表达式中，不能直接在 `+` 操作符后裸调函数（如 `C @(0x...)`），必须先将函数返回值赋给变量再拼接
- **Unicode 编码**：涉及中文、标点符号时，务必使用码点（如 `0x6BDB`）构造字符串，避免 IDE 保存导致的乱码问题
- **幂等性**：替换前确认旧字符串完全匹配（包括空格、标点），否则替换失败
