## 输入
- 场景：App 内搜索功能，需保留用户最近一次搜索的关键词及命中结果列表
- 约束：不仅保留搜索词，还需保留“搜出来的内容”；跨页面/重启 App 后能自动恢复；支持快速连续输入时的竞态防护

## 步骤
1. **持久化设计**：在 SettingsStore 中仅保存 `bookKey` + `keyword` + `regex` 三元组，不直接存结果列表（避免数据陈旧）。
2. **恢复逻辑**：进入书籍时，优先读取初始传入词；若无则从 SettingsStore 加载最近记录，并立即触发异步重搜以恢复命中列表。
3. **更新策略**：每次搜索成功或用户主动清空时，同步更新持久化记录（空词即清除记录）。
4. **竞态防护**：为搜索请求分配递增序号（searchSeq），丢弃过期返回结果，防止旧数据覆盖新状态。

## 输出
用户再次进入该书或切换文章后，搜索框自动填充上次关键词，且命中列表完整恢复（数据实时重查，非缓存陈旧数据）。

## 注意事项
- 核心原则：只存“查询意图”，不存“查询结果”；结果由最新意图实时生成，保证数据新鲜度。
- 性能优化：恢复逻辑异步执行，不阻塞阅读页初始化。
- 边界处理：书架入口带词进入时，若此前无记录，按入口词执行；若已有记录且 bookKey 匹配，则忽略入口词（以本地记录为准）。
