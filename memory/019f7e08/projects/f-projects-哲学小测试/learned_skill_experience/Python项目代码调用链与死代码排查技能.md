## 输入
- 项目根目录路径
- 需要排查的文件或函数名

## 步骤
1. **定位活跃入口**：使用 `grep` 或 Python 脚本搜索核心入口函数（如 `run.py`、`main.py`），确定当前实际执行的代码路径。
2. **追踪函数调用**：在核心入口文件中搜索关键业务函数（如 `recognize_meta`, `classify_one_book`），记录其被调用的行号和上下文。
3. **全量扫描引用**：遍历所有相关源文件（`.py`），搜索目标函数或模块名的出现位置，区分“定义处”和“调用处”。
4. **对比模板文件**：列出提示词/配置文件目录下的所有文件，结合代码搜索结果，标记哪些文件被实际引用，哪些是死代码。
5. **生成调用地图**：整理结果，明确“现行主链”与“退役旧链”，标注重复来源。

## 输出
一份清晰的项目调用链地图，包含：
- 实际运行的主流程路径
- 各功能模块对应的文件列表
- 未被引用的废弃文件或模板列表

## 注意事项
- 注意区分“函数定义”和“函数调用”，避免将定义处的引用误判为活跃调用。
- 对于动态导入或反射调用的情况，需额外检查配置项或字符串拼接逻辑。
