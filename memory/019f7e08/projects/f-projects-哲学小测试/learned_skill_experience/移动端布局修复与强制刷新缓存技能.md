## 输入
- 移动端页面样式修复后仍不生效（浏览器缓存）
- 聊天区标题栏消失或布局切换卡顿

## 步骤
1. **布局方案**：聊天区用 grid 流式布局（grid-row:3 固定 46px 行 + overflow:hidden），标题栏在行内正常流动永远可见；切换对话模式时行高变 1fr 自然展开。禁止绝对定位 + translateY 抽屉方案（实测手机上聊天区宽度变 0、标题栏消失）；禁止过渡 grid-template-rows 和 max-height（逐帧重排卡顿）。
2. **强制刷新缓存**：构建脚本加版本号常量，HTML 引用资源追加 ?v= 查询参数。
3. **服务端禁用缓存**：Flask 加 @app.after_request，对静态资源和页面返回 Cache-Control: no-store。
4. **验证部署**：SSH grep 确认服务器文件包含新规则、旧规则已移除、版本号生效。

## 输出
- 标题栏始终可见，切换流畅不卡
- 浏览器每次访问加载最新资源，无需手动清缓存

## 注意事项
- 修复后仍显示旧版效果，先怀疑浏览器缓存（版本号+no-store 双保险）
- 必须同时检查本地构建产物和服务器实际文件
- 移动端布局方案以用户手机上实际效果为准，本地数学推演不可靠
