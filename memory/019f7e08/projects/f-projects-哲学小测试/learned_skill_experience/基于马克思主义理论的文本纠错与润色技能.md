## 输入
- 待修正的文本内容（如免责声明、说明文档等）
- 指定的理论框架或指导思想（如马克思主义、辩证唯物主义等）

## 步骤
1. **理论审查**：逐句分析文本，识别违背指定理论原则的表述（如相对主义、唯心主义、教条主义、绝对化结论等）。
2. **定位错误**：标记具体段落，明确其理论偏差所在（例如：“意义依附于读者”是接受美学/相对主义，背离唯物主义反映论）。
3. **理论重构**：依据目标理论的核心观点重写句子。例如：
   - 反对“没有权威/不可知”，改为强调“实践检验/历史条件”；
   - 反对“读者中心论”，改为强调“客观基础 + 认识发展”；
   - 反对“永恒真理”，改为强调“科学方法 + 实践检验”。
4. **补充方针**：在涉及取舍时，加入经典理论的具体方针（如“取其精华、去其糟粕”、“实事求是”）。
5. **验证**：确保修改后的逻辑自洽且符合理论原意。

## 输出
修正后的文本，消除了原理论错误，表述符合指定理论框架，逻辑严密。

## 注意事项
- 区分“相对主义”与“辩证发展”：承认变化不等于否定客观标准，需强调实践检验。
- 避免“读者中心论”陷阱：文本意义有客观基础（历史/作者），而非完全由读者赋予。
- 修正时需保留原文本的事实内核，仅调整其解释框架。
