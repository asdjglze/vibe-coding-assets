## 输入
- 包含图片的目录路径
- 目标比例（如 1:1）

## 步骤
1. 编写 Python 脚本，引入 `PIL.Image` 模块。
2. 遍历指定目录下的所有图片文件（支持 jpg/png/webp 等）。
3. 对每个文件调用 `Image.open()` 获取尺寸 `(w, h)`。
4. 判断 `w != h`（或其他比例逻辑），记录异常文件及其尺寸。
5. 输出统计结果（总数、异常数、具体文件名及尺寸）。
6. 任务完成后删除临时脚本。

## 输出
包含非目标比例图片的文件名、实际尺寸及错误类型的列表

## 注意事项
- 确保环境已安装 Pillow (`pip install Pillow`)。
- 若需处理大量图片，建议先打印日志再执行修改操作，避免误删或覆盖。
