## 核心架构决策
1. **目标**：准确率第一，禁止编造分类号（必须从官方候选选择+程序校验），AI用于信息检索与判断。
2. **交互模式**：放弃外部书目库自动刮削；不使用轮数状态机，AI信息不足时调用工具获取，充足后直接Final输出JSON。
3. **上下文管理**：Ollama无状态，由程序拼接上下文。策略包括：Token预算控制（超限先压缩）、分层窗口（最近N轮完整+旧轮折叠进事实清单）、超长工具结果自动压缩（独立LLM调用，不占Agent轮数）。
4. **错误处理**：网络失败→程序降级关闭联网；工具问题→工具层重试；AI判断问题→AI重试。
5. **分类逻辑**：目录名仅作为粗分类线索，书名非分类依据，一律按内容实质与体裁归类（如《禅与摩托车维修艺术》归I712.45文学）。
6. **协议修复**：三重保险（提示词约束单一JSON→统一args嵌套格式→代码双读兜底）。
7. **其他**：网页抓取超时30-60s；评测以分类正确率为唯一目标。
