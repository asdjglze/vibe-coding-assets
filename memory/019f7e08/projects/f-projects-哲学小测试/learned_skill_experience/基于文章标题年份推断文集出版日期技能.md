## 输入
- 待填充出版年份的书籍列表（如拾遗汇编、xx集等）
- 包含文章标题(subtitle/titleNote)和作者信息的数据库

## 步骤
1. **提取文章年份**：扫描全书所有文章的标题、副标题、标题备注，使用正则提取1450-2026范围内的年份。
2. **过滤后世研究文章**：若提取的最大年份 > 作者卒年 + 15年，说明混入了后世纪念/研究文章，应改用作者卒年作为出版年份。
3. **知识库兜底**：若整本书的文章标题均无年份，使用预置的知识库映射表填入已知出版年或作者卒年；若无记录则设为2000。
4. **数据质量校验与修正**：检查并修正数据库中人物`person.lifespan`字段本身的错误（如巴金卒年误写为1920、霍布斯鲍姆误写为1931等），防止基于错误卒年推导出的出版年份失效。
5. **同步与备份**：更新主库后，自动备份数据库，并将修改后的数据同步至assets目录及更新MD5校验值。

## 输出
候选范围内书籍的publishYear全部填充完毕，剩余空年份为0。

## 注意事项
- **核心原则**：文章标题中的年份往往是后人整理/研究的时间，而非著作本身时间。当文章年份远超作者卒年时，极大概率是后世研究文章混入。
- **数据源可信度**：人物生卒年(lifespan)等基础元数据可能存在录入错误，在依赖这些数据进行逻辑判断前，务必进行抽样核查。
- **正则范围**：建议限制年份提取范围（如1450-2026），避免提取到页码、期号等非年份数字。
