## 输入
- 待分类图书的书名

## 步骤
1. 使用 `search_web` 搜索书名，初步获取编号线索
2. 使用 `fetch_page` 打开权威平台（京东、豆瓣、淘宝、孔夫子旧书网、当当、出版社官网）的详情页
3. 核对并提取书籍元数据（书名/作者/出版社/ISBN/CIP/中图分类号）
4. 基于确认的元数据分析并确定图书的分类方案

## 输出
经过权威平台元数据核实的图书分类结果

## 注意事项
- 优先选择上述列出的权威平台，禁止在无确切证据时猜测类号
- 若搜索结果不匹配，需继续查询直至找到准确类目
