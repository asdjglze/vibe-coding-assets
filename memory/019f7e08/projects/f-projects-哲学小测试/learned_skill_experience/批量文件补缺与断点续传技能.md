## 输入
- 本地文件系统的缺口清单（如 _stock_report.json）
- 目标文件的 URL 规则或备用通道地址

## 步骤
1. **环境准备**：设置请求间隔（如 10 秒/请求），确保低并发不触发 WAF。
2. **缺口扫描**：遍历目录，解析元数据（XML/JSON）定位缺失文件路径。
3. **URL 映射**：将本地相对路径转换为网络 URL（注意处理旧域名到新域名的重定向逻辑）。
4. **下载与校验**：使用 requests 下载，写入后读取文件头校验格式（如 jpg/swf 魔数），失败则重试或记录。
5. **断点续传**：每次下载前检查文件是否存在且有效，支持中断后重跑。
6. **后台运行**：使用系统命令（如 Windows `Start-Process`）分离进程，避免终端阻塞。

## 输出
- 成功下载的文件数量
- 跳过的已有文件数量
- 失败的列表及原因

## 注意事项
- 务必在脚本头部配置 `sys.stdout.reconfigure(line_buffering=True)` 以便实时查看进度。
- 对于大体积任务，建议后台启动并重定向日志到文件。
