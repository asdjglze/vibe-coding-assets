## 输入
- PDF 体检报告 JSON 文件（含每本页数、空白页号、评级等字段）
- 源书目数据（如 zk_books.json，含书名与预期页数）
- Flip 书对照日志（_rebatch.log，含 swf 源数与页图数）

## 步骤
1. **数据聚合**：加载体检报告与书目数据，按书名建立映射；解析 flip 日志提取源文件页数信息。
2. **交叉核对逻辑**：
   - Flip 书：验证 `PDF页数 == 源swf数 + 1`（封面）
   - 普通书：对比 `PDF页数` 与 `书目记录页数`（允许±1误差）
3. **生成 CSV 明细表**：包含序号、分类、文件名、PDF页数、大小、源对照结论、体检评级、空白页号、尺寸异常页、备注。
4. **生成 Markdown 总表**：汇总总页数、分类统计、Flip 书对账结果、复核抽验结论、校对口径说明。
5. **备份原始数据**：复制体检报告 JSON 至输出目录。

## 输出
- `PDF页数对照表.csv`：Excel 可直接打开的逐本明细，用于人工校对。
- `PDF体检总表.md`：结构化汇总报告，含统计图表与结论。
- `PDF体检报告.json`：原始数据副本。

## 注意事项
- CSV 编码必须使用 `utf-8-sig` 以兼容 Excel 中文显示。
- Flip 书核对需考虑封面差异（源数+1）。
- 空白页多为衬页结构，需在报告中注明口径避免误判缺页。
