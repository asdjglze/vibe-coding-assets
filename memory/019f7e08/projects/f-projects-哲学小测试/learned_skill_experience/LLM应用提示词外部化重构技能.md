## 输入
- 包含硬编码长字符串（如System Prompt、Task Template）的源代码
- 需要将这些提示词与业务逻辑解耦

## 步骤
1. **盘点**：使用Grep搜索所有LLM调用点（如chat()函数），定位所有硬编码的提示词变量。
2. **创建Loader**：编写统一的提示词加载模块（如prompt_loader.py），实现从指定目录（如skills/）读取.md文件的功能，并加入进程内缓存机制。
3. **拆分文件**：为每个独立的提示词（系统指令、任务模板、JSON Schema等）创建单独的.md文件，存入统一目录。命名建议采用`模块_用途`格式。
4. **替换引用**：在代码中删除硬编码字符串，改为调用Loader读取对应文件的内容。
5. **验证**：运行冒烟测试脚本，确保所有模板文件的占位符（如%s, {key}）与代码中的格式化参数完全匹配，无残留孤儿占位符。

## 输出
- 一个统一的提示词加载器模块
- 一组结构化的单文件提示词（.md）
- 清理后的源代码（不再包含长文本常量）

## 注意事项
- 建议在Loader中加入缺文件检测，防止静默失败。
- 拆分时注意区分“系统提示词”、“任务模板”和“输出规格”，保持单一职责。
- 验证环节至关重要，需检查format/f-string的参数一致性。
