## 输入
- Agent 代码中的工具/动作注册逻辑
- 发送给 AI 的系统提示词（System Prompt）

## 步骤
1. **提取注册列表**：从代码中解析所有注册的工具名和控制动作（如 `decide_level`, `final` 等）。
2. **核对提示词覆盖**：将注册列表与 System Prompt 中的工具描述段落进行比对，确保每个工具都有对应的功能说明和使用场景。
3. **补全使用场景**：对于仅有功能描述但缺乏“何时使用”指引的工具，在提示词中补充具体的适用场景（例如：`book_api` 用于核实正式出版物元数据，`read_slice` 用于快速判断体裁而非通读全文）。
4. **自动化验证**：编写脚本遍历注册列表，检查是否全部存在于提示词文本中，输出覆盖率报告。

## 输出
- 完整的工具清单及其在提示词中的对应位置
- 覆盖率验证结果（如 14/14 全部齐）
- 更新后的 System Prompt 片段

## 注意事项
- 工具说明必须包含三要素：功能、JSON 参数格式、**何时使用**（触发条件/场景）。
- 控制动作（如 `reset_level`）需明确其副作用（如回退状态）。
- 每次修改提示词后，建议运行自动化脚本验证完整性，防止遗漏。
