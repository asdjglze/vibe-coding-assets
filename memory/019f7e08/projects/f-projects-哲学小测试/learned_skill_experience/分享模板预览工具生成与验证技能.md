## 输入
- 项目根目录下的 `share_templates/manifest.json`（模板清单）
- 需要验证的 ShareCardData 数据（10 个字段：text, pre, post, title, subtitle, source, person, lifespan, avatar, appName）

## 步骤
1. 运行生成器脚本 `python scripts/gen_template_preview.py`，自动扫描 `manifest.json` 并生成 `demos/分享卡片/模板预览工具.html`
2. 用浏览器直接打开生成的 HTML 文件（无需本地服务器，支持 file:// 协议）
3. 左侧点击模板名称，右侧 iframe 实时渲染该模板的真实效果（同源 share_core.js + 模板 HTML）
4. 修改右侧 JSON 数据或切换预设示例，点击"应用数据"即时查看渲染变化
5. 若修改了模板，重新运行生成器脚本刷新工具页

## 输出
一个独立的 HTML 预览工具，可零写死地展示所有模板的真实渲染效果，与 App 内 WebView 完全同源

## 注意事项
- **核心原则**：预览工具必须基于同一份模板 HTML 和 share_core.js，确保所见即所得
- **禁止硬编码**：模板清单由生成器自动扫描 manifest.json 生成，改模板后需重新运行脚本
- **数据注入**：通过 URL hash 传递 JSON 数据，与 App 内 WebView 注入逻辑一致
- **适用场景**：在修改模板前先用此工具验证真实效果，避免因版本差异导致无效修改
