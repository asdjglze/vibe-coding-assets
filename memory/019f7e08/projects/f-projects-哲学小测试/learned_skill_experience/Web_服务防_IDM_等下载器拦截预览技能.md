## 输入
- 目标服务地址（如 Calibre-Web）
- 浏览器中遇到的下载器（如 IDM）自动捕获弹窗现象

## 步骤
1. **诊断确认**：在浏览器打开目标资源（如 PDF 阅读页），观察下载器拦截的具体请求 URL 和响应头特征。
2. **服务端改造（治本）**：修改服务端的文件响应逻辑，将原本直接返回文件的 `Content-Type` 和 `Content-Disposition` 改为伪装格式（如将 PDF 流伪装为普通文本或应用数据），使下载器无法识别为可下载文件，但前端阅读器通过内存解析仍能正常渲染。
3. **客户端兜底（速效）**：在下载器（如 IDM）设置中添加目标域名为“站点排除/不自动捕获”。

## 输出
- 服务端：资源请求不再触发下载器弹窗，但页面内阅读功能正常。
- 客户端：下载器对该域名完全静默。

## 注意事项
- 纯服务器配置（如端口、密码）无法阻止客户端侧的下载器插件，必须通过“去特征化”或“内存加载”手段。
- 服务端改造需确保前端阅读器能兼容新的 Content-Type 或自行解析字节流。
- 此方案适用于所有基于 Web 的文件预览场景（电子书、文档等）。
