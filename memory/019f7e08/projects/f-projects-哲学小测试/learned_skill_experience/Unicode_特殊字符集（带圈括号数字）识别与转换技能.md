## 输入
- 包含特殊符号（如带圈数字、括号数字）的文本内容

## 步骤
1. **识别字符范围**：确认目标符号的 Unicode 编码区间（如带圈数字 ①-⑳:U+2460-U+2473，括号数字 ⑴-⒇:U+2474-U+2487，带圈数字 ㉑-㉟:U+3251-U+325F）
2. **构建映射函数**：按码点分段计算数值键（例如：`if (c >= 0x2474) return String(c - 0x2474 + 1)`），避免简单枚举导致的错位
3. **修正正则表达式**：确保捕获组能匹配到原始字符（如使用 `([①-⑳⑴-⒇㉑-㉟])` 而非 `[①-⑳⑴-⒇㉑-㉟]`），以便后续提取 raw 值
4. **全链路同步**：前端收集（collectTags）、渲染（tagraw 显示原文）、定位（jumpToLine 用 raw）、服务端转换（convert_tags）均需应用相同映射逻辑

## 输出
- 特殊符号被正确识别为独立注码类型
- 弹窗列表显示原文（如 `⑸` 而非转换后的 `[^5]`）
- 仅转换勾选项，未勾选项保留原样
- 预览与检查面板中点击能准确定位到原文位置

## 注意事项
- 注意区分相似符号的 Unicode 编码（如 `⑸` 是 U+2478 括号数字，非 U+2464 带圈数字），需扩展字符范围
- 正则必须加捕获组才能通过 m[4] 等索引获取原始字符，否则会导致 data-tag 为 undefined
