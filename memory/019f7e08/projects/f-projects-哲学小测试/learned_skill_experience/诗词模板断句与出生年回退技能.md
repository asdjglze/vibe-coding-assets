## 输入
- 诗词优先的分享模板（data-poem="1"）
- 作者元数据（lifespan 字段含生卒年）
- 当前 UI 风格需求（如公文风、新拟态）

## 步骤
1. **诗词断句优化**：在 share_core.js 中实现 `splitPoem` 函数，在中文句读标点（，。；！？、：；）及收尾符号（"』）后强制换行，避免按字符宽度随机截断诗句。
2. **出生年回退逻辑**：为无年份数据的字段添加 `data-fallback-birth="1"` 属性，JS 从 lifespan 字符串中提取首组数字（正则 `\d{3,4}`）作为出生年显示。
3. **公文风精简**：删除头部装饰性星星元素，缩小顶部空白间距（padding-top 18px）。
4. **新拟态头像克制**：缩小头像尺寸（48→36px），保留原有凹陷阴影实现，不新增阴影层。

## 输出
- 诗词模板：诗句按标点自然分行，排版整齐
- 作者信息：缺失年份时自动显示出生年
- 界面风格：符合公文/新拟态要求的精简布局

## 注意事项
- **核心原则**：诗词模板必须尊重原文韵律，禁止机械按像素宽度切分
- **数据提取**：lifespan 格式通常为「1881—1936」，取第一组数字即出生年
- **UI 克制**：新拟态风格应避免过度装饰（大阴影、多余图标），保持极简
