## 输入
- 需要排查数据发布盘与公网服务器之间的同步逻辑或数据更新问题

## 步骤
1. **查阅部署文档**：确认OPDS服务（如COPS）的数据源挂载路径及容器配置。
2. **分析源码中的发布逻辑**：重点检查`metadata_db.py`等发布层代码，确认数据库文件的生成位置（如`Y:\图书书库\metadata.db`）及重建机制（全量重建 vs 增量同步）。
3. **核对路径一致性**：对比代码中配置的`library_root`与Docker-compose中挂载的目录是否一致。
4. **检查状态文件与日志**：查看`state/pubwork/`下的工作副本时间戳及当日运行日志，确认是否有新的数据写入操作。

## 输出
- 明确数据从发布盘到服务器的完整流转链路（如：PC端生成metadata.db → NAS挂载 → COPS容器读取）。
- 确认数据是否已更新至目标服务器数据库。

## 注意事项
- 避免直接拖库查询，优先通过代码逻辑和文件系统状态进行诊断。
- 注意区分旧的Calibre复制链路与新的自建metadata.db链路，防止混淆。
