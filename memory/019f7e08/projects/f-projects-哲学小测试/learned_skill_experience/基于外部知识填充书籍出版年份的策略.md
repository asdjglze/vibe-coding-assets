## 输入
- 书籍清单（含书名、作者）
- 缺失的出版年份字段

## 步骤
1. 提取所有缺失出版年份的书名。
2. 利用知识库或搜索工具查询每本书的实际首次出版年份。
3. 将查询到的年份填入数据库，**不区分**是否为正式出版物（如内部刊物、讲义、非正式汇编等），只要确认为真实出版物即可。
4. 同步双副本并更新MD5。

## 输出
数据库中对应书籍的 publishYear 字段被填充为实际出版年份。

## 注意事项
- 核心原则：以“是否知道实际出版年份”为准，而非“是否属于正式出版物”。
- 对于确实无法确定年份的（如纯书信集、按年份分卷的文集、人物条目页等），保持为空或根据特定规则处理（如取最后文章日期），不要强行编造。
