## 输入
- 待验证的百科词条链接或人物名称

## 步骤
1. **直接抓取**：使用 `WebFetch` 尝试直接访问目标 URL。
2. **搜索引擎兜底**：若直接抓取失败（如返回空内容），使用 `WebSearch` 搜索该链接或关键词，通过搜索结果中的标题和摘要判断是否命中目标人物。
3. **Agent 模拟浏览器**：若搜索引擎也未直接命中，使用 `Agent` 模拟真实浏览器操作（如构造站内搜索 URL `www.sogou.com/sogou?query=XX&insite=baike.sogou.com`），逐一搜索并读取词条页进行二次确认。
4. **交叉验证**：对存在同名歧义的人物，需核对生卒年、身份简介等信息以区分；对 NONE 判定，需确认是“无独立词条”还是“仅有提及”。

## 输出
- 确认存在的词条：返回正确的百科 URL 及关键身份信息。
- 确认不存在的词条：标记为 NONE，并说明原因（如无词条、仅被提及、同名他人）。

## 注意事项
- 搜狗百科等站点常有反爬机制，直接抓取可能失败，需准备备选方案。
- Agent 模拟浏览器时，注意处理站内搜索逻辑和跳转链接解析。
- 遇到同名人物（如梁赞诺夫有导演和马克思学家两个词条）时，必须通过详细信息严格区分。
