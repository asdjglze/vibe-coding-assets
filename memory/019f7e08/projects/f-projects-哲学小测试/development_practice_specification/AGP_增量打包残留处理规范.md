AGP 增量打包会导致被删字体的 zip 空洞残留，造成不同档位 APK 物理体积一致。修复方案：在打包脚本中每档构建前强制清理 APK 与 assets 中间产物，执行全量打包而非增量构建，确保 APK 实际大小反映字体数量差异。
