歌手指定逻辑：AI 在 analyze_user_state 一次性判断并输出结构化 JSON 数组（specific_requests.artist = ["周杰伦", "王力宏"]），程序归一化后 O(n) 归一化包含匹配过滤（支持合唱/featuring 任一命中即保留）。禁止程序按顿号字符串拆分 AI 输出——AI 直接输出数组，字符串拆分仅作容错。用户否定需求（如"不要纯音乐"）结构化存储于 specific_requests.exclude 数组，注入精选提示词 + 程序防御兜底（_remove_excluded_songs 按 genre 别名映射 _EXCLUDE_ALIASES 移除命中歌曲）双重保障。禁止为特定概念建立专属搜索流程：AI 遇到不确定概念在 agent 工具链中自行调用 web_search 通用工具。
