诗词模板（data-poem）实现动态字号缩放：
1. 容器固定宽度 `.poem { width: 100% }` 防止 flex 塌缩。
2. 使用 DOM Range 实测每句真实渲染宽度，按圆窗弦长逐行约束（离圆心越远允许宽度越窄）。
3. 迭代缩放字号直到每句完整一行，不再自动换行拆断。
4. 上下文字句与正文块间强制 `<br>` 独立成行，避免跨块拼接导致的异常换行。
