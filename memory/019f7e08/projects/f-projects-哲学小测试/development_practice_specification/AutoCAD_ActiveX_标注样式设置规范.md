使用 AutoCAD ActiveX (win32com) 修改标注样式时，仅调用 SetVariable 设置的变量只是"文档级替代"，必须在设置后调用 DimStyles.CopyFrom(doc) 方法将设置固化到样式对象中，否则切走激活样式后设置会丢失。

挡土墙断面图尺寸标注定位规范（CAD 版）：
- 水平标注：b1（墙顶宽）放在自然地坪线上方（y=-0.5，文字 y=-0.95）；b2（墙底宽）、垫层宽放在垫层底面以下分层排布（b2 尺寸线 y=H+0.45、垫层宽尺寸线 y=H+1.2），标注点仍贴基础底面/垫层底面，尺寸界线穿过垫层属正常画法。
- 垂直标注：全部放在断面左侧分层（自外向内 H=-1.65、h3=-1.25、h2=-0.85、h1=-0.45，文字各在尺寸线外侧 0.55），右侧只保留构件名称引出线，避免垂直标注与引出线重叠。
- 尺寸标注不得压住图形或与构件引出线文字重叠。
