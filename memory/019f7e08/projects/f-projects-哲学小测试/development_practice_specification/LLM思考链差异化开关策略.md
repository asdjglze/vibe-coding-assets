LLM thinking（思考链）功能按场景差异化配置：
1. **关闭**：纯聊天回复、机械性检索（搜索策略、标签推导）、知识抽取、意图检测、JSON 格式修复。
2. **保留开启**：推荐核心链路（状态分析、精选歌曲、注入人格写串词）+ agent 工具链全部环节（判 need_tools、生成执行计划、步骤参数填写、失败重试分析）。工具链必须开思考：工具描述多且复杂，不开思考会导致工具误判，让用户重复表达需求，代价远大于推理 token 成本。
