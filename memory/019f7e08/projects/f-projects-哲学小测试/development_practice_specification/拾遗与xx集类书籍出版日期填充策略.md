针对《拾遗汇编》及各类'xx集'等无出版日期的书籍，按以下优先级填充 publishYear：
1. **提取书内最晚文章标题中的年份**作为出版日期。
2. 若提取到的文章年份超过作者卒年+15年（视为后世研究/纪念文章混入），则改用**作者卒年**。
3. 若整本书文章均无年份，使用**外部知识库**查询实际出版年份。
4. 若知识库也无法确定，统一兜底填入 **2000年**。
