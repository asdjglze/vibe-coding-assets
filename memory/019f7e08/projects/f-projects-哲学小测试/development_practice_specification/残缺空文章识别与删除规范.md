清理残缺空文章时，需识别并删除以下类型的无效条目：
1. 纯导航文字
2. 期号 + 导航文字
3. 面包屑或占位语
4. 纯出版信息（如"XX译 XX公司出版"）
处理规则：剔除上述干扰内容后若正文为空，则删除该文章及其目录条目；若被其他书引用则仅删目录，否则连article行一起删除。
