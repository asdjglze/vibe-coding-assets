竖排分享模板长文处理策略：不缩小文字、不扩充卡片宽度（分享图统一 320px），采用"列数固定、每列字数随内容增长、卡片高度自适应"方案。实现要点：
1. 容器 width 固定 = 列数 × 列宽（列宽 = line-height），height:auto 不生效（Chrome 竖排容器高度不会随内容增长），必须由 share_core.js 的 data-cols 属性显式计算：总字数/列数 = 每列字数，容器高度 = 每列字数 × (字号+字距)。
2. data-max-sel-chars 设置 sel 上限，超长截断并在竖排尾部加省略号，防止卡片被无限拉高。
