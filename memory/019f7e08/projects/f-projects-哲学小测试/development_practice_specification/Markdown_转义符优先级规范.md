Markdown 解析中，转义符（\ 或 /）的优先级必须高于所有块级标记（如 [诗]/[题]/[抬]/[款]）。
1. 行首转义（如 \[诗]）应被识别为普通文本，剥离转义符后显示字面内容。
2. 在块级标记的惰性延续扫描中，遇到转义行必须立即打断，不再将其并入当前块。
3. 纯文本渲染逻辑（如桌面组件、诗词兜底）需同步处理转义剥离，防止误剥字面标记。
核心原则：转义行为优先于格式解析，确保特殊字符能正确显示为文本而非触发格式块。
