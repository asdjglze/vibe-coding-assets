---
title: "文档检索采用开源两级检索模式"
usage_scenario:
    - "设计或优化AI辅助工具中的文档/知识库检索功能时"
    - "需要降低大模型上下文窗口占用并节省Token成本时"
keywords:
    - "两级检索"
    - "Token优化"
    - "开源最佳实践"
    - "按需读取"
---

文档检索应参考开源coding软件（如Aider repo-map、Claude Code grep→read）的两级检索模式：第一跳提供高信息密度的清单与摘要（如目录带摘要、多命中返回排序后的片段列表），细节按需再读；避免一次性全量加载文档导致token浪费。
