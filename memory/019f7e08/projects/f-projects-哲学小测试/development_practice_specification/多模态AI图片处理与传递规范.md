多模态AI交互中的图片处理最优方案：
1. **默认不带图**：模型上下文默认不包含图片，需查看时通过工具（如view_pages）按需获取；
2. **已吸收留痕**：AI看完并输出结论的图片，将其关键信息转化为文本摘要写入历史记录，原图从后续轮次中移除以节省Token；
3. **按需回拉**：若后续流程需要回顾细节，再次调用工具渲染原图；
4. **长文档预筛**：对于大量图片的文档，先低清扫全篇（如缩略图拼接），由AI标记有信息的页码后再渲染高清大图。
