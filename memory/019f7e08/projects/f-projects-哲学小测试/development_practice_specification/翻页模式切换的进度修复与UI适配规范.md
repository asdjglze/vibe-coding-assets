切换至翻页模式（墨水屏优化）时，必须执行以下操作：
1. 修复阅读进度恢复逻辑：使用精确逆映射公式 `ceil(rp×总页数/100)-1` 替代原截断公式，确保从滚动模式切换后能准确定位到上次阅读页码。
2. 禁用所有非一次性动画：工具栏箭头旋转、搜索行展开收起、加载转圈等改为直切或静态显示。
3. 调整 UI 样式：首页卡片背景变为白底黑字，字体保持不变。
4. 功能限制：关闭分享功能（框选不弹分享按钮），保留收藏功能。
5. 用户提示：弹窗告知旧进度数据可能因折算产生误差，需手动翻至相近位置。
