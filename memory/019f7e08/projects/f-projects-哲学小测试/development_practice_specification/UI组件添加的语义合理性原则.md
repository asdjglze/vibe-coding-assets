UI组件（如头像）的添加必须基于版面语义的合理性进行筛选，严禁无差别全量添加。判断标准：头像只存在于"社交平台形态"的场景（聊天记录、博主笔记、issue 作者等）；一切拟物形态（书信/信笺、书页/书眉、书法卷轴、水墨横幅等）模拟的是"物"，真实的物上没有头像，只能用署名、落款、印章、题跋等物的语言。极简几何风（Apple/Nike/Tesla/BMW 等）同样排斥具象头像。
