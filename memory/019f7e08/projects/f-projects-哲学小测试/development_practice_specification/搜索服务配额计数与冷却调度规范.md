项目联网搜索采用配额感知调度：豆包 500 次/月、Tavily 1000 次/月免费额度，通过 data/search_quota_state.json 按月计数。调度规则：剩余配额比例高者优先（均衡消耗），比例相同豆包优先；引擎连续失败进入指数退避冷却（10min→20min→30min 封顶），冷却中不参与调度。计数在各自 service 内部 HTTP 成功后执行（无结果也计），失败只触发冷却不计次数。注意 threading.Lock 不可重入，锁内禁止调用其他锁方法（status() 曾因锁内调用 is_cooling 死锁）。配额状态文件在 deploy 排除列表中，本地与服务器计数独立。
