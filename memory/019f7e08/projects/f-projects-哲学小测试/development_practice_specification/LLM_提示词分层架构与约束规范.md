LLM 提示词采用双层结构：
1. 系统提示词 (SYSTEM)：仅包含人格设定、身份定义、内容安全铁律及人格底线（如“介绍即评价”、“黑帮歌曲舆论武器”等），禁止在任务层重复人格描述。
2. 任务提示词 (USER)：仅描述具体任务目标与执行方法，开头需大篇幅重复“严格遵守系统提示词里的人格所规定的内容”以明确层级关系，防止 AI 混淆人格与任务。

任务提示词内部结构：
- 第一块【你的任务是什么】：简述核心任务（写串词、回复、返回 JSON）。
- 第二块【你要如何才能完成】：详细阐述分配策略、密度控制、素材池使用、示例、禁令、格式规范及评价切入点。
