同一本书内若存在两篇不同编号（articleId）的文章内容完全一致，应视为重复数据。处理原则是保留组内 sortOrder 最小的一篇，删除其余冗余文章及其对应的目录条目；若被删文章不再被其他书引用且无语录关联，则一并删除该文章记录。
