Markdown 风格注释定义（如 `[^N]:`）需确保在行首被识别。插入逻辑更新为：点击按钮时直接在**当前行行首**插入定义内容，而非另起新行。若当前行已有正文，插入后整行变为定义行；建议用户将光标置于空行以保留原内容。解析器仍使用正则 `^\[\^(\d+|\*)\]:` 进行行首匹配，段落中间插入无效。编号按钮应自动匹配正文中缺失的定义编号。
