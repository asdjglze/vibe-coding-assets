在调研报告或技术方案中引用外部数据源/API 的能力（如"豆瓣/微信读书返回中图分类号"、"国图 OPAC 有 SRU 接口"）前必须实际核实字段与可接入性，不能凭印象推断。错误事实会导致方案核心假设（如"书目库直通中图号捷径"）整体作废。核实途径：搜索该 API 的字段文档、查看项目中已实现的调用代码、测试真实返回。
