分享卡片模板字体加载失败根因排查与修复：
1. **现象**：模板中指定字体（如毛体思、楷体、硬笔手写）实际渲染为宋体。
2. **根因**：
   - `share_templates/fonts/` 目录下仅有 `maoti_si.ttf`（1168字节，仅含"思"一字形），其余字体文件（kaiti, maobixing, shtfybs等）缺失。
   - WebView 加载无效/残缺字体时自动回退默认字体（宋体）。
3. **修复方案**：
   - 从 `assets/fonts/`（App级全量字体目录）复制所有模板所需字体文件至 `share_templates/fonts/`。
   - 确保 `@font-face` 声明的 `src: url('../../fonts/xxx.ttf')` 路径下存在有效字体文件。
4. **验证方法**：使用 Python fontTools 检查字体文件 `numGlyphs` 和 `cmap`，确认包含所需字形（如"思"=0x601D）。

**来源**：Bash (Get-ChildItem), Python (fontTools) + 模板修改实践
