分享卡片模板正文渐隐失效的根因与修复：fillTextContext 用 el.clientWidth 测量行宽，但 flex 居中布局（share-card 常见 justify-content:center + align-items:center）下未填充内容的正文容器宽度为 0，导致测量失败走退化分支（纯文本 textContent 填充），pre/post 渐隐结构（ctx-pre/ctx-sel/ctx-post 与逐字 opacity）全部丢失。修复：maxWidth 仍为 0 时回退用父容器内容宽度（parent.clientWidth - paddingLeft - paddingRight）。此问题影响全部 flex 居中模板（66/67/69 等），非单模板问题；验证渐隐需检查 .ctx-pre/.ctx-post span 的 style.opacity 是否呈 0.06→0.30 渐变。
