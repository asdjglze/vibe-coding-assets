项目采用本地构建模式，部署脚本 `deploy_sync.py` 实现全自动流程：
1. 本地构建并自动断言产物（bundle.js/css大小、引用完整性）
2. MD5对比差异文件上传
3. 服务器自动复制HTML
4. 后端自动重启并执行HTTP健康检查
5. 最终输出明确结论（✅成功或❌失败步骤），全程无需人工干预
