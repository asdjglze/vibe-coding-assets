项目支持三档字体版本打包（Large/Medium/Mini），通过 build_pack.ps1 脚本实现：
- Large: 原 17 款 +4 款毛笔/手写体 (21 款)
- Medium: 原 17 款去掉书宋 (16 款)
- Mini: 仅宋体/黑体/楷体 (3 款)

打包流程：同步语料库 → 全量子集化 → 逐档过滤字体并重写 manifest.json → 构建 → 拷贝 APK → 恢复全量字体供开发环境使用。
