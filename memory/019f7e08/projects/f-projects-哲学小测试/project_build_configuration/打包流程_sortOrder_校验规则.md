打包程序必须集成 sortOrder 校验脚本 (scripts/verify_book_sort.py)，校验失败则终止打包。
校验规则:
1. 人物排序：马恩列毛斯固定置顶，其余按名字笔画数逐字比较，全同按入库 ID
2. 人物内排序：类别 → 出版年份 (无年份排最后) → 卷序
3. 全局编号：从 1 开始连续分配，保证全局唯一性
