导出报告功能支持TXT、MD、HTML三种格式：
- TXT：立即下载纯文本报告，0费用
- MD：立即下载Markdown报告，0费用
- HTML：优先使用缓存直接打开；若无缓存则先询问性别，再由AI生成后在新窗口打开
用户点击导出按钮后需先选择格式（1/TXT、2/MD、3/HTML、4/跳过），确认后再执行对应逻辑，避免无意义资源消耗。
