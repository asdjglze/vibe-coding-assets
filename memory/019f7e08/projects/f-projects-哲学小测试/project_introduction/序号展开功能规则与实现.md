序号展开功能（notes_editor 中 btnExpand）：用户选中一段文字点击后，把其中疑似序号逐项拆成独立段落，每项间换两行（插入 \n\n，即一个空行，用户明确"换两行=两个\n"），文字内容不变仅插换行。正则覆盖：（一）中文括号、（9）/（10）全角括号数字、(1) 半角括号数字、（甲）（乙）天干地支括号、(A)/(B)/（C）字母括号（大小写全半角）、①-⑳/⑴-⒇/㉑-㉟ 带圈数字，均不限位数。数字序号规则（用户指定）：数字+顿号（1、）识别；数字+点且点后非数字（1.文字、1. 文字）识别；数字+点后跟数字（3.14）认定为小数点不识别；数字+空格（半角/全角空格 U+3000）识别。规则：段首序号（m.index===0）不插；序号前紧邻已是换行的（已展开）不重复插（幂等）；无选中弹 toast 提示。[^1] 等注释引用天然不匹配正则。
