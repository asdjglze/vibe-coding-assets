项目排版判定功能支持以下照片比例选项：
- 横图阈值（宽/高 ≥）：2:1、1.85:1、16:9、16:10、3:2（默认）、7:5、4:3、5:4
- 竖图阈值（宽/高 ≤）：4:5、3:4、5:7、2:3、5:8、9:16、1:2
共横图8档、竖图7档，覆盖超宽全景至接近方形的常见比例。
