项目核心功能架构:
1. 四域扩展: 中图/规范/未分类/待人工四区遍历
2. 快通道发布: 新文件自动把关→按桶挪入未分类区→登记→即刻发布
3. 程序直打标: 未校对/待分类/待富化 + 类型标 (来源已知时)
4. 缺失记录库: 程序同目录存储 AI 报"确认不存在"的字段，支持批量查询与清除
5. 精修入口: 按标补课一条龙，卡住转待人工 (锁死)
6. 提示词注入: 四个会话注入未校对警示/类型已定告知/已确认缺失信号
关键架构修复: 发布库桶区分组由"目录=一本"改为"域感知分组 + 删除按 id",避免多书合成一本
