平台模板 69-85 样式与数据规范：
- 69 小红书：封面右上无 emoji；第二个标签为书名（source data-book + data-prefix="#"）；xhs-avatar 用 img data-field="avatar" object-fit cover。
- 70 推特：xs-avatar img 头像；xs-name 作者名（person）；xs-handle 作者拼音（data-pinyin="1" + data-prefix="@"，如 @Lu Xun）；xs-date 显示「摘自《热风》」（source data-book + data-prefix="摘自"）。
- 71 ins：ig-avatar img 头像（白边圆形）；正文楷体（KT 字体 kaiti.ttf，无斜体）；ig-quote padding-bottom 64px 固定间距。
- 72 Telegram：tg-sub 已删；tg-channel 为 @作者拼音；tg-logo 毛体思蓝底白字（MaoXing + #1D9BD6 底）；tg-quote padding 34px/60px 上下留白，tg-plane 纸飞机保留。
- 73 知乎：zh-avatar img；zh-brand 左侧毛体思蓝字斜体（MaoXing italic）+ 右侧 appName 黑体（HT）蓝字 700；zh-name .label 显示 lifespan 纯年份生卒年；zh-q 显示文章标题（data-field="title"），::before 伪元素为蓝色 T 字块。
- 74 NASA：manifest 名称「NASA 蠕虫 · 汇报版面」；nasa-worm 大标题写文章标题（SS 斜体 39px，data-fit-title min 12）；nasa-meta 左侧文章标题、red 保留；nasa-sub 为 作者 · 《书名》 · 出版年份（person + source data-book + year data-fallback-death）。
- 75 宜家：ikea-logo-mark 黄块写文章标题（宽 160px 占卡片一半、padding 5px 12px 防圆角遮挡、data-fit-title min 9）；ikea-top 左作者右出版年份（space-between）；ikea-sub 摘自《书名》；ikea-source 英文节选「Excerpt shared in 当前年」。
- 76 谷歌：g-meta 三段式 作者 | 《书名》 | 出版年份；g-source 英文节选。
- 77 Spotify：sp-mark 绿底黑字毛体思（MaoXing + #1DB954 底 + color #000）；sp-sub 作者 · 《书名》 · 年份；sp-source 英文节选；sp-wave 波形保留在 foot 右侧（右缘距卡边 24px），sp-logo 与 appName 已删。
- 78 Apple：ap-source 作者 · 年份；ap-sub 真实出处（source 完整）；ap-id 英文节选；ap-logo 已删；卡片 padding-bottom 60px 保证 foot 间距 31px。
- 79 可口可乐：cc-script 毛体思大字写文章标题（data-fit-title min 12，40px）；cc-top 三段式 作者 | 《书名》 | 出版年份；cc-source 英文节选；cc-logo 保留 appName。
- 80 企鹅经典：pg-penguin 圆形黑边头像（img）；pg-series 文章标题（9px，data-fit-title min 7）；pg-title-top 作者用硬笔手写体（YB = shtfybs.ttf，17px）；pg-label 人物简介第一句（intro + data-sentence="1"，11px 居中）；pg-source「摘自《书名》 · 年份」；pg-logo 保留 appName。
- 81 爱马仕：hm-royal 顶部品牌行写文章标题（10px 黑体 700，data-fit-title min 7）；hm-no 与 hm-logo/appName 已删；hm-sub「— 作者 · 《书名》」（person + source data-book，楷体斜体）；hm-source 英文节选。
- 82 IBM：ibm-meta 写文章标题（10px，data-fit-title min 7）；ibm-sub「— 作者 · 《书名》 · 出版年份」（person + source data-book + year data-fallback-death，灰色斜体）；ibm-source 英文节选；ibm-logo 保留 appName。
- 83 爱彼迎：ab-belo 改为毛体思白字「思」（MaoXing 30px 白字，40px 方块 flex 居中，去花朵 clip-path）；ab-top 左书名（source data-book）右出版年份（year data-fallback-death，space-between）；ab-sub「— 作者 · 《书名》」；ab-source 英文节选；ab-logo 保留 appName。
- 84 MOMA：mm-mark 改文章标题（SS 35px 白字，data-fit-title min 14）；mm-top 左书名右出版年份；mm-sub「— 作者 · 《书名》」；mm-source 英文节选；mm-logo 保留 appName。
- 85 MIT：mit-meta 左文章标题（data-fit-title min 7）右蓝色加粗书名（.blue + source data-book）；mit-sub「— 作者 · 《书名》 · 出版年份」；mit-source 英文节选；mit-logo 保留 appName。
- 62 暗夜极简：顶栏左标 EXCERPT；64 微信读书：wr-logo::before 为毛体思「思」字（MaoXing 15px）。
- 数据链：ShareCardData/ShareCardScreen/ReaderScreen 贯通 intro（Person.intro）与 birth（StylePresets.birth）；share_core.js 支持 data-pinyin（姓名拼音）、data-sentence（取第一句）、data-now-year（当前年）、data-fit-title（两行缩放）、data-book（取《书名》）、data-fallback-death（年份回退链：数据 year → lifespan 死亡年 → 当前分享年）。
- 英文节选统一写法：`<span data-field="year" data-now-year="1" data-prefix="Excerpt shared in "></span>`。
- 硬笔手写体：shtfybs.ttf 注册为 font-family 'YB'（54_editorial/63_journal/80 使用）。
