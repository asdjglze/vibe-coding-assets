人物生卒年数据清洗规则:
- 错误修正: 发现并修正 19 处明显错乱年份 (如巴金 1904-2005, 马克思恩格斯列宁等 130+ 人核对无误)
- 缺失补充: 为 7 个明确人物补全生卒年 (帕尔乌斯、巴布石金等)
- 存疑处理: 托派小人物 (毛林、李季等) 因知识库无把握，暂不自动修正，需人工逐人查证
