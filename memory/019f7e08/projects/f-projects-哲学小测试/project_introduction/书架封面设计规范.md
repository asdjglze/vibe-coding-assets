书架封面设计规范:
1. **背景色系化**:按分类定义色系（文章-米褐、诗词-绿、语录-青灰），每系4档深浅变化。
2. **书名处理**:自动剥离外层《》，保留中间书名号（如论《xxx》的aaa）。
3. **署名样式**:移除朱砂印章和姓氏方框，直接显示作者名（如鲁迅、毛泽东）。
4. **篇幅标记**:模板1仅显示大数字，删除“共xx篇”文字；其余模板保留“共xx篇”。
