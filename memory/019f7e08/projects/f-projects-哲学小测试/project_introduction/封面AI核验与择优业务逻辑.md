项目封面处理采用两段判断机制：①完整性（是否为正经封面）→②归属一致性（书名/作者/册次是否匹配）。支持拒绝权（不合格则无图）、搜索权（掀页+查词API，禁网页抓取）。分级努力：出版书（有ISBN/出版社/简介含出版信息）竭尽全力，非出版书从简允许无图。AI申请上限3轮。高清图片仅用于AI判断，入库统一归一化（长边≤1200px, JPEG q90）。
