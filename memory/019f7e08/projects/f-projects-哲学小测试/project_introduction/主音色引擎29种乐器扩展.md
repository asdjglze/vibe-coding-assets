项目主音色引擎已扩展至29种乐器，覆盖多类真实与电子音色：
- 键盘类：piano、organ、accordion
- 弹拨类：guitar、ukulele、harp、banjo、mandolin
- 弓弦类：violin、cello、erhu
- 管乐类：flute、pan_flute、clarinet、saxophone、trumpet、oboe、harmonica、hulusi
- 中乐类：pipa、guzheng
- 敲击类：kalimba、music_box、xylophone、vibraphone
- 电子类：8bit、16bit
- 基础波形：sine、triangle
所有乐器均通过泛音合成+ADSR包络实现，支持声部级独立指定（如`[1* guitar]`），鼓组与贝斯仍使用专用渲染器。
