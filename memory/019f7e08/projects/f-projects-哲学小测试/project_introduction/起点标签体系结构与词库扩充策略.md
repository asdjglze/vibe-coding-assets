项目对标起点中文网标签体系:
- 结构认知: 起点采用"分类(男频14/女频11) + 标签云(80个细节词)"双层结构
- 词库扩充: 已补入题材(如蜀山、阵法)、情节(废材流、练功流)、角色(孤儿、黑客)等核心词
- 过滤原则: 舍弃性格形容词(冷酷/阳光)、具体游戏版本词(LOL/手游)及低频女频变体词
