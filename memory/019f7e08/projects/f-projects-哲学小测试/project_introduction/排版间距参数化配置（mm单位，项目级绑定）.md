项目排版功能新增以下与项目绑定的间距配置项，单位统一使用毫米（mm）：
- 图片上下间距
- 图片左右间距
- 图片与介绍文字间距
- 图片与标题文字间距
- 页眉与页眉线间距
新建项目（即导入新文件）时，需为这些字段提供默认值并写入session.json
