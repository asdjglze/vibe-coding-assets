项目前端与后端协同流程规范：
- 后端必须确保Phase 1 AI输出完成且JSON解析成功后，才向SSE发送`phase1_done`事件（含完整哲学画像文本）
- 前端收到`phase1_done`后立即启动`typewriterPlay`逐字显示（25ms/字 + 光标闪烁），不等待Phase 2开始
- Phase 2在后端独立立即启动，不依赖前端打字效果完成
- 打字效果期间用户可见内容，Phase 2输出到达后直接覆盖打字区域显示行为分析
