爬虫数据范围与分类规范:
1. 范围限制：仅爬取人物主页关联的书籍和文章，忽略无明确人物关联的内容（如第一国际文本、会议决议等）。
2. 资源完整性：必须保留头像、插图等所有视觉资源。
3. 诗集识别：需区分标记“诗集类型的书籍”（整本收录诗歌诗词），单篇诗歌或文集内的单首诗不单独标记为诗集。
