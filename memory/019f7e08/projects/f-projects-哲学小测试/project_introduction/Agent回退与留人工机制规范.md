图书分类Agent交互协议修正：
1. **新增 `reset_level` 指令**：允许AI走错分支时随时回退（指定深度），保留上下文重新钻取正确路径。
2. **新增 `manual` 指令**：全书唯一合法的显式留人工出口，需附带原因说明，程序收到即结束本书并生成人工留置记录。
3. **修正 `confidence=low` 语义**：不再代表留人工申请，而是“打回自纠”信号；AI收到后必须尝试回退或补证，严禁直接交卷。
4. **留人工触发条件**：仅限AI显式输出manual、连续3次low仍无法解决、校验5次未通过或动作耗尽。
