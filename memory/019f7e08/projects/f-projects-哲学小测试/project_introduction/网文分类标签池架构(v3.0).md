项目具备网文分类与打标能力，采用v3.0标签池模式:
- 结构: 固定标签(网络小说) + 频道(男频/女频) + 平台(10个受控枚举) + 四大标签池(题材99词、情节94词、角色62词、衍生22词)
- 规则: AI从四个池中自由组合选3~9个标签，支持多题材混搭，程序负责白名单校验和总量限制
