项目记谱规范文档需拆分为两个独立AI技能文档：
- `USAGE.md`：语法手册，聚焦ABC Notation合法写法（音符、和弦、声部、乐器映射等），确保AI能正确生成合乎语法的`.abc`文件；
- `CREATION.md`：创作指南，聚焦音乐性表达（旋律规则、节奏编排、声部分工、和弦进行、情绪映射等），确保AI能生成好听、合理、有表现力的乐谱。
二者职责分离：USAGE管'合不合法'，CREATION管'好不好听'。
