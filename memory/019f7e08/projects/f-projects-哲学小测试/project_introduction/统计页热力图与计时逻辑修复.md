项目统计页存在三个已知 Bug 已修复:
1. 热力图点击识别错误：原用列宽计算行号导致错位，现改为列宽算列、行高(高/7)算行；
2. 悬浮窗定位偏移：原将局部锚点误转为窗口坐标导致双重叠加，现直接使用图表局部锚点并钳制在容器内；
3. 阅读时长虚增：原会话计时未监听生命周期导致后台继续计时长，现增加 ON_STOP 结算暂停、ON_START 恢复逻辑。
