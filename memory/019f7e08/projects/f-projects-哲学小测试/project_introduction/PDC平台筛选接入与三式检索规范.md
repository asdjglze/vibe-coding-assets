PDC（国家版本数据中心）接入规范升级：
1. 三式检索：①搜索列表（带序号1-10）→ ②带筛选条件二次搜索 → ③按序号读取详情。
2. 筛选能力：支持作者(zz)、主题词(ztc)、出版单位(publisher)、中图分类(cate)、出版年、价格、数据类型(ztype)；筛选项清单(rangeType)有7天缓存。
3. 分页限制：个人账号仅能查看第1页（前10条），需通过筛选将目标挤入前10。
4. 列表与详情分离：列表先给AI看，确认目标后按需读详情（含副书名subbookname、定价、版权页全文等82个字段）。
