图集与政策文件命名规范:
- **图集**: 必须包含实印图集号，格式为`[图集号]：[书名]`（如 `2003沪J906：住宅信报箱`）；程序无法提取的中文夹杂图集号交由AI从封面/扉页刮削。
- **政策文件**: 必须包含发文字号，格式为`[机关代字〔年份〕序号]：[标题]`或`[机关名 公告 第X号]：[标题]`（如 `建标〔2018〕243号：...`）。
- **通用规则**: 编号与标题间使用全角冒号分隔；纯ASCII标准号维持官方空格规则（如 `AQ 1058-2008`），含中文/六角括号的号原样保留不强制修正。
