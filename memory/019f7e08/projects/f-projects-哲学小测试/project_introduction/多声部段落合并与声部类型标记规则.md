项目声部标记规则如下：
- `[N]`：普通伴奏，音量系数 0.5
- `[N*]`：主旋律，音量系数 1.0
- `[N D]`：鼓组，单独渲染为打击音色，音量系数 0.8
- `[N B]`：贝斯，单独渲染为低频贝斯音色，音量系数 0.7
其中 N 为纯数字，相同 N 的所有行属于同一段落并同时播放；解析器仅依据数字 N 进行段落合并，后缀（`*`、` D`、` B`）仅用于声部类型标识，不影响段落归属。
