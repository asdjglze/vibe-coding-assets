项目存储架构调整：诗词数据并入文章表（article），通过新增 `kind` 列区分（'article'/'poem'），未来可扩展更多分类；Poem.kt 降为普通 UI 类型，不再作为独立数据库实体。

新增 Markdown 块语法 `[诗]`：
- 语法定义：行首标记，与 [题]/[抬]/[款] 同构，支持惰性延续与去前缀并入
- 渲染行为：居中逐句排版、超宽自动缩放、保留行内语法（加粗/脚注等）不互斥
- 打断规则：与 [副]/[题]/[抬]/[款]/脚注定义双向打断
- 迁移策略：历史诗词按段落自动添加 `[诗]` 前缀，toc_entry 重映射
