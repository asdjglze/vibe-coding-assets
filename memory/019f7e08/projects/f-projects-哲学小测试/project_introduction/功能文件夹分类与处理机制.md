图书分类系统支持"功能文件夹"机制，程序自动创建并永不误删：
1. **暂不处理**：整树跳过扫描、识别、移动和删除，作为人工暂存区。
2. **强制按单独文件分析**：内部文件独立成书，跳过分卷合并及文件夹形书籍判断，直接逐文件识别归档。
3. **待人工**：语义区分"AI无法处理留给人工"，整树跳过。
4. **强制合并为一本**：目录内所有文件无视分卷规则，全部合并为一个PDF后识别。
5. **强制类型类**（强制书籍/规范/图集/政策文件）：跳过AI类型初判，直接按指定类型流程处理（如规范走标准号匹配）。
6. **零散文章直通**：文件直接归类为网络文章，不调用AI。
7. **只解压不识别**：压缩包解压清理后暂存，不进AI。

通用规则：不存在时自动创建；加入空文件夹清理硬保护名单；路径命中即生效（子目录继承）。
