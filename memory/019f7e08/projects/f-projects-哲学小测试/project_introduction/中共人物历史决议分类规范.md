中共人物分类需严格依据党的历史决议进行细分：
- 正确路线代表（如周恩来、刘少奇）归入**毛派**
- 陈独秀归为**机会主义**（右倾错误）
- 瞿秋白归为**盲动主义**（左倾盲动）
- 李立三归为**立三路线**
- 王明归为**王明路线**（教条主义）
- 张国焘、罗章龙归为**分裂主义**
- 林彪归为**林江集团**
- 李大钊等早期牺牲先烈归为**革命先驱**
