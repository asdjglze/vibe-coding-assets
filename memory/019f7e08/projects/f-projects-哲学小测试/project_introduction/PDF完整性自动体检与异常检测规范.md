项目具备全库PDF完整性自动体检能力，需逐页扫描检测三类异常：1) 空白页（非白像素检测），2) 坏页（读取/渲染异常），3) 尺寸异常页（识别WAF验证页被存成的假页）。同时支持有源目录书籍的页数收付相符性比对，最终输出红黄绿分级体检表及异常页号清单，无需人工逐本翻阅。
