鼓组音色播放严格遵循原始采样时长：当请求时长小于采样实际长度时，截断播放；当请求时长大于采样实际长度时，在末尾补静音；全程禁止任何形式的时间拉伸（pitch-shift或time-stretch），确保鼓组保持瞬态冲击力与真实感。
