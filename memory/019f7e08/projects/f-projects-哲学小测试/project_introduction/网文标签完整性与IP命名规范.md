网文标签体系构建原则:
1. **完整性优先**: 标签本身的丰富度比分类层级更重要，宁可不分池也要保证词库全量覆盖
2. **IP名称合法化**: 具体IP名（如火影、柯南、原神等）属于行业通行的受控标签，应作为衍生类标签收录，不视为AI自创词
