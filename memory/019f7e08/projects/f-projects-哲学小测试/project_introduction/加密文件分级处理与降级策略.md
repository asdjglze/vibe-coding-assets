加密文件分级处理策略:
1. **程序级拦截**: 利用PyMuPDF/zipfile标志位检测加密，加密压缩包不进AI；
2. **AI降级引导**: 开场白明确告知正文不可读，禁止尝试读取正文，改为凭文件名+联网确认身份并完成分类；
3. **提示词修正**: manual适用条件仅限彻底损坏，加密不算退出理由，需查证后refuse。
