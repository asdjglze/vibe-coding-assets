项目人物流派分类新增规则（非马左翼与马克思主义必须明显区分）:
- "社会民主"拆分为两类："第二国际"（马克思主义谱系：倍倍尔、威廉·李卜克内西、考茨基、蔡特金、拉法格、梅林、普列汉诺夫、阿克雪里罗得、帕尔乌斯、奥托·鲍威尔、潘涅库克）与"社会民主"（非马克思主义改良派：拉萨尔、饶勒斯、幸德秋水、江亢虎）。
- 英国左翼拆分：汤普森、霍布斯鲍姆、威廉斯、密利本德归"英国新左派"，拉斯基归"工党左翼"，多布留"英国左翼"。
- 美国左翼拆分：斯威齐、哈里·马格多夫、布雷弗曼、艾伦·伍德归"每月评论"，埃里克·赖特归"分析马哲"，杜波依斯归"泛非主义"，贝尔·胡克斯归"黑人女权"（美国左翼类取消）。
- 非马克思主义左翼独立成类：无政府、空想派、泛非主义、黑人女权、工党左翼、左翼文学（鲁迅）、社会民主（改良派）。
