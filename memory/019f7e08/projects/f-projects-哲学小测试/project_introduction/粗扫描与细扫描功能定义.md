粗扫描阶段功能包括：递归列对象、自动创建功能文件夹、排除名单过滤、空文件夹清理、推广残留目录清理、孤儿侧车清理；建议增加的功能：散落快捷方式文件 (.url/.lnk)、系统垃圾文件 (desktop.ini/Thumbs.db/.DS_Store/._*)、下载残留 (*.part/*.crdownload)、Office 锁残留 (~$*.docx)、0 字节文件、临时备份文件 (*.tmp/*.bak)。

细扫描阶段采用按需处理策略：根据来源类型、已有标签和元数据完整度判断，需要分类则分类，需要富化则富化，两者皆需则都做，都不需要则直接跳过归档。
