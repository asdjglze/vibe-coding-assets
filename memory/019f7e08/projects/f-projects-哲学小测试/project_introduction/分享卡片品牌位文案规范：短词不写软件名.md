分享卡片品牌风模板中原「平台/软件名」位置的处理规则（用户终审）：
1. 严禁放软件名称（如「有所思」），也严禁写死虚构数据（英文 repo 名、篇目编号、出版年份如「1925 年版」）；
2. 优先用真实数据短词：书名《热风》（从 source 提取，share_core.js 的 data-book 机制）、作者名、生卒年；
3. 或沿用 demo 原版写死短词装饰（「节选 · QUOTE」「节选 / QUOTE」「quote」「每日节选」等）；
4. 出处一律短词化：标题已显示篇名时禁止再写「摘自《X》 · 篇名」全称（data-short 截书名、data-book 取书名）；
5. 品牌装饰元素（绿点、音量柱、几何标、徽章样式）原样保留，仅替换文字内容。
