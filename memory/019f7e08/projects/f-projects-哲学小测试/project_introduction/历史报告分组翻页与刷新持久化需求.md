历史报告页面翻页功能需支持：
- 工具栏提供'上一组'和'下一组'按钮，点击直接切换相邻分组第一页；
- 点击左侧CC分组列表项，右侧预览立即跳转至该组第一页并高亮当前组；
- 页面刷新后不丢失用户当前项目的照片排序、所在分组及页码，通过localStorage持久化sessionId、排序状态和浏览位置，并在加载时调用GET /api/session/:id恢复数据。
