免责声明文案中关于争议人物的表述需遵循以下原则：
1. 理念差异是客观的，但理念不代表正确与适合；
2. 阅读争议人物是为了通过了解其错误，深刻理解其所处时代，并以此对应当下；
3. 对人物是否有争议或是否为叛徒的评价，在不同时代会产生不同的时代性解读；
4. 学习文本必须立足当下，多实践、多验证，将当下的经验总结成新的理论。
