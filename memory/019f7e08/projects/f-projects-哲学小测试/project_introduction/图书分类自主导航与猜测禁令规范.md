图书分类Agent架构调整：取消强制逐层漏斗模式，改为"自主导航 + 目录查询 + 猜测禁令"机制。AI需具备自我规划能力，在无确切证据时禁止强行归类，应通过list_tree工具查询完整子树确认类号存在性；若无法找到准确类目或证据不足，必须标记低置信度并转人工，严禁在错误分支中硬凑近似值。
