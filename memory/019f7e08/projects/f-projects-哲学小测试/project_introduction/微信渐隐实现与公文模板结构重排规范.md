微信模板渐隐效果与公文模板结构规范：
1. 微信模板：正文容器必须为 block 且气泡 flex:1 占满头像右侧，避免 inline 模式导致宽度塌陷触发渐变退化；渐隐逻辑生效需依赖正确计算的 clientWidth。
2. 公文模板：删除顶部 head-bar 红条，仅保留标题下方红星线；作者名作为副标题居中对齐置于标题正下方；红线下方放模拟文号的版本行（格式：《书名》〔年份〕版），文号右对齐，字号字体与副标题完全一致（KT 楷体同字号），不可比副标题大；年份缺省时回退为当前分享年份（share_core.js 的 data-fallback-year="1" 属性）；正文 3 号仿宋感：首行缩进 2 字符、行距固定 28px、两端对齐；移除右下角重复的作者署名。
