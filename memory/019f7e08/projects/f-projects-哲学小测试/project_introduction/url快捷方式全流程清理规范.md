Internet 快捷方式 (.url) 清理逻辑需覆盖全流程：
1. **识别前清理**：在主流水线识别步骤（05步）最前调用 `clean_pending()`，递归清理所有 pending 目录下的 .url/.lnk 等推广后缀；
2. **空壳清理**：在收尾阶段（08步），将仅剩 .url/.lnk 的目录视为垃圾连根删除，解决书搬走后残留的问题；
3. **解压链路**：统一使用公共清理函数，确保 heavy 目录和普通目录均执行相同清理标准。
