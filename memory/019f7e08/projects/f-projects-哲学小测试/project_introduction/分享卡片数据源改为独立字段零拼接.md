分享卡片数据链路重构：删除 `source` 字段（原「摘自《》 > 篇」拼接串），改为独立传入 `bookTitle`（纯书名）、`title`（篇名）、`person`（作者）。App 端（ShareCardWebView.kt、ShareCardScreen.kt、ReaderScreen.kt）不再进行任何文本拼接，直接透传各字段；JS 层 share_core.js 中旧模板的 `data-field="source"` 统一映射到 `bookTitle`。
