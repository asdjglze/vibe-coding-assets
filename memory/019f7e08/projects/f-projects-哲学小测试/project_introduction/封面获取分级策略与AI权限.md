图书封面获取与处理策略调整：
1. **分级努力原则**：出版书（有ISBN/出版社）需竭尽全力获取封面；未出版书（网文/私人汇编/内部发行）允许合法无封面，不硬塞。
2. **AI程序权力**：赋予AI拒绝权（输出`{ok:false}`保留原状）及有限搜索权（仅限掀页截取和结构化API查询，禁止互联网图片爬取）。
3. **停用假封面**：找不到真实封面时不再合成占位图，直接显示无封面状态。
