人物流派徽标意象色规范:
- 马主义谱系 (129 人): 使用红色系，象征社会主义传统。底色 `0xFFF4DDD3` (淡陶土红)，文字 `0xFF9A4B35` (砖红)。
- 非马左翼谱系 (20 人): 使用中性米色，与马哲明显区分。底色 `0xFFE8E4DE`，文字 `0xFF6B6259` (深棕)。
