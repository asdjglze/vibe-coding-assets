选集类书籍命名规范（与毛泽东选集格式统一）：
1. 多卷选集：《人名选集》第X卷 时期描述——书名号+中文数字卷次（按时间顺序编卷）+时期描述并列，时期以「时期」结尾的括号内容去括号并列，非时期类说明（附录、未确定日期、年代不详等）保留括号紧贴卷次，如《列宁选集》第一卷 1893-1904时期、《陈独秀选集》第二十一卷（附录）。
2. 分卷文集：卷册标记统一，如《周恩来选集》上卷（去括号）、《卢森堡文集》第一卷（1893-1902）（括号年份区间，同毛泽东思想万岁格式）。
3. 单选本：仅加书名号，如《克鲁普斯卡娅文论选》。
4. 禁止纯数字年份作书名；书名中连字符仅用于年份区间，不是分隔符。
