批量爬取电子书任务支持两种格式：
1. **普通电子书**：通过 `files/mobile/N.jpg` 下载图片并合并为 PDF
2. **Flash 老书 (FlipViewer)**：解析 XML 配置整包下载 SWF、封面、文本等原始文件
