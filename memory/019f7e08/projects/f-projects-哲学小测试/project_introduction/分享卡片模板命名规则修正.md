分享卡片模板命名规则：公司/平台类模板，若同一主体在模板池中有多个模板（含基础款自身），则每个模板都必须带区分后缀，不允许任何一款光秃秃独占主体名（如 Apple 分享/Apple 阅读/Apple 极简，Spotify 歌词/Spotify 歌手/Spotify 播放）；主体唯一（如 Nike、企鹅）才可只留主体名。产品全名（微信读书）与主体名（微信）算不同主体，可并存。另：manifest.json 中同一主体的模板必须排在一起（相邻）。
