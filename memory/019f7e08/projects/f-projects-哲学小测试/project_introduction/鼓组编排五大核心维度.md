项目鼓组编排能力包含五大核心维度：
- 进鼓策略：Intro不加→Verse轻进→预副歌加密→Chorus全开→Bridge撤鼓→Outro逐步撤出
- 编鼓方法：底鼓跟随贝斯、军鼓打2/4反拍、镲片铺刻度，并支持5种加花手法
- 跟节奏方式：可选择跟随贝斯、跟随旋律、在段落边界做标记、通过密稀分布避让其他声部
- 情绪表达：提供平静/紧张/释放/诡异/欢快五套差异化编排方案
- 密度与音色：禁止全程使用<S>H/<K>H，要求段落间鼓点密度和音色必须动态变化
