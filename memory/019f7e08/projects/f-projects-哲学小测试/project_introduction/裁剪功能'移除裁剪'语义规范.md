照片排版项目裁剪功能的'移除裁剪'语义定义：点击'移除裁剪'按钮后，后端清空该图片全部裁剪字段（cropLeft/cropTop/cropWidth/cropHeight/effectiveWidth/effectiveHeight），type恢复为原始尺寸分类，图片呈现完全不裁剪状态；前端立即写入数据并自动关闭裁剪弹窗，无需二次保存。
