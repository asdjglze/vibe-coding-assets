微信翡翠绿模板（19_wechat）的灰色居中时间位字段错误，原绑定 `data-field="subtitle"`（副标题），已修正为 `data-field="year"` 并增加 `data-fallback-death="1"` 兜底逻辑，显示书籍出版年份或作者死亡年。
