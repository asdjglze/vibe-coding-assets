图书入库快通道流程调整：
1. **OCR 策略**：取消 OCR 识别（纯文本无法区分书名/出版社，低产出），改为由后续 AI 全链处理。
2. **内嵌元数据**：不用于快通道书名生成（常含垃圾信息），仅作为 AI 精修时的零成本参考素材。
3. **快通道流程**：真实格式把关 → 挪位进「未分类」域 → 登记（书名=文件名）→ 挂「未校对」标签 → 发布可见。
4. **精修流程**：后续独立工序，AI 读取「未校对」标签时强制加警示句进行交叉验证。
