新增文章插入位置交互（notes_editor）：弹窗里先自动定位当前打开的文章（locateBookAndGroup 反查其书/章，填作者/所属书/所属章），"参照文章"是下拉菜单——列出当前所选书/章位置下的全部文章，默认选中当前打开的那篇；若没识别到（未打开文章或不在列表中），用户手动从下拉重选。选好参照后"插入位置"选"在其上/在其下"，前端传 refId+pos 给 /api/add；后端按 refId 查 toc_entry，在其 sortOrder 前/后插入（above：参照及后续 sortOrder+1；below：参照后续 +1），parentId/level 取参照的；参照无效或为空则退化为书/章末尾插入。
