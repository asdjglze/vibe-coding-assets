图书分类系统支持"功能文件夹"机制，程序自动创建并永不误删。新增4个强制类型类文件夹：
1. **强制书籍**：跳过AI类型初判，直接走中图分类Agent。
2. **强制规范**：跳过AI类型初判，按标准号匹配全表→工标网→失败转AI兜底。
3. **强制图集**：跳过AI类型初判，按图集号定位归档。
4. **强制政策文件**：跳过AI类型初判，归档至政策法规目录。
通用规则：不存在时自动创建；加入空文件夹清理硬保护名单；路径命中即生效（子目录继承）；除"暂不处理"和"强制按单独文件分析"外，其他文件夹不排除分卷合并。
