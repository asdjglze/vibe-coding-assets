项目鼓组需扩展拟声（Foley）音效支持，涵盖枪声、脚步声、敲门、拳击、水滴、筷子、撕纸、电击、风铃、爆炸等10类常见音效；采用SFZ格式封装，映射至GM标准预留MIDI音符槽位（27–34及82–87），确保与现有鼓组不冲突；音源须来自freesound.org或pixabay等平台的CC0协议免费WAV采样。
