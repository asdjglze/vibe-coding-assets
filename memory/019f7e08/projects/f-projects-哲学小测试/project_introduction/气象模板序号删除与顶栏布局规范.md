气象类分享模板（index 86-97）的三项统一规范:
1. 序号删除：所有模板右上角的「NO. XXX」编号全部移除。
2. 左上角布局：统一改为「文章名 + 当前分享时间」（如「随感录四十一 / 20:01」），使用 data-now 机制动态获取。
3. 特殊右上角处理:
   - 93 荒原雷暴：保留 ⚡ FLASH 装饰，左上角为「文章名 · 当前时间」组合。
   - 95 马孔多的雨：右上角年份采用回退链显示——优先书出版年 → 退行人物死亡年（lifespan 末位）→ 再退行用户分享年。
