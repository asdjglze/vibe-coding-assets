封面获取高清化策略修正：
1. 豆瓣：URL从/s/public/升级为/l/public/，下载请求增加Referer: book.douban.com头以解决418反爬。
2. 微信读书：URL前缀从s_改为b_（最大公开档），404时退至m_。
3. PDF截页：缩放倍率从2倍提升至3倍以获取更清晰图片。
4. PDC：优先使用详情大图f_image。
