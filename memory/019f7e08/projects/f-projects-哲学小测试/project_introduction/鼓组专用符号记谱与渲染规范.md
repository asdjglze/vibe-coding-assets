项目鼓组记谱采用专用符号系统：
- `K`：底鼓，渲染为低频正弦波 + 噪声包络
- `S`：军鼓，渲染为正弦 + 白噪声
- `H`：闭镲，渲染为高频带通噪声 + 短衰减
- `O`：开镲，渲染为高频噪声 + 长衰减
- `R`：叮叮镲，渲染为中高频噪声 + 持续
所有符号以负频率编码（如 K=-1），确保不与真实音高冲突；完整支持时值修饰符（. - + ^）、休止符 0 和和弦 <...>。
