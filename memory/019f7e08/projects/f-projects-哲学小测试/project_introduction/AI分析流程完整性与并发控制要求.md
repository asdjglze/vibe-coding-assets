项目核心业务逻辑要求：
- 前端退出或SSE断开后，后端必须持续执行完全部AI分析阶段（含哲学家相似匹配），不得中断；
- 后端处于生成分析报告状态时，禁止用户前端创建新的答卷session，需拒绝重复提交。
