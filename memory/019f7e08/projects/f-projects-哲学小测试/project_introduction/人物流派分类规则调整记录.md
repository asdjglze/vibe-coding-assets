项目人物分类规则调整:
- "革命先驱"统一改为"中共先驱"，明确仅指中国共产党早期牺牲先烈，排除苏联、古巴等其他国家革命者。
- 林彪归类调整为"毛派"，依据是其早期执行了毛派路线（毛派现含毛泽东、周恩来、刘少奇、林彪）。
- 共产国际类拆分：保尔·列维归"卢森堡主义"（维护卢森堡遗产）、拉狄克归"托派"（托季联盟成员），其余各国支部领袖与驻华代表（台尔曼、库恩·贝拉、片山潜、福斯特、约翰·里德、马林、罗易）保留"共产国际"。
