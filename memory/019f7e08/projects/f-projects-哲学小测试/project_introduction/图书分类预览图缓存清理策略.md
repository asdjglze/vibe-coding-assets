图书分类系统需实现预览图缓存自动清理机制：当一本书完成识别并入库后，立即删除该书的预览图缓存文件（包括 `state/preview_imgs/` 目录下的单本书渲染页及内嵌提取图，以及 `state/std_prev_p*.png` 规范图集预览图）。清理时机设定为当前书处理期间保留供AI读取，下一本书开始前清除上一本的缓存，确保磁盘空间不随书籍数量累积增长。
