人物生卒年月数据结构优化: lifespan 字段恢复为纯年份格式 (如「1881—1936」)，新增独立的 birth 字段存储带月生的完整日期 (如「1881.09」)。App 数据链 (ShareCardData, ShareBridge JSON) 需同步透传 birth 字段，供喜马拉雅 FM 频段号提取等场景直接读取，避免在多个模板中重复编写复杂的日期提取逻辑。
