项目排版设置页的间距配置区域需采用表格化CSS网格布局，确保所有配置项的标签、输入框、单位三列严格对齐：
- 使用6列网格 `5em 58px auto 5em 58px auto`
- 标签统一宽度`5em`且右对齐
- 输入框统一宽度`58px`
- 前4行各占满6列，第5行仅占前3列，右侧留空
- 避免因文字长度差异导致输入框错位
