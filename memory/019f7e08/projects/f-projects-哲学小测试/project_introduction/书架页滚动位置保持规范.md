书架页从阅读页退出返回时，必须保持进入阅读页前的原始滚动位置（如网格滚动偏移量），禁止重置到页面顶部。该状态需通过提升 LazyGridState 至永不离开组合的层级（如 MainActivity）来持久化，避免依赖不可靠的 SaveableStateProvider 时序机制。
