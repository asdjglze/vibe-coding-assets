竖版长文处理策略：卡片宽度固定（320px），列数固定（书牌6列/竹简7列），每列字数随内容增长导致卡片高度自适应增加；超长内容自动截断并在尾部加省略号。实现方式：JS显式计算高度 = (总字数 ÷ 列数) × 字高，解决Chrome竖排容器height:auto不随内容扩展的问题。
