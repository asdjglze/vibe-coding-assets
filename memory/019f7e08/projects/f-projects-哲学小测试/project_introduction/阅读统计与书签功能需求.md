项目阅读统计与书签功能：1. 统计图表：信息页展示阅读时间段分布、每日阅读时长折线图、各书籍/人物总进度、不同人物总时长、每日人物时长柱状图。2. 进度书签：记录每本书/篇文章的最大阅读进度，目录和书架显示；翻至最后一页无法继续翻页时强制进度100%。3. 文本收藏书签（另一含义）：阅读页选中文本后点分享栏旁「加入书签」收藏，存独立 bookmarks.db；「我的」页书签入口两级展示：书列表（作者筛选 chips）→ 该书条目翻页列表（每页20条，卡片固定高度96dp统一格式，可删除，删除确认弹窗）。搜索范围跟随书架人物筛选（浏览鲁迅书架只搜鲁迅）。
