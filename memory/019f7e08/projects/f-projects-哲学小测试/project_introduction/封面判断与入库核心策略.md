封面判断与入库策略:
1. **无图处理**: 找不到合格封面时直接标记为无图，禁止生成合成占位图。
2. **尾部掀页**: AI需具备查看尾部页面的意识，程序也可自动提取尾部页面供AI参考。
3. **申请轮次**: AI的掀页/查词申请最多限制在 3 轮以内。
4. **出版判定**: 依据元数据中的简介、ISBN或出版社信息进行粗判，有任一字段即视为出版物。
5. **清晰度用途**: 高清图片仅用于AI视觉判断；入库后只要符合XOPS格式要求即可，不强制保留原图分辨率。
