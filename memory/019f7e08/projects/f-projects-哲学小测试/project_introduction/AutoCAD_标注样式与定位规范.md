AutoCAD 标注样式配置规范:
- 样式名: DTQ_DIM_V1_9F3C72A5 (带GUID后缀确保唯一性)
- 标记类型: DIMBLK="_ARCHTICK" (专用建筑标记，非倾斜)
- 小数精度: 2位
- 文字位置: 尺寸线上方，与尺寸线对齐
- 字体: HZTXT (gbenor.shx + bigFontFile=hztxt.shx)
- 文字高度: 0.09
- 颜色: 白字绿线
- 水平标注定位: b1在自然地坪线上方；b2和垫层宽在垫层底面下方分层排布
- 垂直标注定位: h1/h2/h3 左侧连续标注（共一条尺寸线首尾相接，cx=-0.6），H 总高单独在外侧（X=-1.55）；右侧仅留构件引出线
