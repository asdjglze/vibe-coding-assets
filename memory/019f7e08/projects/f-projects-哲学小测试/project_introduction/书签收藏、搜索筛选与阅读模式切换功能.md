项目新增三大核心功能：
1. **书签/收藏**：用户选中文本后点击「加入书签」存入独立本地数据库 `bookmarks.db`（快照式实体防内容库更新失效）。入口在「我的→书签」，采用两级结构：一级书列表（含作者筛选 chips）+ 二级条目翻页列表（固定高度卡片、每页20条、支持删除）。
2. **搜索作者筛选**：书架页搜索激活时，复用当前人物筛选状态（`selectedPersonId`），搜索框下方显示作者筛选 chips，仅搜索选中作家的文章。
3. **阅读模式切换**：设置中提供「滚动阅读 / 翻页阅读」切换。翻页模式采用贪心装箱算法分页：标题/署名作为不可分割头部单元；诗词逐句装箱居中；普通文本块超出视口剩余高度时按行切割跨页。
