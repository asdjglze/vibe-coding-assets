中图分类遵循「总论入上位类，专论入下位类」原则，层级深度由书籍论述范围决定而非强制要求；泛论书可停在第三层（如TU242），专论书才下钻至第四层或更深。归档目录结构应直接反映实际分类层级，无需为祖先类目（如T、TU）建立冗余目录树，允许不同深度的类目在同一父目录下共存。
