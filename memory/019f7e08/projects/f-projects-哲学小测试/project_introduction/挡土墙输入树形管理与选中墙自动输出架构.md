挡土墙计量工具输入输出交互架构（2026-08 重构）：输入区为左右分栏——左侧文件夹树（根节点"挡土墙工程"，每面墙=一个文件，单击选中、双击行内重命名、悬停×删除、顶部＋新建），右侧只渲染当前选中墙的输入卡片+全局参数。数据层用内存数组 wallsData 驱动（每项含 name/sections/proc），切换选中前先 syncCardToData 保存编辑。输出改为每次修改自动计算（防抖600ms），且只输出选中墙的表/断面示意图/伸缩缝表；单墙输出不显示总计行（总计含其他墙数据）。新建墙编号从现有墙名动态推断最大序号+1，避免删除中间墙后重名。
