当前鼓组系统共支持10种鼓音色：
- 合成鼓9种：C(底鼓)、D(军鼓)、E(闭镲)、F(开镲)、G/A/B(低/中/高通鼓)、c(叮叮镲)、d(强音镲)，均通过波形合成实现；
- 采样鼓1种：moog_drums（SFZ采样）。
缺失但高频需求的鼓件：hihat_pedal（脚踩镲，高优先级）、rim_shot（边击，高优先级）、splash（水镲，中）、china（中国镲，中）、clap（拍手，中）。
