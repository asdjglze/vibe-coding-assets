项目简谱播放模块采用三阶段流水线架构：
1. 解析阶段：`_load_score`和`_parse_line_to_notes`函数全量解析整份简谱，将所有音符数据（频率、时长、分组）存入内存；
2. 渲染阶段：`_render_notes_to_samples`函数将内存中的音符数据批量转换为音频采样值；
3. 播放阶段：`play_score`函数调用`_play_wav`逐段播放已渲染好的采样数据，不包含任何解析逻辑。
禁止边解析边播放的旧模式。
