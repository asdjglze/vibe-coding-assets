项目核心功能改造需求:
1. **导航重构**:底部三标签（主页/书架/我的）。
2. **书架模块**:顶部人物筛选，按出处聚合书本，极简封面设计；点击进入统一阅读页。
3. **阅读页规范**:长版滚动无翻页，左侧可收展目录，字号三档切换（默认/大/超大），字体/字色/背景色可在设置中自定义。
4. **语录与文章关联**:点击语录跳转至关联文章页面。
5. **毛泽东文章版式**:主标题下方显示日期副标题及题注（写作环境说明）。
6. **全面屏适配**:修复底部导航键区域遮挡问题。
