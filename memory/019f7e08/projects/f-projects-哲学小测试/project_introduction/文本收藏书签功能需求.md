项目新增文本收藏书签功能：
1. 阅读页交互：选中文章段落后，分享栏增加「加入书签」按钮。
2. 数据存储：收藏内容存入独立的本地数据库 `bookmarks.db`（实体包含书名、作者、篇目标题及文本快照），防止预打包语料库更新导致收藏失效。
3. 书签列表页：在「我的」页面提供入口，采用两级结构——一级为书籍列表（按作者筛选，仅展示有收藏的书籍），二级为分页展示的收藏条目卡片（固定高度96dp，超长截断，支持删除）。
