report生成流程重构为两个阶段：
- 哲学画像分析阶段：仅基于维度数据进行哲学层面的深度分析，输出纯哲学画像（profile）；
- 心理学行为分析阶段：接收哲学画像与原始维度数据，生成称号、五个生活领域分析（家庭/交友/工作/学习/恋爱）及巴纳姆式行为建议。
