分享卡片模板 69-74 专项修改:
1. 69 小红书: 标签改为动态书名 (如#《毛泽东诗词》), 添加真实头像, 删除右上 emoji; 修复全库正文渐隐失效 bug(原因为 flex 居中布局下空态宽度为 0 导致测量失败)。
2. 70 推特: xs-name 显示作者名, xs-handle 显示拼音英文名 (新增 data-pinyin 属性转换), xs-date 显示「摘自《书名》」。
3. 71 ins: 添加真实头像, 正文改用楷体 (KT), 设置固定底部间距。
4. 72 Telegram: 删除 tg-sub, tg-channel 显示@作者英文名, tg-logo 改为毛体思蓝底白字, 保留纸飞机图标并设固定间距。
5. 73 知乎: zh-avatar 显示头像, appName 与 logo 分离 (黑体蓝字名称 + 毛体思斜体 logo), label 显示生卒年, zh-q 显示文章标题, Q 伪元素改为 T。
6. 74 NASA: 改名「NASA 蠕虫 · 汇报版面」, nasa-meta 显示文章标题, nasa-sub 显示「作者·书名·出版年份」。
