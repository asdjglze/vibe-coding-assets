gb99.cn 标准数据源已接入作为统一兜底源（25万+数据量）：
1. URL构造：将编号中的空格和斜杠替换为连字符（如 GB/T-22522-2021 → GB-T-22522-2021）；
2. 兜底策略：当工标网/openstd/图集站匹配度<80分时自动补查 gb99.cn；
3. 未收录页识别：返回 200 + 模板占位符时判定为“未收录”，需通过字段校验拒绝，不可直接采信。
