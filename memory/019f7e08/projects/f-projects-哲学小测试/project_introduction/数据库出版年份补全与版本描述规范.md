数据库出版年份补全规则：
- 后人整理汇编本（如序跋集、书信集、语录、拾遗系列）若无明确初版年，可填整理出版年份（如静火版毛选整理年2004）或保持空缺。
- 版本描述统一用「xxxx年版」格式，禁用「初版」等未经确认的定性词。
- 分享卡片上若数据库未记录出版年，则不显示年份行，仅显示出处。
