照片排版项目核心功能需求：
- 输出A4纸张PDF，每页按2×2网格排版（竖向照片占1×1格，横向照片占1×2格）
- CC为分组标识（ZIP内二级文件夹名），AA为照片文件名（去除(1)/_1等尾缀）
- BB为页眉文本（来自ZIP压缩包名）
- 支持GBK编码中文文件名解码，自动修复乱码
- 智能跳过ZIP公共根目录，准确提取真实分组结构
