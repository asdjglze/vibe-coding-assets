校对工具"自动排版"功能（index.html 中 analyzeHeading）的层级分配规则：按标题模式（第X章、一、、（一）、(1)、1.、短行）在全文中的首次出现顺序分配 H1/H2/H3，先出现的模式层级更高；第4种及以后模式并入 H3。弹窗中用户可逐行调整层级并勾选应用。排除规则：已有 # 标题行、[题]/[副]/[抬]/[款] 标记行、注释定义区、引号开头或结尾的对话行、后续无正文的落款/署名行；zhnum 序号分隔符仅限、．.（不含中圆点·以免日期误判）；digit 后跟引号视为摘录而非标题。
