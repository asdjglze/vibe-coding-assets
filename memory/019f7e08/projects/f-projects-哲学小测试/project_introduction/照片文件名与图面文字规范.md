项目照片管理功能要求：
- 文件名必须使用汉字清晰描述拍摄内容，并按工序路径组织（如`01-土方开挖/基坑放线定位.jpg`）
- 图面大字显示汉字内容描述+序号（如"基坑放线定位 #12"）
- 图面小字显示尺寸与真实拍摄时刻（EXIF修改时间），用于核对按时间排序的准确性
