转注码两个按钮（notes_editor）都走同一弹窗勾选流程（openConv(items, mode)，convMode 决定替换目标）："转引用"（btnConvert）全文收集（collectTags，行首的视为序号不收集——用户行文规范注释永远在段落后），勾选后转 [^N]；"转定义"（btnDef）要求先选中一段文字（如注释定义区），选区限定范围（collectDefTags 不过滤行首，定义区 [1] 常在行首），弹窗勾选后转 [^N]: 定义形式，仅换注码本身保留内容，后跟空格时吃掉原空格补标准冒号空格，未选中时 toast 提示。弹窗列结构：主行（勾选/类型徽章/行号/正文列/引用符原文/→/目标列）+副行；ref 模式正文列=注码前方30字+注码，目标列 [^N]，副行=定义正文（未定义红色 miss、无内容 empty，title 悬停全显）；def 模式正文列=注码起的内容40字，目标列 [^N]: ，副行=该行完整内容。
