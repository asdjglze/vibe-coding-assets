人物流派谱系区分的软件实现已完成：
- person 表新增 schoolCategory 字段（「马主义」/「非马」），AppDatabase version 8→9，双库（notes_editor 源库 + assets 打包库）同步。
- 33 个流派全部归类：26 个马主义谱系（129 人）、7 个非马左翼（20 人），共 149 人。
- 徽标意象色规则：马主义谱系 = 红色系（淡陶土红底 0xFFF4DDD3 + 砖红字 0xFF9A4B35，象征社会主义红色传统）；非马左翼 = 中性米色（0xFFE8E4DE 底 + 0xFF6B6259 字）。颜色判断逻辑在 PersonSelectionScreen 中按 schoolCategory == "马主义" 分支。
