report生成流程升级为三阶段流水线：
- 阶段1（立即）：用户答题完成后，前端立即渲染维度数据概览（`showDimData`）；
- 阶段2（AI启动）：后端开始哲学画像分析，完成后存储并推送至前端，前端立即启动打字机逐行显示；
- 阶段3（并行）：哲学画像推送后，后端继续生成心理学行为分析报告，完成后同样推送并由前端打字机逐行显示；
- 阶段4（终态）：心理分析完成后，后端执行哲学家匹配并直接显示最终结果。
全程遵循前后端解耦并行原则：前端打字显示不阻塞后端后续阶段计算。
