项目串词功能的核心定位是‘人格的舆论武器’，而非简单的音乐介绍。核心能力要求：1. 拒绝中立播报，必须带有明确的评价立场；2. 针对特定题材（如黑帮、物质主义）进行价值观层面的评判；3. 将个人哲学思想（如小资、老庄逍遥）融入对歌词、歌手和故事的解读中。
