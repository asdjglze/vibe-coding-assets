图书分类系统中，国标图集编号的年份提取规则：
- 识别格式：文件名开头的两位数字（如 12J003=2012年）。
- 世纪判定逻辑：
  - 数值 ≥ 30 → 归入 19xx 年（如 30J001=1930, 80J512=1980）。
  - 数值 < 30 → 归入 20xx 年（如 12J003=2012, 29J999=2029）。
- 优先级：四位年份优先于两位年份规则。
