挡土墙计量中泄水管工程量计算规则：泄水管长度(m)=泄水孔个数×泄水管平均长度。泄水孔个数=段长/泄水孔间距向上取整；泄水管平均长度由用户输入（默认0.6m），前端参数框 p-weeplen，后端参数 weep_len（params.get('weep_len', 0.6)）。输出表列名为"泄水管"、单位 m，计算式显示"向上取整(L/间距)×平均长度"。反滤层(滤水包)仍按泄水孔个数计算，不随平均长度变化。
