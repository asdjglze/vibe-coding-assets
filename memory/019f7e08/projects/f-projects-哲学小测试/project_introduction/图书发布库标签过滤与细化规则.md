图书发布库标签生成规则修正：
- **移除域级通用标签**：不再为所有书打上“中图分类”或“规范图集”等无区分度的域级标签。
- **保留细分领域标签**：仅保留具有筛选价值的细分标签，如`[规范]行业标准`、`[图集]中南标`、`[政策]政策文件`、`[领域]文学`等。
- **目的**：避免读者在海量书籍中面对无意义的“全集桶”，提升标签的检索价值。
