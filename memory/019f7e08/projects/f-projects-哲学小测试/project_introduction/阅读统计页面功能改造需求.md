阅读统计页面改造需求:
1. 书籍总进度改为按整书进度降序的排名榜（带名次徽章）。
2. 每日阅读时长与时间段分布采用多层堆叠柱状图（一柱=总量，分色=人物），点击柱段悬浮显示明细。
3. 新增GitHub风格贡献热力图（月/年视图，支持翻页，点击格子悬浮当日明细）。
4. 所有图表组件统一提供日期范围切换工具（近7/30/90天 chips + 翻月/翻年）。
