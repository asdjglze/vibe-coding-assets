分享卡片模板序号删除范围与文案规范:
1. 序号删除: index 52(瑞士网格)至气象类(index 86-97)所有模板的「NO. XXX / № XXX」批次序号一律删除，保留左侧品牌/栏目文字；58老报纸删序号后title加flex:1居中。
2. 52瑞士网格: marker右边文案改为「● 摘录」（非引用）。
3. 56双色印刷: cr-top左侧改文章标题，右侧改出版年份（走回退链）。
