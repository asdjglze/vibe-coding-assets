中图分类域目录结构优化：在分类层级与作者桶之间插入 `[本层书籍]` 文件夹。当图书归类到当前层级（泛论书）时，统一放入该层；若需继续下钻细分，则进入子分类文件夹。此设计使分类目录下仅存在“带类号的子分类”和“[本层书籍]”两种文件夹，清晰区分待细分类目与已归档书籍。
