诗词优先的分享模板（如月窗）必须实现格式化断句算法，避免在诗句中间（如"如"字后）强制换行导致语义断裂；第二行开头不应出现孤立汉字（如"铁"）。实现方式：share_core.js 的 data-poem="1" 属性 + poemLines/splitPoem 函数，在中文句读标点（，。；！？、：；）及收尾符号（"』））后换行，pre/post 上下文按整句截取（data-pre-lines=2 / data-post-lines=1），配合 white-space:pre-wrap 渲染。

圆形受限容器（圆窗）内必须动态缩小字号：fitPoemFont 用 DOM Range 实测每句渲染宽度（getClientRects 片段数=1 表示未自动换行），按行到圆心的距离算弦长作为该行允许宽度，加总行高限制，迭代缩放字号（data-fit-font="1" + data-fit-min 下限）直到每句完整一行。关键陷阱：
1. .poem 必须 width:100% 固定宽度，flex 列布局下 align-items:center 会使容器塌缩成内容宽，测量全部失真。
2. 上下文块（ctx-pre/ctx-post）与选中正文（ctx-sel）是内联衔接，诗词模式下必须在块间插 <br> 各自独立成行，否则诗句首行会与上文尾行拼在同一行被拆断。
