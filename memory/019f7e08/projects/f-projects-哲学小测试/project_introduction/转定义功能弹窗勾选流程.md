转定义功能改为弹窗勾选模式：选中定义区后点击按钮，打开弹窗展示选区内所有候选注码（含行首），用户勾选需要转换的目标后确认执行；弹窗标题提示"选中区域内共 N 处注码…勾选后将转为 [^N]: 定义"，正文列显示注码起的内容，副行显示该行完整内容，支持整类勾选/全选/全不选
