项目是一个基于ECharts实现的国家排名动态条形图可视化系统，核心功能包括：
- 单段条形图展示各国得分
- X轴自动添加5%余量并优化刻度分布
- Y轴显示国旗图片+国家名称（富文本）
- 支持排名变化动画与数据入场动画
- 当前核心挑战：解决category Y轴下排名动画不同步、瞬移、刻度不同步等问题
