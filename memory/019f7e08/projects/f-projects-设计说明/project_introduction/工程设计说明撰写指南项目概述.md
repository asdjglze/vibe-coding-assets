项目定位：湖南省工程设计说明撰写指南，服务于中级职称申报的设计说明编制工作，本质是‘指导与索引’而非成品文本。

核心特点：
- 结构化多文件体系：分‘总通用要求’（所有专业共用）、‘专业要求’（按建筑工程/市政/水利等5类职称方向细分）、‘成果文件夹’（实际产出存放）
- 强调规范溯源：所有内容仅为指引，必须核查最新版规范原文，严禁直接套用示例文字
- 目标用户：湖南省从事工程设计的技术人员（中级职称评审适用）
