title: "demo与预览产出文件需存档到 demos 分类目录"
usage_scenario:
    - "生成demo或预览文件时"
    - "组织项目文件目录结构"
    - "清理临时目录时确认文件是否需存档"
keywords:
    - "demo存档"
    - "分类目录"
    - "临时文件"
    - "效果预览"
---

demo、风格预览、效果图等产出文件需要长期存档，不能放进 temp/ 等临时目录（临时目录里的东西会被当成看完即删）。应放在项目根目录专门的 demos/ 文件夹下，并按功能分类建子文件夹存放（如 demos/分享卡片/）。
